# 城市地图 · 编辑器 + 路线 — 使用说明

一个让你**自定义地图、放置地点、连接道路**，再**规划路线玩闭环**的小工具。
纯前端、零依赖，拆分前是单个 `地图连线.html`，现重构为规范的多文件结构（`index.html` 为入口）。

---

## 一、如何打开

### 方式 A：直接打开（最简单）
双击 `index.html`，用浏览器打开即可使用（脚本采用经典 `<script>` 加载，不依赖本地服务器）。

> 说明：导入 / 导出基于浏览器本地下载与文件选择，直接以 `file://` 打开也能正常工作。

### 方式 B：本地服务器（可选）
若希望以 `http://` 方式访问，可在本目录起一个静态服务器：

```bash
# Python 3
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

## 二、界面总览

工具分为两个屏幕，由底部「开始游戏」按钮切换：

| 屏幕 | 用途 |
| --- | --- |
| **编辑器** | 摆放地点、连线成路、编辑/删除、缩放、撤回、导入导出 |
| **游戏**   | 从起点出发，依次点选相邻地点，绕回起点完成闭环 |

---

## 三、编辑器用法

### 1. 三种模式（顶部切换）
- 📍 **放置**：点击空白处新增一个地点（离已有地点太近会被忽略）。
- 🔗 **连线**：先点一个地点作为起点（高亮），再点另一个地点完成一条道路；再次点同一地点可取消起点。
- 🗑️ **删除**：点击地点或道路即可删除。

### 2. 编辑地点
- **双击**地点打开编辑弹框，可修改图标（任意字符 / emoji）与名称，并支持删除该地点。
- 新建地点后会自动弹出编辑框。

### 3. 移动地点
- 在地点上**长按**进入拖动模式，移动后可松开；相连道路会实时跟随。

### 4. 画布操作
- **拖动**空白处平移地图。
- **滚轮** / **双指捏合**缩放。
- 顶部提示条会随模式给出操作指引。

### 5. 底部操作区
- **↶ 撤回**：撤销上一步（放置 / 连线 / 删除 / 移动均可撤销）。
- **清空**：清空整张地图。
- **加载示例**：一键载入内置示例地图。
- **⬇ 导出 JSON**：把当前地图下载为 `map-<时间戳>.json`。
- **🖼 导出图片**：把整张地图导出为 PNG。会自动按所有地点计算边界，并在最边上的地点外留出约 80px 内边距留白；地点大小统一归一化，不受当前缩放影响。
- **⬆ 导入 JSON**：选择本地 JSON 文件导入（也可直接把 `.json` 文件拖拽到窗口内导入）。
- **开始游戏**：当地图至少有 2 个地点、1 条道路时可用。

### 6. 自动保存
编辑器会**自动把当前地图存入浏览器 localStorage**，刷新或重新打开后会自动恢复，不会丢失。

## 四、路线游戏用法

1. 进入游戏后，**起点（家）**已被选中，路径面板显示已走步数。
2. 点击与当前地点**有道路相连**的地点即可前进；可走地点会有蓝色高亮提示。
3. 想回头？点击路径中的**上一个地点**即可「回到上一步」。
4. 当已走过至少 3 个不同地点后，可点击**起点（家）**完成闭环；达成后地图与面板变为绿色完成态。
5. 右侧 **+ / − / ⊙** 按钮可缩放，**⊙** 一键复位视图；底部「清空重来」重新开始。
6. 连线过程中，底部面板右上角的 **导出图片** 可把**当前画布**（所见即所得，含已进入的路线与高亮状态）导出为 PNG。

### 小提示
- 没有可走的路时，提示条会变红，点击「清空重来」即可。
- 缩得很小时地点名称会自动隐藏，避免拥挤。

## 五、数据格式（导入 / 导出）

导出的 JSON 结构如下：

```json
{
  "version": 1,
  "places": [
    { "id": 1, "x": 700, "y": 520, "icon": "🏠", "name": "家", "color": "#e88b3a" }
  ],
  "edges": [ [1, 2], [1, 4] ]
}
```

- `places`：地点数组。`x/y` 为世界坐标（可任意数值，视图会自动适配）。
- `edges`：道路数组，每项是两个地点 `id` 的无序对。

## 六、设备适配

- **手机**：默认全屏沉浸，底部面板贴合屏幕。
- **平板 / 桌面**：在较宽屏幕上自动居中为「设备卡」形态，并放大触控目标。
- **横屏 / 矮屏**：自动压缩面板高度，保证地图可视区域。
- 所有尺寸下均支持触控与鼠标操作。

---

## 七、常见问题

- **开始游戏按钮是灰的？** 地图至少需要 2 个地点、1 条道路。
- **导入没反应？** 确认文件是合法 JSON，且包含 `places` 数组。
- **刷新后地图变了？** 编辑器会自动保存，可在编辑器点「清空」后重新编辑，或导入新地图覆盖。
