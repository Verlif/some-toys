## 修复：连线变成黑线（道路样式丢失）
- 根因：`base.css` 约定的四层道路结构（`.road-outer` 灰边外框 / `.road-inner` 白色路面 / `.road-dash` 中央虚线 / `.road-hit` 命中区）与 JS 渲染脱节——`editor.js`、`game.js` 只输出 `<path class="road-line">`，该类无任何 CSS 定义，走 SVG 默认值（fill 黑 / stroke 无），整条路渲染成黑色实线。
- 修复：`js/editor.js`（renderEditor）与 `js/game.js`（buildGameMap）的道路模板改回分层结构（游戏侧道路无交互，不渲染 road-hit）。
- 补充：`css/base.css` 增加 `.road.dim` 预览压暗规则（editor.js 预览模式本就会加 dim 类，此前无对应样式，压暗效果失效）。
- 校验：`node --check js/*.js` 全部通过；类名覆盖静态检查确认 road-outer/inner/dash/hit/road/place 均已在 CSS 定义；`.road-line` 全库无残留。
- 经验：export-image.js 的注释早已记录过同一坑（SVG 默认 fill=black，fill:none 必须显式覆盖）；本项目 JS 模板类名与 CSS 是契约关系，改动渲染结构务必同步检查 CSS 覆盖。

## 新增：预览/游戏中非高亮地点半灰度化
- 需求：编辑器预览模式与进入连接后的游戏中，非高亮地点半灰度化。
- 实现：纯 CSS 补缺——JS 早已动态加类（game.js renderRoute 加 `idle`，editor.js 预览渲染加 `dim`），但 CSS 一直没有对应规则，效果为空转。
  - `base.css`：新增 `.place.idle { opacity:.5; filter:grayscale(1) }`，并给 `.place` 加 `transition: opacity .3s, filter .3s`（游戏侧类切换发生在持久元素上，可平滑过渡）。
  - `editor.css`：新增 `.edit-place.dim` 同款规则（编辑器每次全量重渲染，过渡无意义故不加）。
  - `docs/开发文档.md`：扩展说明补记 idle / selected / neighbor / dim 状态类。
- 视觉约定：非高亮 = 全彩的其余地点保持原色即高亮；selected/neighbor 不设显式样式（全彩即高亮），与灰度化其余形成对比。
- 校验：jsdom 冒烟测试 17 项全过（内联 CSS/JS、MouseEvent 带 clientX、按 world transform 反算屏幕坐标派发指针事件、elementFromPoint 打桩）；预览模式 dim 地点 2/道路 6，游戏初始 available 4/idle 2，走一步后 idle 2→3、道路 active 0→1。
- 坑：jsdom 校验脚本里 `new Event()` 不带 clientX/clientY（须用 MouseEvent）；`cat <<'EOF'` 经 Git Bash 会吞正则反斜杠，脚本改用 Write 工具落盘再执行。
