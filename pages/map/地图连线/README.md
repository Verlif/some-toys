# 城市地图 · 编辑器 + 路线

> 自己画一座城，再沿着自己画的路走一圈。

一个「编辑地图 → 连线成路 → 规划闭环路线」的小工具：在画布上摆地点、连道路、随手改配色与图标，然后从「家」出发，依次点选相邻地点，绕回起点完成一圈。

纯前端、零依赖，脚本用经典 `<script>` 加载（不是 ES Module），所以**双击 `index.html` 就能用**，离线也没问题。

---

## 快速开始

**方式 A：直接双击** `index.html`（导入导出、自动保存都正常工作）。

**方式 B：本地服务器**（想用 `http://` 访问时）：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 编辑器怎么用

界面分两个屏幕，底部「开始游戏」按钮切换。

### 三种模式

| 模式 | 操作 |
| --- | --- |
| 📍 放置 | 点击空白处新增地点（离已有地点太近会被忽略） |
| 🔗 连线 | 先点一个地点作起点（高亮），再点另一个地点连成道路；再点起点可取消 |
| 🗑️ 删除 | 点击地点或道路删除 |

### 编辑细节

- **双击**地点打开编辑框：改图标（任意字符 / emoji）、改名称、删除地点。新建地点后自动弹出。
- **长按**地点进入拖动模式，相连道路实时跟随。
- **拖动空白处**平移地图，**滚轮 / 双指捏合**缩放，顶部提示条会随模式给出指引。

### 底部操作区

| 按钮 | 作用 |
| --- | --- |
| ↶ 撤回 | 撤销上一步（放置 / 连线 / 删除 / 移动都可撤销） |
| 清空 | 清空整张地图 |
| 加载示例 | 一键载入内置示例地图 |
| ⬇ 导出 JSON | 下载 `map-<时间戳>.json` |
| ⬆ 导入 JSON | 选择文件，或直接把 `.json` 拖进窗口 |
| 🖼 导出图片 | 按所有地点计算边界导出 PNG，四周留约 80px 白边，地点大小统一归一化 |
| 开始游戏 | 至少 2 个地点、1 条道路时可用 |

编辑器会**自动把地图存进 localStorage**，刷新或重开都会恢复。

## 路线游戏怎么玩

1. 进入后**起点（家）**已选中，路径面板显示已走步数。
2. 点与当前地点**有道路相连**的地点前进，可走项会有蓝色高亮。
3. 点路径中的**上一个地点**即可回退一步。
4. 走过至少 3 个不同地点后，点**起点（家）**完成闭环，地图与面板变绿。
5. 右侧 `+` / `−` / `⊙` 缩放、复位；底部「清空重来」重新开始。
6. 底部面板右上角的**导出图片**会按当前画布所见即所得导出（含已走路线与高亮）。

缩得很小时地点名称会自动隐藏，避免拥挤。

## 数据格式

导出的 JSON 字段稳定，可以自己写脚本生成后再导入：

```json
{
  "version": 1,
  "places": [
    { "id": 1, "x": 700, "y": 520, "icon": "🏠", "name": "家", "color": "#e88b3a" }
  ],
  "edges": [[1, 2], [1, 4]]
}
```

- `places`：地点数组，`x/y` 是**世界坐标**，与屏幕像素无关。
- `edges`：道路数组，每项是两个地点 id 的无序对（A-B 与 B-A 视为同一条）。

## 目录结构

```
index.html            入口：DOM 与 SVG defs，按顺序引入 css/js
css/
├─ variables.css      主题变量（配色 / 字体 / 圆角 / 阴影）
├─ base.css           重置、应用外壳、道路与地点共享样式
├─ editor.css         编辑器 UI：模式栏、提示条、底部操作、地点编辑框
├─ game.css           游戏 UI：标题、缩放控件、路线面板、路径链
└─ responsive.css     平板 / 桌面卡 / 横屏压缩 / 粗指针适配
js/
├─ config.js          预设图标、示例地图、阈值与限制
├─ utils.js           选择器、夹取、哈希、贝塞尔路径、转义
├─ viewport.js        平移缩放变换（编辑器与游戏共用）
├─ storage.js         JSON 导出 / 读取 / localStorage
├─ editor.js          放置 / 连线 / 删除 / 拖动 / 撤回 / 导入导出
├─ game.js            路线规则、渲染与提示
└─ main.js            引导、屏幕切换、开始游戏、resize
docs/
├─ 使用说明.md
└─ 开发文档.md
```

模块挂在全局命名空间 `window.App` 上，按依赖顺序加载：
`config → utils → viewport → storage → editor → game → main`。

## 实现要点

- **道路是弯的**：两端点中点沿法线偏移生成两段三次贝塞尔，偏移方向由 id 哈希决定（确定性），偏移量取 `min(长度 × 0.13, 60)`——避免正反向两条边重叠，也让直角连线更像「路」。
- **视口变换**：世界层 `translate + scale`，地点额外施加补偿缩放 `clamp(1/scale^0.8, 0.5, 3.6)`，缩放时地点视觉大小基本恒定。
- **手势判定**：位移超过 10px 算拖动，按住 480ms 未移动进入长按拖动，两次点击间隔 < 280ms 算双击。
- **闭环判定**：`tryConnect` 里先查邻接表，点起点且已走过 ≥3 个不同地点才算完成。
- **无第三方依赖**：没有 CDN、没有构建步骤，图形全部是 SVG + DOM。
