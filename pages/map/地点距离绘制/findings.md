# 发现与决策

## 需求
- 地图数据按浏览器分别保存，并可命名。
- 当前地图名位于左上角，点击编辑，失焦时保存。
- 右下角“加载历史”列出本地所有地图，支持创建、加载、重命名、删除。
- 删除需二次确认，确认框显示对应地图预览。
- 当前地图编辑内容自动实时保存。

## 研究发现
- 当前版本只使用 `place-distance-drawing:v1` 保存单张地图对象，内容为 places、edges、nextId 和 cellDistance。
- `editor.js` 的 `render()` 是主要地图变更出口；拖动地点期间直接调用 `renderer.render()`，结束时才回到 editor render。
- 删除确认使用页面已有 `<dialog id="confirmDialog">`，可扩展预览图区域。
- 当前实际页面路径为 `pages/map/地点距离绘制`；其 `theme.css` 还残留 `user-select: none`，本次一并移除以遵守之前的要求。

## 技术决策
| 决策 | 理由 |
|------|------|
| 新增 `place-distance-drawing:library:v1` 保存 `{maps, activeMapId}` | 不覆盖旧单地图数据，并能迁移旧版本 |
| 地图记录包含 id/name/updatedAt 和完整地图数据 | 支持历史列表排序、命名与恢复 |
| 历史列表操作在编辑器中委托处理，存储细节收敛到 storage.js | 避免 UI 直接操作 localStorage |
| 预览 SVG 直接根据任意地图记录生成 | 不干扰当前正在编辑的地图 |
| 新建地图默认空白，并自动聚焦左上名称框 | 新地图不会误覆盖当前地图，名称可立即编辑 |

## 视觉/浏览器发现
- 当前页为多文件结构，操作区使用底部浮动按钮；“加载历史”可以放在右下角浮动入口，列表向上展开。
