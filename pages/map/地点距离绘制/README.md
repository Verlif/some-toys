# 地点距离绘制

> 在网格上摆地点，连起来，距离自己算。

一个用 Canvas 画「地点关系图」的小工具：在地图上放置地点、填写名称与图标、把需要的地点连成道路，每条道路会按「每格距离 × 格数」实时标出直线距离（米 / 千米自动切换）。

适合画通勤示意图、游戏地图、街区尺度草图——不需要 GIS，也不需要联网。

---

## 快速开始

经典 `<script>` 加载，不依赖服务器，**双击 `index.html` 即可使用**：

```bash
# 或者用本地服务器
python -m http.server 8080
```

手机 / 平板同样可用，界面会自动压缩成适配的布局。

## 功能

### 画图

| 操作 | 说明 |
| --- | --- |
| 放置地点 | 在网格上点击，弹出编辑框填写名称、图标（emoji / 任意字符）与颜色 |
| 连线 | 选两个地点生成道路，道路中间自动标注距离 |
| 拖动 | 拖动地点，相连道路实时跟随 |
| 删除 | 选中地点或道路后删除 |
| 撤回 | 撤销上一步操作 |
| 缩放 / 平移 | 滚轮或双指缩放，空白处拖动平移，`⊙` 一键复位视图 |
| 每格距离 | 顶部输入「每格距离」，整张图的距离标注随之换算 |

### 多地图与自动保存

- 左上角是**地图名称**，点击即可改名，失焦保存。
- 右下角「加载历史」列出浏览器里保存的所有地图，支持**新建 / 加载 / 重命名 / 删除**。
- 删除前有二次确认，确认框里会画出该地图的 **SVG 预览**，不会删错。
- 当前地图编辑内容**实时保存**（拖动时短暂节流，松手立即落盘）。

### 导入导出

- **导出 JSON**：完整地图数据（地点、道路、每格距离、名称）。
- **导入 JSON**：选文件或直接拖进窗口。
- **导出图片**：把当前画布导出为 PNG，所见即所得。
- **载入示例**：内置一张「家 / 工作室 / 咖啡馆 / 公园 / 书店」的示例地图。

### 其他

- 亮 / 暗两套主题，一键切换。
- 顶栏实时显示地点数与道路数。
- 所有操作都有 toast 提示，误删可撤回。

## 数据与存储

浏览器里用两个 key 分开存：

| key | 内容 |
| --- | --- |
| `place-distance-drawing:library:v1` | `{ maps, activeMapId }`，多地图库 |
| `place-distance-drawing:v1` | 旧版单地图数据，首次加载时自动迁移 |

地图数据结构：

```js
{
  places: [{ id, x, y, icon, name, color }],
  edges: [[fromId, toId]],
  nextId: 6,
  cellDistance: 100
}
```

`x / y` 是以格为单位的相对坐标，渲染时乘 `CELL_SIZE`（44px）映射到画布，所以换设备、换缩放距离都不变。

## 目录结构

```
index.html            入口 + 全部界面骨架（顶部栏 / 画布 / 浮动操作 / 弹窗）
css/
├─ theme.css          主题变量与基础排版
├─ layout.css         顶栏、画布、浮动按钮布局
├─ map.css            画布内的地点、道路、标注样式（含预览图）
└─ responsive.css     手机 / 平板 / 横屏适配
js/
├─ config.js          每格大小、缩放范围、配色、示例地图
├─ renderer.js        画布渲染：网格、地点、道路、距离标注、命中检测
├─ storage.js         多地图库、旧数据迁移、节流保存
├─ export-image.js    PNG 导出
├─ theme.js           亮暗主题切换
├─ editor.js          放置 / 连线 / 拖动 / 删除 / 撤回 / 编辑弹窗
└─ main.js            引导与事件装配
```

脚本用 IIFE 挂到 `window.DistanceDrawing` 上，按 `config → renderer → storage → export-image → theme → editor → main` 顺序加载。

## 实现要点

- **距离标注**：`hypot(dx, dy) / CELL_SIZE × 每格距离`，≥1000 米显示 km（保留 1~2 位小数并去掉尾零），否则显示整米。
- **坐标与缩放分离**：地点存世界坐标，视图变换（平移 + 缩放 + 高 DPI）只作用于绘制，导出的 PNG 与屏幕所见一致。
- **实时保存不能卡**：拖拽过程中不写 localStorage，松手或停顿后再落盘。
- **预览不影响当前编辑**：删除确认框里的缩略图直接用目标地图数据另起一份渲染，不切换当前画布状态。
- **纯 Canvas**：没有图形库，命中检测用图形包围盒与线段距离自己算。

## 已知取舍

- 距离是**直线距离**，不计算绕行路径长度。
- 地图数据存在浏览器本地，换设备 / 清缓存会丢，重要地图请导出 JSON 备份。
