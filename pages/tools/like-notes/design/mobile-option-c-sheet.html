方案 C · 底部工作表

单手操作优先
布局
编辑区始终常驻；文件树与大纲合并在一个底部工作表中，顶栏两个图标分别打开对应标签；设置是更高一层的全屏工作表。
信息层级
编辑内容是主线程，辅助信息是临时浮层；圆角、拖拽柄与遮罩明确表达“临时唤出”。
交互
点图标或遮罩开合，工作表内切换文件/大纲标签；设置底部操作栏始终固定，符合你之前的要求。
取舍
单手可达性最好、动效最现代，但要新增工作表开合动画与手势区，JS/CSS 改动量最大。
