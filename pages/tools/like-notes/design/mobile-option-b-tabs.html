方案 B · 分段式单栏

实现成本最低
布局
顶栏下放三档分段控件，文件树、编辑器、大纲各自独占整屏；分栏模式在手机上变成上下堆叠。
信息层级
同一时刻只保留一个任务焦点，段落标题与当前文档标题最突出，减少窄屏上的信息竞争。
交互
点击分段即可切换；新建用右下角悬浮按钮；设置仍为全屏弹窗、底部固定操作栏。
取舍
JS 改动最小（主要靠 CSS 控制显示），但文件与编辑不能同屏，来回切换成本略高。
设置
更改即时生效并保存在本地。令牌仅保存在此浏览器，不会上传到第三方服务器。
