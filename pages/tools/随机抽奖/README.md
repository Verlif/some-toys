# 随机抽奖系统

> 名单丢进去，剩下的交给动画。

一个带权重、滚动动画与历史统计的抽奖小工具。适合年会抽奖、课堂点名、直播抽选——打开就能用，数据存在浏览器本地。

纯前端、零依赖、原生 ES Module，拆成模块化的小文件。

---

## 快速开始

ES Module 需要 HTTP 环境：

```bash
# 项目目录下
npx --yes serve .
python -m http.server 8080
```

也可以从仓库根目录的导航页点进来。

## 功能

### 项目与权重

- 输入内容 + 权重（正整数）添加项目；内容为空或权重非法会被忽略。
- 权重越大，在抽奖池里出现的次数越多，中奖概率越高。
- 列表里可以直接调整权重、删除单项。
- 首次打开会填三条示例数据，删掉即可开始正式使用。

### 抽奖

| 操作 | 说明 |
| --- | --- |
| 开始 | 右侧滚轮开始滚动，点「停止」定住结果 |
| 连抽 | 「开始」右侧的下拉可选 3 / 5 / 10 / 20 / 50 / 100 次，逐个出结果 |
| 速度 | 1–8 档，数字越大滚动越快，设置会记住 |
| 点滚动区 | 也可以直接点击滚动区开始 / 继续 |

结果区会同时显示**最近一次结果**与**历史上最常抽中**的项目（并列时全部列出）。

### 历史记录

- 每次结果都会入库，记录内容与时间。
- 支持两种排序：按时间、按出现次数。
- 可单条删除，也可清空全部（会二次确认）。

### 配置管理

- 「保存配置」把当前名单与权重存成一份命名配置。
- 「读取配置」列出本地所有配置，可加载或删除。
- 临时状态（名单、历史、速度）自动保存在 `localStorage` 的 `drawAppState`，刷新不丢。

### 其他

- 亮 / 暗主题切换，选择会记住。
- 响应式布局，手机竖屏也能正常抽。

## 目录结构

```
index.html            页面骨架：添加表单 / 结果 / 操作 / 历史 / 滚动舞台
css/
├─ base/              reset、主题变量、响应式
├─ components/        按钮、下拉、表单、列表、历史、结果、弹窗、滚动舞台
├─ layout/            页头与整体布局
└─ main.css           汇总入口
js/
├─ core/              dom 缓存、全局 state、localStorage 读写
├─ modules/           items、scroll、history、result、config-panel、modal、theme
├─ utils/             array（洗牌）、debounce、stats（最常抽中）
└─ main.js            装配模块、绑定事件、启动
```

依赖方向单一：`utils → core → modules → main`，没有环形引用。

## 实现要点

- **加权池**：项目按权重展开成一个数组（`weighted`），抽奖时从池里等概率取——权重逻辑就变成了一次数组取样。
- **滚动是动画不是概率**：轨道由打乱后的池重复铺满 20 份，动画按速度滚动到某个位置停下，落点对应的项目就是结果；概率已由池的构成决定。
- **状态集中**：所有可变数据在 `state.js`，持久化只在 `storage.js`，界面模块不直接碰 `localStorage`。
- **纯函数统计**：`utils/stats.js` 只根据历史算出「并列第一」，避免 result 与 history 互相依赖。
- **下拉交互**：悬停展开、移开 180ms 收起，跨过按钮与面板之间的间隙不会闪退。

## 数据

```js
// localStorage['drawAppState']
{ items: [{ content, weight }], history: [{ result, timestamp }], scrollSpeed: 3 }

// localStorage['drawConfig_<名称>']
{ items: [{ content, weight }] }
```

换设备或清缓存会丢数据，重要名单建议保存成命名配置后再导出备份。
