# 图片主题色替换

> 提取一张图的主色，然后一个颜色一个颜色地换掉。

一个纯前端的图片换色工具，适合改主题色、统一配色、批量看「换个色调会怎样」。选图后自动抽取最多 10 个主色，每个主色都能单独指定新颜色，配合容差与「合并相近颜色」，相近像素会跟着一起替换。

全程在浏览器本地完成，图片不会上传到任何服务器。

---

## 快速开始

双击 `index.html` 即可（经典 `<script>` 加载，不依赖服务器）。

想用 `http://` 访问也可以：

```bash
python -m http.server 8080
```

## 用法

### 1. 载入图片

三种方式，随便挑一种：

- 点击上传区选择文件；
- 把图片直接**拖拽**进页面；
- 复制图片后 `Ctrl / ⌘ + V` 粘贴。

### 2. 调主色

右侧「主要颜色」是从图里抽出来的色板（最多 10 色，按像素数排序，会显示占比）：

| 操作 | 说明 |
| --- | --- |
| 改色 | 点色块上的颜色选择器，选一个替换后的颜色 |
| 重置单色 | 单个颜色恢复原色，不影响其它 |
| 屏蔽颜色 | 该颜色不参与替换（保留原样） |
| 重置全部 | 一键回到初始状态 |
| 点击找色 | 在画布上单击某个像素，自动定位并高亮它所属的色板条目 |

### 3. 调容差与合并

| 参数 | 说明 |
| --- | --- |
| 容差范围（0–255） | 按 **RGB 单通道差值**计算。0 = 只替换完全相同的颜色，数值越大，越多相近颜色被一起换掉 |
| 合并相近颜色 | 把容差内相邻的主色合并成一组处理，色板更干净，改动也更统一 |

容差是全局参数，松开滑块才会刷新色板，避免拖动过程中反复重算。

### 4. 看效果、存结果

- 左右两个画布：原图 / 预览效果，各自支持**滚轮缩放、拖拽平移、双击复位**。
- 「像素预览」开关：放大查看时保持像素硬边，方便检查锯齿与边缘残留。
- 右下角显示本次处理**耗时**与颜色数量。
- 「下载图片」导出 PNG，文件名带尺寸：`换色-1920x1080.png`。

### 5. 其他

- 中文 / English 双语切换，亮 / 暗主题切换，都会记住选择。
- 「更换图片」不用刷新页面，直接换一张继续调。

## 实现要点

- **主色提取**：先把每个像素按 RGB 高 4 位分箱统计（16³ 个桶），桶内求平均色；再按欧氏距离预合并相近色，最后按像素数排序取前 10。比逐像素聚类快得多，10 万像素量级几乎无感。
- **替换判定**：对每个像素，遍历色板求「单通道差值最大值 ≤ 容差」的颜色，命中就替换成目标色；被屏蔽的颜色跳过。复杂度 O(像素 × 色数)，色数上限 10，足够实时。
- **大图保护**：处理画布边长上限 1400px，超出等比缩小，避免移动端内存爆掉。
- **缩放与取色**：视图变换单独保存，像素坐标由屏幕坐标反算，缩放平移后单击找色依然准确。
- **主题不闪**：首屏内联脚本先落 `data-theme`，再加载样式与模块。

## 已知取舍

- 输出尺寸跟随处理画布（≤1400px 长边），不会导出原始超大分辨率。
- 容差按单通道差值判定，不做感知色差（Lab / ΔE）匹配，极端渐变图上可能略显生硬。
