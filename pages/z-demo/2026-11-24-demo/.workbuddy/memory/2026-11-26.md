# 2026-11-26

## 五行卡牌战斗 demo：生克结算 + 灵力重铸
- `src/core/rules.js` 新增 `resolvePayment`：基于原始支付同时结算相生（生方点数加给被生方）与相克（克方点数削减被克方，下限 0），取唯一最高值为技能附着属性，并列则无属性。
- 词条判定改为使用结算后点数与生克事件：`contains`/`attribute` 看附着属性，`shengAny`/`keAny`/`shengPair`/`kePair` 看实际发生的生克事件，修复了"三种属性必然双触发"的问题。
- `src/core/game.js` 新增灵力：上限/初始 100，每回合 +15，重铸花 20 且每回合限一次；重铸随机生成本回合 10 点五行（不改变局外分配）。出牌日志展示支付→生克后点数→附着属性→生克事件。
- UI 增加灵力条、重铸按钮、生克后点数与附着属性预览；设置页补充规则提示。
- 已通过语法检查、规则单测（2金1水→2金3水、并列无属性、相克削减）与视图渲染检查。
- 用户采用的默认解释：生克同时基于原始支付结算；灵力百分比按最大值计算；重铸只影响当前回合点数。

## 敌方属性与伤害克制
- 敌方开局随机获得一个五行属性（整场固定）。技能附着属性克制敌方时，该牌全部伤害 ×1.5；否则（含无属性）×0.5。用 `Math.round` 取整，在护盾抵扣前计算；敌方打玩家不受此倍率影响。
- `rules.js` 新增 `counteredBy` / `damageModifier`；`game.js` 在出牌时计算倍率并传入 `applyEffects`，日志记录判定与倍率；敌方面板显示属性及受克属性，支付区实时预览倍率。
- README 新增「敌方属性与伤害克制」章节并调整后续编号。测试验证：8→12（克制）、8→4（未克制）、6→3（无属性）。
