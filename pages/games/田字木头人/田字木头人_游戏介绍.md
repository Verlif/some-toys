# 木头人 · 游戏介绍

> 「他写字的时候，往前走；他回头的时候，不许动。」
>
> 一款紧张刺激的「回头抓人」小游戏。你可以是背对众人在黑板上写字的**写字人**，
> 也可以是悄悄靠近的**木头人**——当写字人回头时，木头人必须立刻停下，动了就输。

---

## ✨ 游戏特色

- **多种模式**：单人挑战 AI、双人本地对战、最多 8 名木头人混战。
- **主动出击**：木头人可以制造声响，把写字人惊得回头——逼他再吃一次 -3 秒。
- **智能 AI**：AI 写字人会根据距离、剩余时间、你的移动状态综合判断何时回头；
  AI 木头人会预判暂停，回头时也有一小段反应时间——它也可能刹车不及。
- **公平开局**：所有木头人站在同一起点，3-2-1 倒计时后同时行动。
- **时间压力**：写字人只有 50 秒，每次回头还要扣 3 秒，节奏紧凑。
- **完整结算**：每局结束展示时长、完成笔画、回头次数等详细数据。
- **触屏支持**：手机、平板直接游玩，无需下载。

## 🕹️ 游戏模式

| 模式 | 说明 |
| --- | --- |
| 你是木头人 · AI 写字 | 单人。你靠近 AI 写字人，AI 会随时回头。 |
| 你是写字人 · AI 木头人 | 单人。你按住按键写「田」字，松开回头抓 AI。 |
| P1 写字人 · P2 木头人 | 双人。P1 写字，P2 靠近。 |
| P1 木头人 · P2 写字人 | 双人。P2 写字，P1 靠近。 |
| P1 + P2 双木头人 vs AI | 双人合作。两人同时靠近 AI，先摸到者胜。 |

每种模式都可在页面底部选择木头人总数：**1 / 2 / 4 / 8**（独行 / 成双 / 结队 / 成群）。
人数不足时由 AI 补齐——一群木头人里混着几个不要命的 AI，反而更难预判。

## ⌨️ 操作方式

### 键盘

| 角色 | 操作 | 按键 |
| --- | --- | --- |
| 木头人 P1 | 靠近 | `A` `D` 或 `←` `→` |
| 木头人 P1 | 制造声响 | `W` |
| 木头人 P2 | 靠近 | `←` `→` |
| 木头人 P2 | 制造声响 | `↑` |
| 写字人 P1 | 写字（按住） | `空格` |
| 写字人 P2 | 写字（按住） | `↑` 或 `↓` |
| 通用 | 暂停 / 继续 | `ESC` |

> 写字人的逻辑是「**按住 = 写字，松开 = 回头**」。想抓人就松手，想抢时间就按住。
> 「制造声响」只有木头人能用，且只有轮到人类操作的角色才有对应按键。

### 触屏

屏幕下方会出现虚拟按钮，只有轮到人类操作的角色才显示对应按钮：

- **左侧按钮**：P1 移动
- **右侧按钮**：P2 移动
- **中间按钮**：按住写字
- **左右上方小按钮**：制造声响（P1 / P2）

## 📜 游戏规则

- **木头人目标**：在写字人写完「田」字前，摸到他的后背。
- **写字人目标**：写完「田」字，或抓住所有木头人。
- **回头机制**：写字人回头时，正在移动的木头人被抓；静止不动的人安全。
- **制造声响**：木头人按下声响键惊扰写字人，写字人会被吓得回头一次（再 -3 秒），冷却 6 秒。
- **时间限制**：写字人总时长 50 秒，每次回头扣 3 秒，时间耗尽则木头人胜利。
- **同一起点**：所有木头人从同一起跑线出发，3-2-1 倒计时后开始行动。

**胜负一览**

| 条件          | 结果   |
|-------------|------|
| 木头人摸到写字人的后背 | 木头人胜 |
| 写字人写完「田」字   | 写字人胜 |
| 写字人时间耗尽     | 木头人胜 |
| 所有木头人都被抓住   | 写字人胜 |

## 🧠 小技巧

**当木头人**

- 别一路按住不放。写字人回头的瞬间，你还在滑行的那几十毫秒就是致命的。
- 观察笔画进度：一画快写完时是回头高发期，AI 尤其喜欢这时候转过来。
- 人多时别当出头鸟，让 AI 先冲，你跟在后面捡便宜。
- 逼他多回头几次——回头一次 -3 秒，时间自然就不够了。
- 声响键要**站定了再按**：他会在 0.1 秒内转过来，你还在往前挪就是送人头。
- 冷却 6 秒，一整局也就七八次。留到他快写完最后一笔时甩出去最值。

**当写字人**

- 每回头一次丢 3 秒，而整局只有 50 秒，回头四次等于白送。
- 画面边缘的红色暗角越浓，说明你已经回头很久了，该转回去写字了。
- 进度过 75% 时尽量别回头，一口气写完最稳。
- 但有人贴到脸上了就必须回头，否则下一秒就是他的手。
- 屏幕跳出「身后有动静」说明有人故意弄出声响。别慌着回头——先数一数还有几个在动，一口气全抓了才划算。

## 🚀 如何开始

游戏由多个 ES Module 组成，需要通过 HTTP 打开（浏览器不允许 `file://` 加载模块）：

```bash
# 在仓库根目录执行，任选一种
npx serve
python -m http.server 8000
```

然后访问 `http://localhost:8000/pages/games/田子木头人/index.html`，
点击「开始游戏」→ 选择模式与木头人数量 → 开玩。游戏中按 `ESC` 暂停。

## 📊 结算数据

每局结束后显示：

- 游戏时长
- 完成笔画数（0 ~ 5）
- 回头次数
- 剩余时间
- 制造声响次数
- 木头人被抓住数量 / 总数量

## 🛠️ 技术信息

- 纯 HTML + CSS + JavaScript（原生 ES Module），**无外部依赖、无构建步骤**。
- Canvas 2D 渲染，Web Audio 实时合成音效，不加载任何音频文件。
- 逻辑分辨率 1440 × 560，等比缩放自动适配任意窗口。
- 架构、常量表与扩展方式见《田子木头人_开发文档》。
