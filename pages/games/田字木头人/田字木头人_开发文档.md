# 木头人 · 开发文档

> 黑板前的回头博弈：写字人背身写「田」，木头人趁他不注意摸到后背就赢。
> 原生 HTML + CSS + JavaScript（ES Module），零依赖、零构建。

---

## 1. 概览

| 项目 | 说明 |
| --- | --- |
| 技术栈 | HTML5 Canvas 2D + 原生 ES Module，无框架、无第三方库、无构建步骤 |
| 入口 | `index.html` |
| 逻辑分辨率 | 1440 × 560（等比缩放居中，适配任意窗口） |
| 适配 | 桌面键盘 + 移动端触屏虚拟按钮 |
| 音效 | Web Audio API 实时合成，不含任何音频文件 |

### 运行方式

因为是原生 ES Module，**必须通过 HTTP 打开**（浏览器的 CORS 策略禁止 `file://` 加载模块）：

```bash
# 任选一种，在仓库根目录执行
npx serve
python -m http.server 8000
```

然后访问 <http://localhost:8000/pages/games/田子木头人/index.html>。

> 仓库根目录的 `generate-index.js` 会把本目录收进 `index.html` 导航页；
> 导航页与游戏同源，直接点进去即可。

## 3. 分层与依赖规则

**只允许向下依赖，不允许循环引用**：

```
        main.js
           │
   ┌───────┼────────┬─────────┐
   ▼       ▼        ▼         ▼
  ui/   render/   game/    input/   ──►  core/
   │        │       │         │
   └────────┴───────┴─────────┘
        （都只读 game/state.js 的 world）

core/   ── 基础设施，不依赖任何上层
input/  ── 键鼠触屏 → 语义；ESC 通过回调注入，避免反向依赖 ui/
game/   ── 规则与推进；不碰 DOM（唯一例外：match.js 负责收起菜单）
render/ ── 只读 world，绝不写 world
ui/     ── DOM 与面板；调用 game/ 的 startGame 推进流程
```

三条硬约定：

1. **渲染层只读**。所有对世界的改写都发生在 `game/simulation.js` 的 `update(dt)` 里。
2. **数值只在 `core/config.js`**。别处不得硬编码 50、3、62 这类魔数。
3. **无循环 import**。`input.js` 需要 ESC 时由 `main.js` 注入回调，而不是反过来 import `ui/flow.js`。

### world 的实时绑定

`game/state.js` 用 `export let world`。ES Module 的实时绑定保证任何模块 `import { world }` 后，
读到的都是 `setWorld()` 之后的最新值——不需要 getter，也不需要手写全局单例。
改写的唯一入口是 `setWorld()`。

## 4. 主循环与状态机

```js
function loop(now) {
  const dt = Math.min((now - lastTime) / 1000, 0.05);
  lastTime = now;
  update(dt);
  render();
  requestAnimationFrame(loop);
}
```

`dt` 夹在 **0.05 秒**以内：卡顿时宁可「慢放」，也不让木头人一帧跨过判定距离。

对局状态机：

```
菜单（world = null）
  └─ startGame(mode) ──► 倒计时（countdown 3 → 0，逻辑冻结）
                          └─► 对局（update 每帧推进）
                                ├─ 摸到后背  → 木头人胜
                                ├─ 写完「田」→ 写字人胜
                                ├─ 时间耗尽  → 木头人胜
                                └─ 全员被抓  → 写字人胜
                                      └─► 延迟 0.95s ──► 结算面板
```

### world 字段

| 字段 | 说明 |
| --- | --- |
| `mode` | 模式标识 |
| `active / paused / over` | 是否进行中 / 暂停 / 已结束 |
| `winner / reason` | 胜方（`'wolf'` / `'writer'`）与结束原因 |
| `overlayDelay` | 结束到弹结算的延迟（0.95 秒） |
| `time` | 对局已进行秒数（不含倒计时） |
| `wolves[]` / `writer` | 木头人数组 / 写字人对象 |
| `writerTimeLeft` | 写字人剩余时间 |
| `countdown / started` | 倒计时剩余 / 是否已开始 |
| `startFlash / shake / timeFlash` | 「开始！」闪光 / 震屏 / 扣时闪红 |
| `floatTexts[]` | 飘字（-3s） |
| `stats` | `looks` 回头次数、`strokesDone`、`wolvesCaught`、`wolvesTotal`、`noises` 声响次数 |

## 6. 输入映射（`input/input.js`）

| 模式 | 写字人 | 木头人靠近 | 木头人制造声响 |
| --- | --- | --- | --- |
| 你是木头人（AI 写字） | — AI — | `A` `D` 或 `←` `→` | `W` |
| 你是写字人（AI 木头人） | 按住 `空格` 或 `↑` `↓` | — AI — | — AI — |
| P1 写字 · P2 木头人 | P1 按住 `空格` | P2 用 `←` `→` | P2 用 `↑` |
| P1 木头人 · P2 写字人 | P2 按住 `↑` 或 `↓` | P1 用 `A` `D` | P1 用 `W` |
| 双木头人 vs AI | — AI — | P1：`A` `D`；P2：`←` `→` | P1：`W`；P2：`↑` |

- `ESC`：暂停 / 继续（`main.js` 注入给 `input/keyboard.js`）。
- 触屏：左下 P1、右下 P2、中间「按住写字」，只在对应角色是人类时显示。
- 暂停、开局、窗口失焦都会清空按键状态，避免「攒着」一个前进指令。

## 7. 核心算法

### 7.1 「田」字绘制

五画用归一化坐标描述，绘制时乘 `CHAR_SIZE` 映射到黑板内板：

```js
const STROKES = [
  [[0.14,0.10],[0.14,0.90]],                 // 左竖
  [[0.14,0.10],[0.86,0.10],[0.86,0.90]],     // 横折
  [[0.14,0.50],[0.86,0.50]],                 // 中横
  [[0.50,0.10],[0.50,0.90]],                 // 中竖
  [[0.14,0.90],[0.86,0.90]]                  // 下横
];
```

`writer.writeProgress` 是 `0 ~ 5` 的浮点数：整数部分是已完成笔画数，小数部分是当前笔画进度。
`drawChalk()` 逐笔画完整笔 + 当前笔的部分；`getChalkPos()` 用 `strokePointAt()` 求出笔尖坐标，
写字人的手就跟着笔尖走（`drawWriter` 里按 `facing` 在「笔尖」和「身侧」之间插值）。

### 7.2 AI 写字人决策（`game/writer.js`）

不是固定间隔随机回头，而是每帧算一次「回头期望概率」：

```
危险度 danger = 距离因子 clamp((700 - (最近距离 - MIN_DIST)) / 700, 0, 1)
              + 最近的木头人在移动 ? 0.18 : 0
              + 其他木头人在移动 ? 0.08 : 0

回头率 lookRate = 0.12 + danger × 0.85
若最近距离 < MIN_DIST + 150           → lookRate += 0.6（贴脸了必须看）
× (1 - 时间压力 × 0.4)                 （时间越少越舍不得回头，回头要 -3 秒）
若进度 > 75%                           → × 0.55（快写完了优先写完）

if (random() < lookRate × dt) 回头，持续 0.5 + danger × 0.7 + random(0, 0.3) 秒
```

转回去的条件：回头时长超过上限（+0.8 秒），或已过最短时长且所有木头人都停住了。

### 7.3 AI 木头人行为（`game/wolf.js`）

- **预判暂停**：写字人背对时，若当前笔画进度处于 `0.72 ~ 1`，每秒有约 1.8 次概率触发
  0.35 ~ 0.95 秒的暂停——模拟「感觉他快回头了，先停」。
- **回头反应**：写字人回头瞬间不立刻定住，而是带着 `0.12 ~ 0.46` 秒的反应时间继续以
  55% 速度滑行；反应结束时若对方仍在看（`looking === true`），判定被抓。
- **贴身上限**：最多贴到 `WRITER_X + MIN_DIST`，不会站进写字人身体里。

### 7.4 回头惩罚（`game/simulation.js`）

`update` 比较本帧前后的 `writer.writing`，捕获「写字 → 回头」这一瞬间：

```js
world.writerTimeLeft -= LOOK_PENALTY;   // -3 秒
world.stats.looks++;
world.timeFlash = 1;                    // 时间条闪红
world.floatTexts.push({ text: '-3s' }); // 飘字
```

人类玩家的 `LOOK_GRACE`（0.3 秒）是宽限：刚回头的 0.3 秒内不算「看见」，
给人类留出反应时间，避免松手瞬间就把贴脸的人判死。

### 7.5 制造声响（`game/wolf.js`）

木头人主动惊扰写字人，把「逼他回头」从被动等待变成主动操作。

**触发**：`updateHumanWolf` 里用 `noiseHeld` 做边沿检测——按下瞬间才触发，按住不重复：

```js
const noiseHeld = isNoisePressed(wolf);
if (noiseHeld && !wolf.noiseHeld && wolf.noiseCd <= 0) triggerNoise(wolf);
wolf.noiseHeld = noiseHeld;
```

**效果**（`triggerNoise`）：

```js
wolf.noiseCd     = NOISE_COOLDOWN;      // 6 秒冷却
world.writer.alertTimer = NOISE_ALERT;  // 写字人进入「警觉」
```

- **AI 写字人**：`updateAIWriterDecision` 里 `lookRate += NOISE_LOOK_RATE × (alertTimer / NOISE_ALERT)`，
  约 7.5 次/秒 → 实测 **0.1 秒左右必定回头**，再吃一次 -3 秒。
  这次回头是「惊鸿一瞥」：`aiLookDur = 0.5 + random() × 0.3`，比平时短，
  免得把木头人也一起冻太久。回头发生后 `alertTimer` 立刻清零——**一次声响只惊一次**。
- **人类写字人**：不做任何自动判定，只在 HUD 上闪「身后有动静！」（`hud.js` 的 `drawNoiseHint`），
  回不回头由他自己决定，双方都保留操作空间。

**平衡取舍**：发声后写字人马上会转过来，这时还在往前挪的木头人会被抓——
所以正确用法是「先站定，再按」。冷却 6 秒限制了全局次数，实测一局约 7~8 次。

**表现层**：`characters.js` 的 `drawNoiseGauge` 在人类木头人头顶画冷却环（就绪时呼吸闪烁），
`drawNoiseWave` 画三圈朝左扩散的声波；`hud.js` 飘一个「咚！」。

## 8. 渲染与视口

`render()` 的绘制顺序（越靠后越上层）：

1. 背景（墙面、踢脚线、地面）
2. 黑板
3. 粉笔字「田」（仅对局中）
4. 写字人
5. 起点虚线（仅倒计时阶段）
6. 所有木头人
7. 危险暗角（写字人回头时红色渐变）
8. HUD：时间条 → 飘字 → 321 倒计时 → 「开始！」闪光

**视口适配**：`core/viewport.js` 按 `devicePixelRatio`（上限 2）设置画布实际像素，
再算出 `viewScale / viewOx / viewOy`，把逻辑坐标 **等比缩放并居中**，两侧留黑边。
游戏内所有坐标都是逻辑坐标，渲染层不用关心窗口大小。

## 9. 音效（`core/audio.js`）

全部用振荡器实时合成，无音频文件：

| 函数 | 场景 |
| --- | --- |
| `sfxCatch` | 木头人被抓 |
| `sfxWriterWin / sfxWolfWin` | 写字人胜 / 木头人胜 |
| `sfxPenalty` | 回头扣 3 秒 |
| `sfxNoise` | 木头人制造声响（闷响） |
| `sfxTimeUp` | 时间耗尽 |
| `sfxCountdown(n)` | 3 / 2 / 1 与开始的提示音 |

浏览器要求用户手势后才能播放，因此 `initAudio()` 在**点「开始游戏」**与**触屏按下**时调用。

## 11. 已知事项

- **必须用 HTTP 打开**：ES Module 在 `file://` 下会被 CORS 拦截，直接双击 `index.html` 会白屏。
- 触屏按钮原先在开局后不显示（开始页把容器设为 `display:none` 后没有恢复），
  现已改为由 `input/touch.js` 的 `setTouchLayout(mode)` 按模式显示。
- 主循环是可变步长（`dt` 上限 0.05），没有做固定步长 + 插值；
  将来若要回放或联机锁步，建议先改造成固定步长模拟。
