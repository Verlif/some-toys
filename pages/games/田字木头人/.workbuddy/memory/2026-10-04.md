  - `render/` 只读 world；改写只发生在 `game/simulation.js` 的 `update(dt)`。
  - ESC 由 `main.js` 注入回调给 `input/keyboard.js`，避免 input → ui 反向依赖。

## 木头人：新增「制造声响」能力

- 需求：木头人主动制造声响惊扰写字人。P1 按 `W`，P2 按 `↑`；移动端各加一个小圆按钮。
- 按键无冲突：P1 声响 = `W`（P1 写字是空格），P2 声响 = `↑`（P2 写字才是 ↑/↓，而那时 P2 不是木头人）。
- 效果设计（平衡上踩过一次坑，记录）：
  - 第一版让 `alertTimer` 持续 1.6 秒不清零 → 一次声响连锁惊出 **3 次回头（-9 秒）**，太重。
    改为「一次声响只惊一次」：回头触发时若 `startled` 则立刻 `alertTimer = 0`。
  - 被惊动的那次回头是「惊鸿一瞥」：`aiLookDur = 0.5 + random()×0.3`，比平时短，
    否则木头人自己也跟着被冻太久，能力就没人用了。
  - 人类写字人不做自动判定，只给 HUD 提示（保留双方操作空间）。
  - 冷却 6 秒；实测一次声响 ≈ 0.1 秒内必定回头，一局约 7~8 次。
- 改动文件：`core/config.js`（NOISE_*）、`core/audio.js`（sfxNoise）、`input/input.js`（isNoisePressed）、
  `input/touch.js` + `index.html` + `css/touch.css`（声响按钮）、`game/entities.js`、`game/wolf.js`（triggerNoise）、
  `game/writer.js`（alertTimer 衰减 + lookRate 加成）、`render/characters.js`（冷却环 + 声波）、
  `render/hud.js`（drawNoiseHint）、`render/renderer.js`、`game/match.js`（stats.noises）、`ui/screens.js`（结算项 + 模式说明）。
- 两篇 md 文档已同步（操作表、规则、技巧、结算项、常量表、新增 7.5 节）。

## 冒烟脚本补记
