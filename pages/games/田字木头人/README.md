# 木头人 · 田字木头人

> 「他写字的时候，往前走；他回头的时候，不许动。」

一款「回头抓人」的实时小游戏。写字人背对众人，在黑板上写一个「田」字；木头人趁他背身时一点点靠近，摸到他的后背就赢。写字人每回一次头，都要付出 3 秒。

支持单人对抗 AI、本地双人对战，以及最多 8 名木头人的混战——人数不够时由 AI 补齐，一群木头人里混着几个不要命的 AI，反而更难预判。

---

## 快速开始

原生 ES Module，需要 HTTP 打开（浏览器禁止 `file://` 加载模块）：

```bash
# 项目目录下任选一种
npx --yes serve .
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。也可以从仓库根目录的导航页点进来。

手机、平板可以直接玩，触屏虚拟按钮会自动出现。

## 玩法

### 一局的流程

1. 选择模式与木头人总数（`1 / 2 / 4 / 8`）。
2. 3-2-1 倒计时后所有人同时出发，站在同一起点。
3. 写字人按住写字键，笔尖沿 5 画推进「田」字；木头人一点一点靠近。
4. 写字人回头时，所有**正在移动**的木头人被抓；已停下的木头人安全。
5. 木头人摸到写字人后背即获胜；写字人写完全部 5 画，或抓光所有木头人则获胜；时间耗尽算木头人赢。

写字人每回一次头 **−3 秒**，所以「回头看」既是防守也是成本。进度过半后，回头还会额外拖慢写字节奏。

### 五种模式

| 模式 | 说明 |
| --- | --- |
| 你是木头人 · AI 写字 | 单人。你靠近 AI 写字人，AI 会随时回头 |
| 你是写字人 · AI 木头人 | 单人。按住按键写「田」字，松开回头抓 AI |
| P1 写字人 · P2 木头人 | 双人对战 |
| P1 木头人 · P2 写字人 | 双人对战（换边） |
| P1 + P2 双木头人 vs AI | 双人合作，先摸到者胜 |

### 关键数值

| 项目 | 数值 |
| --- | --- |
| 写字总时长 | 50 秒 |
| 「田」字笔画 | 5 画，每画约 2 秒 |
| 回头惩罚 | −3 秒 |
| 人类回头宽限 | 0.3 秒（刚回头不判定） |
| 木头人最近距离上限 | 58 px（不会站进写字人身体） |
| 制造声响冷却 | 6 秒 |

## 操作

| 角色 | 操作 | 按键 |
| --- | --- | --- |
| 木头人 P1 | 靠近 / 制造声响 | `A` `D` 或 `←` `→` / `W` |
| 木头人 P2 | 靠近 / 制造声响 | `←` `→` / `↑` |
| 写字人 P1 | 写字（按住） | `空格` |
| 写字人 P2 | 写字（按住） | `↑` 或 `↓` |
| 通用 | 暂停 / 继续 | `Esc` |

**制造声响**是一次主动博弈：按下的瞬间，写字人立刻进入警觉，AI 写字人约 0.1 秒内就会回头。所以正确用法是「先站定，再按」——站着按只赚一次 −3 秒，边走边按就是把自己送上去。

---

## AI 在想什么

AI 不是按固定间隔随机回头，而是每帧算一次「回头期望概率」，综合距离、你在不在动、时间压力与书写进度：

- **离得越近越想回头**，贴脸时概率直接加 0.6；
- **有人在动就更警觉**（最近的 +0.18，其他 +0.08）；
- **时间越少越舍不得回头**（回头要扣 3 秒），但**快写完时优先写完**（进度 > 75% 概率 ×0.55）；
- 回头持续时长与危险度正相关，所有木头人都停住就提前转回去。

AI 木头人则有「预判暂停」：写字人当前笔画进度处于 0.72~1 时，它会以每秒约 1.8 次的频率突然停一下，像是在赌「他快回头了」。写字人回头看它的瞬间，它还有 0.12~0.46 秒反应时间以 55% 速度滑行——反应结束时若还在被看，就算被抓。

## 目录结构

```
index.html              入口（按顺序加载 ES Module）
css/                    base / menu / start / dialog / overlay / result / touch
js/
├─ core/                配置、工具、视口、合成音效
├─ game/                状态机、模拟推进、写字人、木头人、实体
├─ input/               键盘 / 触屏输入归一化
├─ render/              背景、黑板笔迹、角色、HUD
├─ ui/                  界面流程、遮罩、菜单
└─ main.js              装配 + 主循环
田字木头人_游戏介绍.md    面向玩家的介绍
田字木头人_开发文档.md    分层约定、算法细节、配置常量
```

几条实现要点：

- **逻辑分辨率固定 1440 × 560**，等比缩放居中，适配任意窗口比例。
- **音效实时合成**：全部走 Web Audio，仓库里没有任何音频文件。
- **笔迹是几何**：「田」字五画用归一化坐标描述，绘制时乘黑板尺寸；写字人的手跟着笔尖走。
- **配置唯一来源**：所有数值集中在 `js/core/config.js`。
