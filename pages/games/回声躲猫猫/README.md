# 回声躲猫猫 · Echo Hide & Seek

> 全黑的房间里，你唯一的信息来源是自己发出的声音。

一款纯前端的非对称对抗潜行游戏。世界一片漆黑，角色只能靠移动或主动发声产生的声波感知环境：声波在墙上反射，勾勒出地形轮廓，同时也把自己的位置卖给对手。

你可以扮演**搜捕者**，在限定时间内抓光所有躲藏者；也可以扮演**躲藏者**，在黑暗里苟到时间结束。单人模式对抗 AI，双人模式两人同阵营协作。

---

## 快速开始

原生 ES Module，**不能用 `file://` 直接双击打开**，需要静态服务器：

```bash
# 在项目目录下任选一种
npx --yes serve .
python -m http.server 8080
```

然后访问服务地址即可开始对局。也可以从仓库根目录的导航页点进来（同源，无需额外操作）。

## 怎么玩

### 双方目标

| 角色 | 默认数量 | 目标 | 特点 |
| --- | --- | --- | --- |
| 搜捕者 | 1（可调 1–3） | 在时间内抓住所有躲藏者 | 移速 ×1.12，声波能标记敌人 |
| 躲藏者 | 6（可调 3–10） | 至少一人存活到时间结束 | 只能靠静步与墙体遮蔽 |

- 搜捕者获胜：所有躲藏者被抓。
- 躲藏者获胜：时间耗尽时仍有至少一人存活。

### 声波是唯一的感官

| 行为 | 声波半径 | 射线数 | 代价 |
| --- | --- | --- | --- |
| 静步移动（每 0.5 秒） | 220 px | 8 | 速度减半，暴露范围小 |
| 快步移动（按住 Shift） | 440 px | 8 | 全速前进，等于开灯 |
| 主动噪声（空格 / Enter） | 660 px | 16 | 4 秒冷却，几乎等于自报坐标 |

声波以约 10 格/秒向前推进，遇到墙壁反射。墙体轮廓由**自己与同阵营队友**的声波共同点亮——分头探图时，队友跑出来的地形你同样看得见；敌人的声波不会给你任何地形信息。

### 几条容易忽略的规则

- **探测闪烁是双向的**：声波扫到角色时接触点会闪橙红，发射方和被打到的人都看得见。
- **近身即现形**：距离小于 3 格时双方互相显形，拐角撞见谁也装不了看不见；搜捕者之间则始终互相可见。
- **抓到人会僵直 2.5 秒**：搜捕者抓人后不能动也不能连抓（AI 搜捕者没有这个冷却）。
- **道具每 20 秒刷新一个**，全图可见，谁捡到谁受益，效果永远作用在**对方阵营**：

| 道具 | 效果 | 持续 |
| --- | --- | --- |
| 回响之眼 | 对方全体显形 | 1 秒 |
| 凝滞之锁 | 对方全体定格（不能动、不能抓人） | 2 秒 |
| 喧嚣之铃 | 对方全体立刻发出一次噪声（无视冷却） | 即时 |
| 疾行之羽 | 自己加速 ×1.6 | 5 秒 |

道具 30 秒后自动消失，刷新点会避开角色与已有道具 90px 以内。

### 开局设置

| 项目 | 选项 |
| --- | --- |
| 搜捕者数量 | 1 / 2 / 3 |
| 躲藏者数量 | 3 / 5 / 6 / 8 / 10 |
| 地图大小 | 小 / 中 / 大 |
| 游戏时长 | 30 秒 / 1 / 2 / 3 / 5 分钟 |

## 操作

| 操作 | 单人 | 玩家 1（双人） | 玩家 2（双人） |
| --- | --- | --- | --- |
| 移动 | `W` `A` `S` `D` / 方向键 | `W` `A` `S` `D` | 方向键 |
| 快步 | 按住 `Shift` | 左 `Shift` | 右 `Shift` |
| 主动噪声 | `空格` | `空格` | `Enter` |
| 暂停 / 继续 | `Esc` | `Esc` | `Esc` |
| 重新开始 | 连按两次 `R` | 同左 | 同左 |

双人模式的两位玩家扮演**同一角色**，各自拥有独立的噪声冷却；一人被抓、另一人仍存活时对局继续。

## AI 在做什么

- **搜捕者 AI**：巡逻 → 听见敌对声波后前往调查 → 记忆可疑区域 → 追击已确认目标；带视线平滑的寻路，不会贴着墙反复横跳。
- **躲藏者 AI**：远离搜捕者与噪声源，靠近墙体与角落，被追时向反方向逃离并寻找可切断视线的拐角。
- **敌我识别**：声波照常传播，但 AI 只把**敌对阵营**的声音当作情报，队友的噪声不会让它惊慌。
- **道具意识**：巡逻与休息时会把附近的道具当作临时目标。

AI 是吃配置的：`js/core/config.js` 里的 `SHARE_TEAM_VISION` / `SHARE_TEAM_WALL_MEMORY` 可以关掉队友视野与墙体共享，难度会明显上升。

## 工程结构

```
js/
├─ core/     配置、全局状态、事件、随机数、计时、队伍、视野判定
├─ world/    地图生成、实体、道具、格子碰撞、寻路
├─ sim/      规则推进：移动、碰撞解算、声波、战斗、道具效果、统计、录像回放
├─ ai/       搜捕者与躲藏者 AI
├─ input/    键盘输入 → 可序列化指令
├─ net/      会话 / 传输 / 协议 / 快照（WebSocket 联机预留）
├─ render/   渲染层：场景、视野、声波视觉
├─ ui/       HUD、面板、设置、结算、回放界面
└─ main.js   装配并驱动固定步长主循环
tests/       无头测试（DOM 桩，无需浏览器）
```

几条贯穿全局的设计：

- **模拟与界面解耦**：模拟层只吃「指令 + 固定步长」，不碰 DOM；界面只读快照。
- **可播种随机**：给定种子与指令序列，同一局必然复现，回放与测试都依赖这一点。
- **配置唯一来源**：所有可调数值集中在 `js/core/config.js`，其它模块不硬编码同类常量。

## 自检脚本

不需要浏览器，用 `tests/dom-stub.mjs` 把游戏直接跑在 Node 里：

```bash
# 碰撞手感：贴墙滑动 / 进通道 / 穿模 / 随机压力
node --experimental-default-type=module tests/collision.mjs

# 道具 + 联机会话（房主 / 客户端走回环传输）
node --experimental-default-type=module tests/features.mjs

# 端到端冒烟：倒计时 → 对局 → 道具 → 抓捕 → 结算 → 回放
node --experimental-default-type=module tests/smoke.mjs

# AI 行为测量：可见晃动 / 卡顿（局数 每局秒数 轨迹条数）
node --experimental-default-type=module tests/jitter.mjs 5 40 0
```

改完逻辑先跑一遍，比手点快得多。
