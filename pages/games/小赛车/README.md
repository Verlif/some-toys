# 双座漂移

> Canvas 赛车小游戏 · **惯性漂移** · 协作驾驶（AI 坐上你的另一个座位，可选保守 / 激进） · 单人 / 双人合作 / 双人对抗 / 观战 · 程序化音效 · 实时生成赛道 · 16 种车型 · 硬墙碰撞 · AI 五挡智能程度 · 3-2-1 倒计时

一辆车有**前后**与**方向**两位驾驶员。你只坐一个座位也行——另一个座位交给 AI 队友，而这位队友有两种性格：**保守**替你把车稳稳地交回你手里，**激进**无条件相信你会做完美操作、绝不拖你后腿。

车不再"指哪打哪"。转向改的是**车头**，车往哪走要看**轮胎还抓不抓得住**——高速大转向会把车甩出去，路面上留下两道淡淡的轮胎印；行进中踩着 `S` 减速再带一点方向，前轴先失抓，同样会甩。

赛道没有模板，每局沿一条随机引导线逐段生长——直道、缓弯、S 弯、发卡弯、360° 回湾随机拼接，再用 Dubins 曲线平滑闭合。赛道是单层平面且全程无交叉，不会自己贴上自己；两侧是红白缓冲带加固护墙，撞墙会被弹回并掉速。每局所有车都会分配到不同的车型，玩家的车随机决定。

## 玩法

- **开赛**：主菜单 → 开始游戏 → 选择模式（单人 / 双人 / 观战）与参数 → 开始比赛
- **驾驶方式**：单人 / 双人对抗时可把一台车的两个座位拆开——自己开一边，另一边交给 AI 队友（详见「协作驾驶」）
- **赛道**：进入选择页会实时生成一条新赛道（生成期间显示进度条补位），缩略图同步刷新；点「重新随机」可换一条，开始比赛用的就是预览的这条
- **发车**：进入赛道后先播 **3 → 2 → 1 → GO!** 倒计时，屏幕上会提示「沿地面箭头方向发车」，赛道地面同时有向前流动的箭头（GO 后淡出），倒计时期间车辆锁定
- **目标**：率先跑完设定圈数；**第一位冲线后比赛最多再持续「圈数 × 5 秒」，或全部车辆冲线即立即结算**（HUD 会显示结算倒计时）
- **碰撞**：撞墙或与其他赛车相撞会冒火花、车身闪白、镜头抖动，速度明显受损，同时有随撞击轻重变化的闷响
- **找自己**：玩家车底部有一层玩家色柔光，车头前方有一条细箭头，不遮挡车身与视野
- **声音**：撞击、倒计时、冲线与结算都有提示音，不合成行驶噪声；模式选择页可整体关闭（详见「音效」）
- **暂停**：`Esc` / `P`，或切走窗口、切到别的标签页时自动暂停；继续时（`Esc` / `P` / 「继续比赛」）会重新播一遍 3-2-1 再走，比赛计时不补
- **结算**：前三名上领奖台，下方逐车列出总时间、最快单圈、平均单圈、碰撞次数（撞墙 / 车与车分开统计）与极速

## 惯性漂移

这是这一版的核心手感，也是所有 AI 逻辑的出发点。

### 车头不等于方向

转向输入改的是**车头朝向**，车实际往哪走由**横向轮胎力**决定。速度越高，能用的横向加速度越低，行驶方向追得越慢——于是高速打方向就会甩出去。

| 你的操作 | 会发生什么 |
| --- | --- |
| 直线全油门 | 稳稳直行，不滑 |
| 满速猛打方向 | 侧滑角每秒涨到 50°+，1 秒就能进 57°；路面上留下双轮胎印，车身顺着侧滑方向歪着 |
| 满速猛打后立刻反打 | 0.1 秒内救回来——**反打就是漂移的核心操作** |
| 行进中踩 `S` 减速 | 车身前倾点头（重量前移），抓地在塌缩，弯里更容易推头 |
| 行进中踩 `S` **同时**打方向 | 前轴先失抓 + 转向权限被放大，滑角轻松上 40° |
| 低速挪车 / 原地打方向 | 几乎不滑（低速时转向权限本来就被压着） |

漂移不是免费的：侧滑时轮胎横向摩擦会磨掉速度（滑角 17° 约 −55 px/s²，40° 约 −122 px/s²）。想靠漂移过更紧的弯，得先算好这笔交换划不划算。

### 看得见的反馈

| 反馈 | 说明 |
| --- | --- |
| **轮胎印** | 两个后轮各留一道淡淡的痕迹，5 秒内淡出。满速甩尾一眼就能看见自己的线 |
| **轮胎烟** | 漂移时后轮冒出的灰白薄雾，越滑越浓 |
| **车身侧倾** | 车身顺着侧滑方向歪过去；轮胎印只在后轮，车身若还端端正正就看不出在甩 |
| **刹车点头** | 踩 `S` 时车身前倾、前轴压缩 |
| **HUD** | 速度条上烧一段琥珀色，旁挂「漂移」小标 |

### 满舵死打会怎样

滑角有个软上限（`slipMax` ≈ 54°）。满速死打方向不会原地打转，稳态会停在 **60° 出头**——是"甩出去"，不是"转圈圈"。反打立刻救得回来。

## 模式与操作

### 单人模式

一台车，两套键位同时生效，怎么按都行。

| 动作 | 键位 |
| --- | --- |
| 前进 | `W` 或 `↑` |
| 后退 / 刹车 | `S` 或 `↓` |
| 左转 | `A` 或 `←` |
| 右转 | `D` 或 `→` |

这是「自主驾驶」——两个座位都自己坐。也可以只坐其中一个，把另一个交给 AI 队友，见下一节的「协作驾驶」。

### 双人 · 合作

两人分工控制同一台车，模式选择页里切换两种分工方案（带按键预览）：

| 方案 | 玩家 1（前后） | 玩家 2（左右） |
| --- | --- | --- |
| A | `W` 前进 / `S` 后退 | `←` 左转 / `→` 右转 |
| B | `↑` 前进 / `↓` 后退 | `A` 左转 / `D` 右转 |

因为一台车的方向与动力由两个人分别输入，配合不好就会贴着墙磨；谁松手谁负责的那一半就归零。

### 双人 · 对抗

一人一台车，P1 用 `W/A/S/D`，P2 用 `↑/←/↓/→`，同时发车。两人各自独立选择驾驶方式：可以都自己开，也可以一人只坐一个座位、让 AI 补上另一半。

### 协作驾驶（单人 / 双人对抗）

每台车本来就有前后与方向两位驾驶员。这两种玩法里，模式选择页会多出一块「驾驶方式」，每个玩家一行三段式：

| 选择 | 你负责 | AI 队友负责 |
| --- | --- | --- |
| 自主驾驶 | 前后 + 方向（原来的玩法） | — |
| 前后位 | 油门 / 刹车（单人两套键都算，P1 `W/S`、P2 `↑/↓`） | 方向 |
| 方向位 | 左右方向（单人两套键都算，P1 `A/D`、P2 `←/→`） | 油门 / 刹车 |

选了座位之后，下面会多出一块「AI 队友风格」，两种性格二选一：

| 风格 | 它相信什么 | 实际表现 |
| --- | --- | --- |
| **保 守** | 玩家可能手生 | 进弯前**早一个刹车点**就开始收油、跟车留足距离（`150 + 0.62s×车速`）、**贴着中线走**不切角、超车犹豫、只敢用六成抓地——弯里稳定 9° 侧滑，**一圈跑下来不留胎痕** |
| **激 进** | 玩家会做完美操作 | 几乎不主动减速、追到车尾才松、**走几何最短路线**（钳形切角，用到 78% 路宽）、抓地用满、弯里甩尾到 17~37° **留下一路胎痕**、反应间隔只有保守档的一半 |

- 这两种风格**不是 AI 强度分级**，而是两种协作契约：保守替你把车**完整地交回你手里**，激进把风险推给你、但**绝不拖你后腿**
- 风格只管你车上的队友，与「AI 对手智能程度」五挡**互相独立**——可以「全场 NPC 都是新手，但你的队友是激进」
- 接管位同样吃 AI 的**位次速度补偿**（名次越低尾速越高，每落后一位 +2% 基准最大速度），这是「车上有 AI 在开」的代价与奖励
- **AI 只管方向时不会自作主张倒车**：脱困、掉头、刹车全归你，它只负责把车往线上带（含躲车、并排让位、超车切外线）
- **AI 只管前后时**会替你刹车、跟车配速、受困倒车，也给超车补油；方向全靠你，冲进弯里它只会尽量刹住
- 只开一半时，另一半的键按下去不生效（不会出现两人抢同一个轴）；左下角键位提示会收窄成你真正用得上的那几个键
- 赛内 HUD 在车手名后面挂一枚 `AI 方向 · 激进` / `AI 前后 · 保守` 小标，结算 meta 会写明谁坐了哪个座位、队友什么风格

### 观战模式

不开车，当导播：全场都是 AI（车辆数下限 2，上限同 AI 数量 12），智能程度五挡同样生效。

| 按键 | 作用 |
| --- | --- |
| `空格` | 鸟瞰总览 ⇄ 跟随视角 |
| `A` / `←` | 切换至上一台车 |
| `D` / `→` | 切换至下一台车（循环） |

- **跟随视角**：相机锁定当前跟随的赛车，随车速微微拉远；被跟随的车带一圈呼吸光环，小地图上也能看到它的位置
- **鸟瞰总览**：相机平滑拉远，把整条赛道（含护墙）完整装进视口，一览全场走位与名次——**甩出去的胎痕在鸟瞰下看得很清楚**
- 开局默认跟随领头羊；底部居中有一条导播条，显示当前视角、跟随谁（第几名）与可用按键
- 结算时冠军即全场第一（如「AI 3 夺 冠」），结算页 meta 标注「观战」

三种驾驶模式都可以追加 0~12 台 AI 对手（设为 0 就是纯练习或纯 1v1）。AI 对手的智能程度分 5 挡，在模式选择页调整，详见「AI 对手」一节。

倒车时转向方向自动反向，与真实车辆一致；速度越低转向越迟钝，高速时转向更灵敏——但**高速转向权限大不等于更好走**，过头就会甩出去。

## 音效

全部**程序化合成**（Web Audio），不加载任何音频文件，也没有素材目录，每个音效都是运行时现算波形。**没有持续行驶噪声**：合成出来的引擎/声浪音色始终偏电子，高频一多就刺耳，所以只在事件上出声，跑起来是安静的。

| 音效 | 听感 | 触发点 | 怎么做的 |
| --- | --- | --- | --- |
| 撞击 | 低频闷响 + 金属碎裂爆点 | 撞墙 / 车车相撞，用碰撞系统已有的 `power` | 正弦砸击从 160Hz 向下扫到 46Hz，叠一段固定种子白噪声（带通中心随强度 900→3300Hz）；越重越亮越长 |
| 倒计时 | 三声「嘟嘟嘟」，前三个数字各一声，GO 更高更长 | 倒计时每跨一步、以及解除锁定的瞬间 | 双音喇叭：纯五度两支振荡器（锯 392Hz + 三角 588Hz）一起响 → 低通削掉刺耳谐波 → 尾音下滑 7%，所以是圆润的「嘟」而不是尖细的「哔」；GO 换 523Hz、时长 0.42s |
| 完赛 | 冲线三连上行音，结算接一段分解和弦 | 玩家车冲过终点、结算面板弹出 | 三角波 E5→A5→E6；结算 C 大调 523/659/784/1047 分解 + 低音铺底，若刚响过冲线音会顺延 0.6s，两段不叠 |

- **听者**是玩家车的中点；观战模式改为当前跟随的那台车，撞击的音量与声像都据此计算
- **声像**按相对听者的左右位置摆动，对手在旁边撞墙能听出在哪一侧
- 撞击按距离衰减（1400 单位外基本听不见），同帧多起碰撞有 35ms 节流，不会叠成爆音
- 模式选择页的「音效」开关控制总音量；浏览器要求用户手势后才能出声，第一次点击 / 按键时自动解锁（`main.js`）

## 赛道

没有预设形状，每局都是**程序化生长**出来的，一圈约 1.6 万~2.1 万世界单位。

### 怎么长出来的

1. **定引导线**：先随机一个椭圆（长短轴比 1.22~1.72、带随机倾角），由目标圈长反推长短轴，再在椭圆上随机取起点与行驶方向
2. **逐段生长**：始终朝「椭圆上的前视点」做纯追踪，每步抽一种片段接上去

| 片段 | 参数 | 说明 |
| --- | --- | --- |
| 直道 | 长 320~720 | 加速路段 |
| 缓弯 | 半径 410~870，转角 40°~99° | 最常见的过弯 |
| S 弯 | 三段反向弧 | 连续左右摆动 |
| 发卡弯（折弯） | 半径 174~250，转角 176°~205° | 必须减速的回头弯 |
| 360° 回湾 | 整圆，半径 285~430 | 平面上绕一整圈；放置前先做「圆盘避让」检查，空间不干净就放弃，绝不跨过赛道别处 |

每局最多 2 个回湾，空间允许才放置（圆盘避让）；回湾之后强制接一段长直道拉开距离。

3. **闭合**：走满目标长度后朝起点收尾，再用 **Dubins 曲线**（LSL / LSR / RSL / RSR 四种「弧-直-弧」组合，半径从 420 递减到 110）把当前位姿接回起点位姿，切线连续，所以闭合处也是一个正常弯道
4. **零交叉检查**：算每个采样点到「沿路径很远」的最近点距离（沿路径距离双向取近，正确排除闭环首尾接缝），任何一处小于路面全宽（336）都判定为交叉，整条作废重长；最多重试 8 次，仍不过就用正圆环兜底
5. **挪起点**：把起终点移到最长直道的中段，保证发车格前后都是平路

### 生成是分片的

整条流程写成 generator，`generateAsync()` 按每片约 8ms 切片执行，期间通过 `onProgress(progress, label)` 汇报「规划路线 → 生成赛道 → 闭合赛道 → 检查路线 → 散布场景」五个阶段。生成快于 340ms 时会把剩余进度平滑补齐，进度条不会冲到 100% 后干等。生成异常时回退到一条正圆环赛道，游戏不会卡死。

### 路面

赛道是**单层平面且无交叉**：没有任何立交，也没有平交路口——赛道从头到尾不会自己贴上自己，两处路面之间至少留出 336 单位的净距（路面全宽 + 安全余量）。

路面结构由内到外为：**沥青 → 红白缓冲带 → 硬墙**。沥青半宽 140（整车面宽 280 ≈ 4 车位），并排超车、内外线切换都有足够空间；赛车可以压上红白缓冲带，但会被缓冲带外侧的墙挡住，缓冲区让贴墙驾驶的手感更宽容。

无交叉是这样保证的：

| 手段 | 做法 |
| --- | --- |
| 源头 | 引导椭圆周长不小于目标圈长，路径绕行不超过一圈，从根上避免折返回自己 |
| 在线避让 | 每生成一段就先做间距检查，贴上别处就换片段重抽（最多 4 次），连续陷坑则回退到更早的位置重新脱困 |
| 回湾避让 | 360° 回湾按左右两个方向各试一圈半径候选，要求整个圆周（含安全余量）不套住别处的路，放不下就放弃这个回湾 |
| 收尾 | 末端退回起点后方沿出发方向进场，与出发段首尾相接；闭合弧按 420→110 五档半径优选，都贴上别处就作废重长 |
| 终检 | 全量最近邻距离零容忍，一处不合格整条作废，最多 8 次尝试 |

> 满速时最小转弯半径约 360——所以发卡弯（174~250）与 360° 回湾（285~430）**正常是过不去的**，必须减速，或者用漂移硬吃。缓弯（410~870）大多能带全速。

车型只改变尺寸与外观，动力参数全车一致，比赛是公平的；尺寸会同步影响碰撞体（OBB 与四角贴墙都用车型尺寸）。最多 8 台车，从 16 款里不重复抽取。

## AI 对手

AI 不是「沿中线匀速开」的摆设：每台 AI 由两位风格激进的「驾驶员」分工操作，会主动绕行超车、各有各的走线，名次靠后还能拿到最高 +20% 的尾速加成。智能程度分 **5 挡**，模式选择页可调。

> 注意区分：**AI 对手智能程度五挡**管的是全场 NPC 的强度；**协作驾驶的保守 / 激进**管的是坐在你车上的那位队友。两者互相独立。

### 智能程度五挡

每台 AI 始终是「两位独立驾驶员」的架构，挡位改变的是反应间隔、默契程度、激进程度与安全覆盖：

| 挡位 | 两位驾驶员的状态 | 油门/转向反应间隔 | 弯道余量 | 过弯技能 | 超车积极性 | 跟车安全距 | 急刹判断余量 | 安全覆盖 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 新手 | **完全没有默契，各管各的**——不共享感知，且各自对赛道形状有随机理解偏差 | 0.32~0.55 / 0.26~0.44s | 0.66 | 0.72~0.88 | 0.15 | 100 + 0.47s | 无（不急刹） | 关 |
| 2 入门 | 开始共享视野，但反应慢、过弯不敢压极限 | 0.20~0.34 / 0.16~0.28s | 0.68 | 0.80~0.92 | 0.35 | 95 + 0.45s | 无（不急刹） | 关 |
| 3 普通 | 有基本配合：会提前刹车、互相避让 | 0.14~0.24 / 0.11~0.20s | 0.72 | 0.85~0.96 | 0.60 | 82 + 0.40s | 0.10s / 72px | 开 |
| 4 老练 | 反应快、跟车压迫积极、走线干净 | 0.10~0.16 / 0.08~0.14s | 0.80 | 0.88~1.00 | 0.80 | 66 + 0.32s | 0.07s / 66px | 开 |
| 5 赛车手 | 极度激进：贴限过弯、贴身超车、反应几乎无延迟 | 0.07~0.12 / 0.05~0.10s | 0.86 | 0.93~1.05 | 1.00 | 52 + 0.26s | 0.04s / 62px | 开 |

挡位同时还决定两档漂移余量：`gripUse`（敢用掉几成抓地）与 `driftCap`（弯里允许滑到多大滑角）。低挡位在弯里滑不到留胎痕的门槛，高挡位贴边走会甩。

### 双驾驶员架构

一台 AI 的前后与左右由两个独立模块分别决策，互不同步：

| 驾驶员 | 文件 | 职责 | 反应间隔 |
| --- | --- | --- | --- |
| 前后驾驶员 | `entities/ai-throttle.js` | 只决定油门 / 刹车 / 倒车 | 由档案决定 |
| 转向驾驶员 | `entities/ai-steer.js` | 只决定左右方向 | 由档案决定 |
| 协调器 | `entities/ai.js` | 共享感知、受阻判定、倒车脱困、安全覆盖 | 每帧 |

`entities/ai.js` 把两位驾驶员都要用的感知只算一次，再分发给两人；两人的决策缓存按各自的间隔刷新，所以同一台车会出现「油门已经踩下、方向还没打」的配合差，像两个人在轮流接管。最低挡位不共享感知：`rollJitter()` 让两位驾驶员各算各的，且各自对赛道形状有随机理解偏差（瞄准点横向偏移、前视采样、刹车窗口），每隔半秒左右重抽一次。

同一个架构也复用给玩家车：`AI.think()` 多了个 `role` 参数（`both` / `throttle` / `steer`），协作驾驶时只出被接管的那一半，另一半取键盘输入（`game.stepRace()` 里拼起来）。`steer` 角色会整段跳过倒车脱困、掉头恢复与紧急制动——这三段都要靠油门执行，AI 不碰油门就不该发起（否则会出现「玩家踩着油门、AI 按倒车逻辑打方向」）。

### 转向：侧滑前馈补偿

有惯性之后，AI 不能只按车头修正——车头摆好了车还在往外甩，跑出来全是弧形外扩。转向驾驶员在瞄准偏差上再减掉一段当前侧滑角：

```
steer = (瞄准偏差 − slip × 前馈系数) × 瞄准增益
```

系数保守档 1.35、激进档 0.95。实测这一项让 NPC 普通挡的均速从 508 提到 566、全速帧占比从 82% 提到 96%、撞墙从 1 次降到 0——补偿让车真的走在线上，而不是靠瞄准误差硬撑。详见 [docs/物理与AI.md](docs/物理与AI.md#二ai-的转向侧滑前馈补偿)。

### 弯道限速：转向能力 ∩ 抓地上限

```
v = min( turnRate × R × 余量 × 技能 ,  √(可用的横向加速度 × R) )
```

第二项是加漂移之后才有的：没有它，AI 会带着满油门冲进抓不住的弯然后甩出去。每台 AI 有挡位区间内的随机过弯系数，入弯收油的早晚与过弯速度略有高低，直道尾速则一致（都给到底）——**比赛的先后来自谁敢压弯，而不是谁少踩了油门**。

### 共享感知

| 信息 | 用途 |
| --- | --- |
| `aimX / aimY` | 瞄准点，转向驾驶员算期望行驶方向 |
| `velAngle` | 行驶方向（不是车头朝向），有惯性后两者会分开 |
| `angleDiff` | 瞄准点偏差。瞄准点已向弯心内切（按前方 26 个采样点的朝向变化偏向内侧），内切权重由档案决定 |
| `minRAhead` | 刹车窗口内的最小曲率半径。窗口随速度放大（16 + 速度×0.055 个采样点，再乘档案倍率），窗口里藏着更急的弯就提前收油 |
| `blocker` | 车头前方最近的占道车（距离、侧偏、对方速度），跟车与躲车的对象 |
| `neighbor` | 并排最近的车（含略偏前后），用于横向分离：steer 层打舵 + 瞄准点层让位，并记录**横向接近速度**（只按同一台车连续跟踪计算） |
| `pass` | 绕行超车期间正在超的那台车（含身侧与略后方），超车状态机与油门加成靠它续命 |
| `rear` | 正后方最近的车，倒车避让用 |
| `wallGap` / `headingToWall` | 与两侧墙的距离和朝向关系（`headingToWall` 用行驶方向算，漂移时车尾可能先蹭上） |

### 激进风格

- **主动超车（不按部就班）**：被前车压住一段时间就选空间大的一侧绕出去——瞄准点向外线偏移、油门目标不低于「前车速度 + 余量」，并**锁定目标车直到明显超过它**：绕行过半时目标会退到身侧甚至略后方，`blocker` 只认正前方的车，靠 `pass` 续上才不会「刚好并排就松油门回正」
- **位次速度补偿（橡皮筋）**：`boost = 1 + 0.02 × (名次 - 1)`——第一名 1.0，每落后一位多 2% 基准最大速度，物理限速随之放宽；弯道限速不吃补偿，否则入弯外抛
- **限速是硬上限**：`phys()` 直接把车速截在 `maxSpeed × boost`，油门顶不出去——否则软阻尼下的 +12% 会把 2% 的位次差异完全盖住
- **各有各的走线**：每台车开局 roll 一条固定的走线偏好（相对半宽 ±35%），叠加弯心内切，不是全场压着中线跑
- **跟车压迫**：被前车压住越久，安全车距压缩越多（最多 38%），主动贴上去求超车
- **跟车安全距**：`基数 + 车头时距 × 车速 + 接近速度折算`——普通挡还在 200px 外就收油，赛车手贴到 100px 内才让
- **急刹判断余量**：`接近速度²/(2·刹车)` 的物理最小刹停间距 + `反应折算 × 接近速度 + 固定缓冲`。余量按**相对距离缩短量**算，不是「自己一路跑过的距离」——普通挡约 80px、赛车手约 60px 才出手
- **躲车随速度收敛**：高速时同样的转角横移更远，所以躲车权重随速度衰减，避免全速打满方向横穿赛道
- **转向速率随速度收紧**：单次决策的方向变化量上限随速度收缩，防止高速下猛打方向造成整车横穿赛道

### 安全覆盖（绕过驾驶员的反应间隔，挡位 3 起开启）

| 覆盖 | 触发条件 | 动作 |
| --- | --- | --- |
| 紧急制动 | 前车近到「现在不刹就停不住」 | 立即把油门计划覆写为全力刹车 |
| 倒车避让 | 倒车中后方 95 内有车，且自己没有贴墙卡住 | 油门归零稳住，等对方过去 |
| 横向分离 | 身旁有并排的车（不限正前） | 打舵往外侧让位，同时把瞄准点也拉到让开的一侧 |

### 脱困与恢复

有惯性之后新增了两种必须处理的困住形态——车可以整台横在护墙里（侧滑角上百度），此时倒车只会把车尾也塞进墙，形成死循环：

| 情况 | 处理 |
| --- | --- |
| **被车顶住** | 受阻倒车：油门踩满但速度低于 50，且前方有车持续 0.55s → 倒车 0.9s，把车头摆回瞄准方向 |
| **横在墙里** | 贴墙卡死：改为**前进**脱困，车头朝赛道中心猛打 + 保持给油。低速下转向权限虽小，车头朝哪挪就往哪挪，慢但出得来 |
| **原地打转** | 连续 1.5 秒速度低于 90 就强制倒车一次 |

这三层兜底与挡位无关，所有 AI 共用。**卡死是 bug，不是档位定位**——档位可以慢、可以撞墙，但不能开不出赛道。
- **掉头恢复**：车头偏离赛道方向超过约 86° 且速度起不来，倒车把车头摆回来，不硬着头皮横向滑墙
- **贴墙倒车降速**：倒车中距墙 60 内自动收油门到 −0.55，避免全速倒车尾部横扫刮墙

## 代码架构

- **单一命名空间**：所有模块挂在 `window.DRC` 上，用 IIFE 包裹，避免全局污染
- **加载顺序**：`index.html` 底部按「core → audio → world → entities → systems → render → ui → game → main」引入，模块之间只在运行时互相调用，不做加载期依赖
- **单向数据流**：`game.js` 每帧驱动「输入 → 物理 → 碰撞 → 胎痕 → 规则」，渲染层只读取状态，不修改状态
- **模式驱动玩家数**：`state.mode`（solo / coop / versus / spectate）决定生成几台玩家车，`Game.playerInput()` 再按模式把键位映射成同一份 `{throttle, steer}`，物理与碰撞完全不区分模式；`state.seats`（0 自主 / 1 前后位 / 2 方向位）再决定玩家车的这一轴是来自键盘还是接管位 AI
- **驾驶档案双轨**：`DRC.AI_LEVELS`（5 挡，NPC）与 `DRC.DRIVE_STYLES`（保守 / 激进，接管位）字段名一致，共用 `applyProfile()`；`Game.useAiProfile()` 在每台车思考前把它那套写进 `CONFIG`，所以一场比赛里可以同时跑三种开法的车
- **参数集中**：手感、赛道尺寸、碰撞系数、漂移模型、AI 反应节奏全部位于 `src/core/constants.js` 的 `DRC.CONFIG`

## 浏览器要求

Canvas 2D、`requestAnimationFrame`、CSS `backdrop-filter`（仅影响面板模糊，缺失不影响运行）、Web Audio API（音效；不支持时游戏静音运行，其余功能不受影响）。已用现代 Chromium / Firefox / Safari 开发与验证。

音频遵循浏览器的自动播放策略：音频上下文在**第一次点击或按键**后才创建 / 恢复（`main.js` 的 `unlockSound`），所以主菜单上前几秒本来就该是安静的。切到别的标签页会自动暂停。
