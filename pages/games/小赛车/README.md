# 双人赛车

> Canvas 赛车小游戏 · 单人 / 双人合作 / 双人对抗 / 观战 · 协作驾驶（AI 坐上你的另一个座位） · 程序化音效 · 实时生成赛道 · 16 种车型 · 硬墙碰撞 · AI 五挡智能程度 · 3-2-1 倒计时

三种玩法共用一套车与赛道：一个人开、两个人分工开同一台车、或者一人一台车正面竞速——也可以都不开，进入观战模式当导播，看全场 AI 自己跑。赛道没有模板，每局沿一条随机引导线逐段生长——直道、缓弯、S 弯、发卡弯、360° 回湾随机拼接，再用 Dubins 曲线平滑闭合。赛道是单层平面且全程无交叉，不会自己贴上自己；两侧是红白缓冲带加固护墙，撞墙会被弹回并掉速。每局所有车都会分配到不同的车型，玩家的车随机决定。

## 玩法

- **开赛**：主菜单 → 开始游戏 → 选择模式（单人 / 双人 / 观战）与参数 → 开始比赛
- **驾驶方式**：单人 / 双人对抗时可把一台车的两个座位拆开——自己开一边，另一边交给 AI 队友（详见「协助驾驶」）
- **赛道**：进入选择页会实时生成一条新赛道（生成期间显示进度条补位），缩略图同步刷新；点「重新随机」可换一条，开始比赛用的就是预览的这条
- **发车**：进入赛道后先播 **3 → 2 → 1 → GO!** 倒计时，屏幕上会提示「沿地面箭头方向发车」，赛道地面同时有向前流动的箭头（GO 后淡出），倒计时期间车辆锁定
- **目标**：率先跑完设定圈数；**第一位冲线后比赛最多再持续「圈数 × 5 秒」，或全部车辆冲线即立即结算**（HUD 会显示结算倒计时）
- **碰撞**：撞墙或与其他赛车相撞会冒火花、车身闪白、镜头抖动，速度明显受损，同时有随撞击轻重变化的闷响
- **找自己**：玩家车底部有一层玩家色柔光，车头前方有一条细箭头，不遮挡车身与视野
- **声音**：撞击、倒计时、冲线与结算都有提示音，不合成行驶噪声；模式选择页可整体关闭（详见「音效」）
- **暂停**：`Esc` / `P`，或切走窗口、切到别的标签页时自动暂停；继续时（`Esc` / `P` / 「继续比赛」）会重新播一遍 3-2-1 再走，比赛计时不补
- **结算**：前三名上领奖台，下方逐车列出总时间、最快单圈、平均单圈、碰撞次数（撞墙 / 车与车分开统计）与极速

## 模式与操作

### 单人模式

一台车，两套键位同时生效，怎么按都行。

| 动作 | 键位 |
| --- | --- |
| 前进 | `W` 或 `↑` |
| 后退 / 刹车 | `S` 或 `↓` |
| 左转 | `A` 或 `←` |
| 右转 | `D` 或 `→` |

这是「自主驾驶」——两个座位都自己坐。也可以只坐其中一个，把另一个交给 AI 队友，见下一节的「协助驾驶」。

### 双人 · 合作

两人分工控制同一台车，模式选择页里切换两种分工方案（带按键预览）：

| 方案 | 玩家 1（前后） | 玩家 2（左右） |
| --- | --- | --- |
| A | `W` 前进 / `S` 后退 | `←` 左转 / `→` 右转 |
| B | `↑` 前进 / `↓` 后退 | `A` 左转 / `D` 右转 |

因为一台车的方向与动力由两个人分别输入，配合不好就会贴着墙磨；谁松手谁负责的那一半就归零。

### 双人 · 对抗

一人一台车，P1 用 `W/A/S/D`，P2 用 `↑/←/↓/→`，同时发车。两人各自独立选择驾驶方式：可以都自己开，也可以一人只坐一个座位、让 AI 补上另一半。

### 协助驾驶（单人 / 双人对抗）

每台车本来就有前后与方向两位驾驶员。这两种玩法里，模式选择页会多出一块「驾驶方式」，每个玩家一行三段式：

| 选择 | 你负责 | AI 队友负责 |
| --- | --- | --- |
| 自主驾驶 | 前后 + 方向（原来的玩法） | — |
| 前后位 | 油门 / 刹车（单人两套键都算，P1 `W/S`、P2 `↑/↓`） | 方向 |
| 方向位 | 左右方向（单人两套键都算，P1 `A/D`、P2 `←/→`） | 油门 / 刹车 |

- 接管位有**自己独立的挡位**（1~5，默认「赛车手」），与 NPC 的「AI 智能程度」互不影响：可以全场 NPC 都设成新手，而你的队友是赛车手
- 双人对抗里两人各选各的：P1 只坐方向位、P2 全自主，照样同时发车
- 只开一半时，另一半的键按下去不生效（不会出现两人抢同一个轴）；左下角键位提示会收窄成你真正用得上的那几个键
- 接管位同样吃 AI 的**位次速度补偿**（名次越低尾速越高，每落后一位 +2% 基准最大速度），这是「车上有 AI 在开」的代价与奖励
- **AI 只管方向时不会自作主张倒车**：脱困、掉头、刹车全归你，它只负责把车往线上带（含躲车、并排让位、超车切外线）
- **AI 只管前后时**会替你刹车、跟车配速、受困倒车，也给超车补油；方向全靠你，冲进弯里它只会尽量刹住
- 赛内 HUD 在车手名后面挂一枚 `AI 方向` / `AI 前后` 小标，结算 meta 会写明谁坐了哪个座位

### 观战模式

不开车，当导播：全场都是 AI（车辆数下限 2，上限同 AI 数量 12），智能程度五挡同样生效。

| 按键 | 作用 |
| --- | --- |
| `空格` | 鸟瞰总览 ⇄ 跟随视角 |
| `A` / `←` | 切换至上一台车 |
| `D` / `→` | 切换至下一台车（循环） |

- **跟随视角**：相机锁定当前跟随的赛车，随车速微微拉远；被跟随的车带一圈呼吸光环，小地图上也能看到它的位置
- **鸟瞰总览**：相机平滑拉远，把整条赛道（含护墙）完整装进视口，一览全场走位与名次，再按空格平滑回到跟随视角
- 开局默认跟随领头羊；底部居中有一条导播条，显示当前视角、跟随谁（第几名）与可用按键
- 结算时冠军即全场第一（如「AI 3 夺 冠」），结算页 meta 标注「观战」

三种驾驶模式都可以追加 0~12 台 AI 对手（设为 0 就是纯练习或纯 1v1）。AI 的智能程度分 5 挡，在模式选择页调整，详见「AI 对手」一节。

倒车时转向方向自动反向，与真实车辆一致；速度越低转向越迟钝，高速时转向更灵敏。

## 音效

全部**程序化合成**（Web Audio），不加载任何音频文件，也没有素材目录，每个音效都是运行时现算波形。**没有持续行驶噪声**：合成出来的引擎/声浪音色始终偏电子，高频一多就刺耳，所以只在事件上出声，跑起来是安静的。

| 音效 | 听感 | 触发点 | 怎么做的 |
| --- | --- | --- | --- |
| 撞击 | 低频闷响 + 金属碎裂爆点 | 撞墙 / 车车相撞，用碰撞系统已有的 `power` | 正弦砸击从 160Hz 向下扫到 46Hz，叠一段固定种子白噪声（带通中心随强度 900→3300Hz）；越重越亮越长 |
| 倒计时 | 三声「嘟嘟嘟」，前三个数字各一声，GO 更高更长 | 倒计时每跨一步、以及解除锁定的瞬间 | 双音喇叭：纯五度两支振荡器（锯 392Hz + 三角 588Hz）一起响 → 低通削掉刺耳谐波 → 尾音下滑 7%，所以是圆润的「嘟」而不是尖细的「哔」；GO 换 523Hz、时长 0.42s |
| 完赛 | 冲线三连上行音，结算接一段分解和弦 | 玩家车冲过终点、结算面板弹出 | 三角波 E5→A5→E6；结算 C 大调 523/659/784/1047 分解 + 低音铺底，若刚响过冲线音会顺延 0.6s，两段不叠 |

- **听者**是玩家车的中点；观战模式改为当前跟随的那台车，撞击的音量与声像都据此计算
- **声像**按相对听者的左右位置摆动，对手在旁边撞墙能听出在哪一侧
- 撞击按距离衰减（1400 单位外基本听不见），同帧多起碰撞有 35ms 节流，不会叠成爆音
- 模式选择页的「音效」开关控制总音量；浏览器要求用户手势后才能出声，第一次点击 / 按键时自动解锁（`main.js`）

## 赛道

没有预设形状，每局都是**程序化生长**出来的，一圈约 1.6 万~2.1 万世界单位，比早期版本的环线长约 3 倍。

### 怎么长出来的

1. **定引导线**：先随机一个椭圆（长短轴比 1.22~1.72、带随机倾角），由目标圈长反推长短轴，再在椭圆上随机取起点与行驶方向
2. **逐段生长**：始终朝「椭圆上的前视点」做纯追踪，每步抽一种片段接上去

| 片段 | 参数 | 说明 |
| --- | --- | --- |
| 直道 | 长 320~720 | 加速路段 |
| 缓弯 | 半径 410~870，转角 40°~99° | 最常见的过弯 |
| S 弯 | 三段反向弧 | 连续左右摆动 |
| 发卡弯（折弯） | 半径 174~250，转角 176°~205° | 必须减速的回头弯 |
| 360° 回湾 | 整圆，半径 285~430 | 平面上绕一整圈；放置前先做「圆盘避让」检查，空间不干净就放弃，绝不跨过赛道别处 |

每局最多 2 个回湾，空间允许才放置（圆盘避让）；回湾之后强制接一段长直道拉开距离。

3. **闭合**：走满目标长度后朝起点收尾，再用 **Dubins 曲线**（LSL / LSR / RSL / RSR 四种「弧-直-弧」组合，半径从 420 递减到 110）把当前位姿接回起点位姿，切线连续，所以闭合处也是一个正常弯道
4. **零交叉检查**：算每个采样点到「沿路径很远」的最近点距离（沿路径距离双向取近，正确排除闭环首尾接缝），任何一处小于路面全宽（336）都判定为交叉，整条作废重长；最多重试 8 次，仍不过就用正圆环兜底
5. **挪起点**：把起终点移到最长直道的中段，保证发车格前后都是平路

### 生成是分片的

整条流程写成 generator，`generateAsync()` 按每片约 8ms 切片执行，期间通过 `onProgress(progress, label)` 汇报「规划路线 → 生成赛道 → 闭合赛道 → 检查路线 → 散布场景」五个阶段。生成快于 340ms 时会把剩余进度平滑补齐，进度条不会冲到 100% 后干等。生成异常时回退到一条正圆环赛道，游戏不会卡死。

### 路面

赛道是**单层平面且无交叉**：没有任何立交，也没有平交路口——赛道从头到尾不会自己贴上自己，两处路面之间至少留出 336 单位的净距（路面全宽 + 安全余量）。

路面结构由内到外为：**沥青 → 红白缓冲带 → 硬墙**。沥青半宽 140（整车面宽 280 ≈ 4 车位），并排超车、内外线切换都有足够空间；赛车可以压上红白缓冲带，但会被缓冲带外侧的墙挡住，缓冲区让贴墙驾驶的手感更宽容。

无交叉是这样保证的：

| 手段 | 做法 |
| --- | --- |
| 源头 | 引导椭圆周长不小于目标圈长，路径绕行不超过一圈，从根上避免折返回自己 |
| 在线避让 | 每生成一段就先做间距检查，贴上别处就换片段重抽（最多 4 次），连续陷坑则回退到更早的位置重新脱困 |
| 回湾避让 | 360° 回湾按左右两个方向各试一圈半径候选，要求整个圆周（含安全余量）不套住别处的路，放不下就放弃这个回湾 |
| 收尾 | 末端退回起点后方沿出发方向进场，与出发段首尾相接；闭合弧按 420→110 五档半径优选，都贴上别处就作废重长 |
| 终检 | 全量最近邻距离零容忍，一处不合格整条作废，最多 8 次尝试 |

## AI 对手

AI 不是「沿中线匀速开」的摆设：每台 AI 由两位风格激进的「驾驶员」分工操作，会主动绕行超车、各有各的走线，名次靠后还能拿到最高 +20% 的尾速加成。智能程度分 **5 挡**，模式选择页可调。

### 智能程度五挡

每台 AI 始终是「两位独立驾驶员」的架构，挡位改变的是反应间隔、默契程度、激进程度与安全覆盖：

| 挡位 | 两位驾驶员的状态 | 油门/转向反应间隔 | 弯道余量 | 过弯技能 | 超车积极性 | 跟车安全距 | 急刹判断余量 | 安全覆盖 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 新手 | **完全没有默契，各管各的**——不共享感知，且各自对赛道形状有随机理解偏差 | 0.32~0.55 / 0.26~0.44s | 0.66 | 0.72~0.88 | 0.15 | 100 + 0.47s | 无（不急刹） | 关 |
| 2 入门 | 开始共享视野，但反应慢、过弯不敢压极限 | 0.20~0.34 / 0.16~0.28s | 0.68 | 0.80~0.92 | 0.35 | 95 + 0.45s | 无（不急刹） | 关 |
| 3 普通 | 有基本配合：会提前刹车、互相避让 | 0.14~0.24 / 0.11~0.20s | 0.72 | 0.85~0.96 | 0.60 | 82 + 0.40s | 0.10s / 72px | 开 |
| 4 老练 | 反应快、跟车压迫积极、走线干净 | 0.10~0.16 / 0.08~0.14s | 0.80 | 0.88~1.00 | 0.80 | 66 + 0.32s | 0.07s / 66px | 开 |
| 5 赛车手 | 极度激进：贴限过弯、贴身超车、反应几乎无延迟——**但仍然是两位各管各的驾驶员** | 0.07~0.12 / 0.05~0.10s | 0.86 | 0.93~1.05 | 1.00 | 52 + 0.26s | 0.04s / 62px | 开 |

- **过弯技能只乘在弯道限速上**：每一挡的 AI 在直道都能跑到尾速（`maxSpeed × 位次补偿`），技能系数只决定它敢不敢按物理上限压弯——新手不是"直道也踩不到底"，而是"入弯前收得早"。早先乘在整个目标速度上，低挡位在直路上永远只到全速的 72%~88%，看着就是不敢开
- 低挡位（1~2）关闭安全覆盖且瞄准增益低（1.4~1.8）：瞄不准、修不勤，**撞墙是正常的**——这正是「没有默契」的代价
- 高挡位（4~5）瞄准增益 2.4~2.6，跟车压迫最多压缩 38% 车距主动求超车
- **车距判断精度从普通挡起递增**（`follow` / `brake` 两列）：
  - `跟车安全距` = 基数 + 车头时距 × 车速 + 接近速度折算——挡位越高跟得越近，普通挡还在 200px 外收油，赛车手贴到 100px 内才让
  - `急刹判断余量` = 按接近速度折算的反应余量 + 固定缓冲（约一个车身长）。**急刹间距按物理公式现场算**：追上前车的过程中相对距离只缩短 `接近速度² / (2·刹车)`，而不是「自己一路跑过的距离」——旧公式按后者算，等于离着 140~200px 就重刹，间距明明很大却减速；改对之后普通挡 ~80px、赛车手 ~60px 才出手，大间距敢全速跟
- **位次速度补偿（橡皮筋）全挡位生效**：名次越低尾速越高——第一名不加，之后每落后一位 +2% 基准最大速度（第 2 名 +2%、第 3 名 +4%…），物理限速同步放宽，比赛始终有悬念；补偿只放大直道尾速，弯道仍按抓地力物理上限跑，不会入弯外抛
- **全油门到底**：直道目标就是 `maxSpeed × 位次补偿`，不再被技能系数打折；离目标 90 以内改成比例油门（`err/90`，只给 8%~100%），超过目标用 `err/200` 的轻收油——旧版"低于 97% 全油 / 高于 103% 重刹"的二值切换会在目标附近甩出上百的速度差，肉眼能看到车速来回跳
- 实测（6 车混战 120s，3 个种子，本次油门改动后）：均速约 228（新手）→ 488（入门）→ 583（普通）→ 619（老练）→ 641（赛车手）；直道段车速稳定在 579~580（`maxSpeed` 580），改前普通挡直道只有 482 且波动 σ≈52

### 双驾驶员架构

一台 AI 的前后与左右由两个独立模块分别决策，互不同步：

| 驾驶员 | 文件 | 职责 | 反应间隔 |
| --- | --- | --- | --- |
| 前后驾驶员 | `entities/ai-throttle.js` | 只决定油门 / 刹车 / 倒车 | 由挡位决定 |
| 转向驾驶员 | `entities/ai-steer.js` | 只决定左右方向 | 由挡位决定 |
| 协调器 | `entities/ai.js` | 共享感知、受阻判定、倒车脱困、安全覆盖 | 每帧 |

`entities/ai.js` 把两位驾驶员都要用的感知只算一次，再分发给两人；两人的决策缓存按各自的间隔刷新，所以同一台车会出现「油门已经踩下、方向还没打」的配合差，像两个人在轮流接管。最低挡位不共享感知：`rollJitter()` 让两位驾驶员各算各的，且各自对赛道形状有随机理解偏差（瞄准点横向偏移、前视采样、刹车窗口），每隔半秒左右重抽一次。

同一个架构也复用给玩家车：`AI.think()` 多了个 `role` 参数（`both` / `throttle` / `steer`），协作驾驶时只出被接管的那一半，另一半取键盘输入（`game.stepRace()` 里拼起来）。`steer` 角色会整段跳过倒车脱困、掉头恢复与紧急制动——这三段都要靠油门执行，AI 不碰油门就不该发起（否则会出现「玩家踩着油门、AI 按倒车逻辑打方向」）。

### 共享感知

| 信息 | 用途 |
| --- | --- |
| `angleDiff` | 瞄准点偏差。瞄准点已向弯心内切（按前方 26 个采样点的朝向变化偏向内侧），过弯走线更短 |
| `minRAhead` | 刹车窗口内的最小曲率半径。窗口随速度放大（16 + 速度×0.055 个采样点），窗口里藏着更急的弯就提前收油 |
| `blocker` | 车头前方最近的占道车（距离、侧偏、对方速度），跟车与躲车的对象 |
| `neighbor` | 并排最近的车（含略偏前后），用于横向分离：steer 层打舵 + 瞄准点层让位，并记录**横向接近速度**（只按同一台车连续跟踪计算） |
| `pass` | 绕行超车期间正在超的那台车（含身侧与略后方），超车状态机与油门加成靠它续命 |
| `rear` | 正后方最近的车，倒车避让用 |
| `wallGap` / `headingToWall` | 与两侧墙的距离和朝向关系 |

### 激进风格

- **弯道限速按物理上限**：过弯速度 = `turnRate × 曲率半径 × 挡位余量`，比能抓地的极限略保守，给转向惯性与贴墙修正留余量；车头还没对准弯道时再收 22%
- **主动超车（不按部就班）**：被前车压住一段时间（挡位越高等得越短，赛车手 0.35s 就动手）就选空间大的一侧绕出去——瞄准点向外线偏移、油门目标不低于「前车速度 + 余量」，并**锁定目标车直到明显超过它**：绕行过半时目标会退到身侧甚至略后方，`blocker` 只认正前方的车，靠 `pass` 续上才不会「刚好并排就松油门回正」——半程收手是超车失败最常见的原因。目标跑到身后 150px、跑出感知范围或绕行超时才回正冷却
- **位次速度补偿（橡皮筋）**：`boost = 1 + 0.02 × (名次 - 1)`——第一名 1.0，每落后一位多 2% 基准最大速度（掉名次时涨得慢、抢到名次时收得快），直道尾速与物理限速同步抬高；弯道限速不吃补偿——抓地力决定的极限不跟着名次放大，否则入弯外抛
- **限速是硬上限**：`phys()` 直接把车速截在 `maxSpeed × boost`，油门顶不出去。原来是软阻尼（超出后按比例回收），全油门稳态会超出上限 70~90（12%+），把 2% 的位次差异完全盖住——这也是先前「看不出补偿效果」的第二个原因；顺带让 HUD 速度表与实际极速对齐（玩家车就是 580）
- **各有各的走线**：每台车开局 roll 一条固定的走线偏好（相对半宽 ±35%），叠加弯心内切，不是全场压着中线跑
- **跟车压迫**：被前车压住越久，安全车距压缩越多（最多 38%），主动贴上去求超车
- **跟车安全距随挡位收紧**：`基数 + 车头时距 × 车速 + 接近速度折算`——普通挡还在 200px 外就收油，赛车手贴到 100px 内才让；越高级对「多近会撞」算得越准，不会隔着老远减速
- **跟车配速**：车距低于安全距时，比前车慢多少由贴住的幅度决定——贴得越紧让得越多，车距被稳定拉回安全距附近，而不是贴住不放或一路全速。**只对正前方本车道内的车生效**（侧偏 64 内）：隔着一条道的车不构成追尾风险，为它减速是判断不准
- **并排避让也作用在瞄准点上**：身旁有车时把瞄准点拉到「对方的横向位置再让开一个半车位」——只靠转向打舵压不住瞄准追踪（弯心内切会把两车对着挤，实测隔着 100px 双方同时切内线，打舵那点修正会被 `angleDiff` 拉回去）。权重按横向接近程度、纵向接近程度**与横向收拢速度**加权：两条线正在收拢时就提前让开，而不是等侧偏掉到贴身再救火
- **躲车随速度收敛**：高速时同样的转角横移更远，所以躲车权重随速度衰减并设上限，避免全速打满方向横穿赛道
- **转向速率随速度收紧**：单次决策的方向变化量上限随速度收缩，防止高速下猛打方向造成整车横穿赛道
- **贴墙兜底**：车已经贴近墙（哪怕车头平行于墙）也会补一道弱修正把车拉回——高速平行墙行驶时朝向门控抓不住微小偏差，而 570px/s 下一次偏差就是一次蹭墙
- **技能差异**：每台 AI 有挡位区间内的随机过弯系数，入弯收油的早晚与过弯速度略有高低，直道尾速则一致（都给到底）——比赛的先后来自谁敢压弯，而不是谁少踩了油门

### 安全覆盖（绕过驾驶员的反应间隔，挡位 3 起开启）

两位驾驶员的反应间隔在全速下相当于 50~90 像素的「盲开」距离，以下三种情况由协调器立即接管，不等下一次决策：

| 覆盖 | 触发条件 | 动作 |
| --- | --- | --- |
| 紧急制动 | 前车近到「现在不刹就停不住」：间距低于 `接近速度²/(2·刹车)`（物理最小刹停间距）+ 挡位判断余量 | 立即把油门计划覆写为全力刹车。间距按**相对距离缩短量**算，不是「自己一路跑过的距离」——旧公式按后者算，等于离着 140~200px 就重刹；改对后普通挡约 80px、赛车手约 60px 才出手 |
| 倒车避让 | 倒车中后方 95 内有车，且自己没有贴墙卡住 | 油门归零稳住，等对方过去；已贴墙卡住时恢复优先，不做无谓等待 |
| 横向分离 | 身旁有并排的车（不限正前） | 打舵往外侧让位，同时把瞄准点也拉到让开的一侧；那一侧贴墙则不让。治起步抢线与超车过半的横向互切 |

### 脱困与恢复

- **受阻倒车**：油门踩满但速度低于 50，且前方有车或贴墙持续 0.55s → 倒车 0.9s；倒车时转向只做一件事——把车头摆回瞄准方向（掉头回正 / 贴墙朝中心倒 / 被车顶住反打脱开）
- **掉头恢复**：车头偏离赛道方向超过约 86° 且速度起不来，倒车把车头摆回来，不硬着头皮横向滑墙
- **贴墙倒车降速**（所有挡位生效，属基础车辆操作）：倒车中距墙 60 内自动收油门到 -0.55，避免全速倒车尾部横扫刮墙

插桩测量「AI 第一次踩刹车时的车身间距」与「跟车限速生效时的间距」（5 车混战 120s）：

## 代码架构

- **单一命名空间**：所有模块挂在 `window.DRC` 上，用 IIFE 包裹，避免全局污染。
- **加载顺序**：`index.html` 底部按「core → audio → world → entities → systems → render → ui → game → main」引入，模块之间只在运行时互相调用，不做加载期依赖。
- **单向数据流**：`game.js` 每帧驱动「输入 → 物理 → 碰撞 → 规则」，渲染层只读取状态，不修改状态；音频层同样只读取车辆状态（车速、位置），从不反向影响物理。
- **模式驱动玩家数**：`state.mode`（solo / coop / versus / spectate）决定生成 1 台、2 台还是 0 台玩家车，`Game.playerInput()` 再按模式把键位映射成同一份 `{throttle, steer}`，物理与碰撞完全不区分模式；`state.seats`（0 自主 / 1 前后位 / 2 方向位）再决定玩家车的这一轴是来自键盘还是接管位 AI。观战模式 `players` 为空，HUD 自动切换为导播条，相机改走跟随 / 鸟瞰两条支路。
- **参数集中**：手感、赛道尺寸、碰撞系数、AI 反应节奏全部位于 `src/core/constants.js` 的 `DRC.CONFIG`。

## 可调参数（`src/core/constants.js`）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `trackHalfWidth` | `140` | 沥青路面半宽（整车面宽 280 ≈ 4 车位） |
| `trackStep` | `15` | 赛道采样步长（世界单位），越小越平滑、采样点越多 |
| `trackMinRadius` | `110` | 最小弯道半径，决定发卡弯能有多急（发卡弯进出两段中心距 2r 必须大于净距判据 336） |
| `trackLength` | `[12000, 15200]` | 每圈目标长度区间；实际成圈长度约 1.6 万~2.1 万 |
| `bufferWidth` | `16` | 沥青外侧的红白缓冲带宽度 |
| `wallMargin` | `2.5` | 车身与墙的额外间隙 |
| `maxSpeed` | `580` | 最高车速 |
| `accel` / `brake` / `reverseAccel` | `440` / `860` / `280` | 加速、制动、倒车加速度 |
| `turnRate` | `2.6` | 转向角速度（rad/s） |
| `wallRestitution` | `0.42` | 撞墙弹性，越小越"闷" |
| `wallFriction` | `0.86` | 撞墙后的切向速度保留比例 |
| `aiLookAhead` | `5` | AI 前视采样基数（实际前视 = 基数 + 速度×0.028） |
| `aiDodgeRange` | `240` | AI 前方避让的起始距离（实际 = 240 + 速度×0.22） |
| `aiDodgeHalfWidth` | `96` | AI 视为"挡住自己车道"的横向阈值（4 车位宽路面上并排两车不算占道） |
| `aiNeighborAhead` / `aiNeighborSide` | `130` / `150` | 并排横向分离的感知范围（纵向 / 横向） |
| `aiRearRange` / `aiRearHalfWidth` | `110` / `100` | 倒车避让的后方车感知距离 / 横向范围 |
| `aiStuckSpeed` | `50` | 判定推不动的速度阈值 |
| `aiReverseTime` | `0.9` | 倒车脱困持续时长 |
| `aiLevel` | `3` | 默认智能程度挡位（1~5，见 `DRC.AI_LEVELS`）；实际挡位来自 `state.aiLevel`（NPC 用）与 `state.seatAi`（玩家车的接管位用） |
| `aiThrottleDelay` | `[0.09, 0.15]` | 前后驾驶员的反应间隔（秒）——**由挡位写入** |
| `aiSteerDelay` | `[0.07, 0.13]` | 转向驾驶员的反应间隔（秒）——**由挡位写入** |
| `aiSteerGain` | `2.4` | 瞄准增益：方向 = 偏差 × 该系数（低挡位低增益，瞄不准也不会打转）——**由挡位写入** |
| `aiCornerMargin` | `0.80` | 弯道限速余量：过弯速度上限 = `turnRate × 曲率半径 × 该系数`——**由挡位写入** |
| `aiOvertakeGap` | `0.30` | 被长时间压制后，跟车安全距最多压缩 38%，主动求超车——**由挡位写入** |
| `aiFollowBase` / `aiFollowHead` | `82` / `0.40` | 跟车安全距 = `基数 + 车头时距 × 车速 + 接近速度×0.55`，挡位越高跟得越近——**由挡位写入** |
| `aiBrakeReact` / `aiBrakeBuffer` | `0.10` / `72` | 急刹判断余量 = `接近速度×反应折算 + 固定缓冲`，叠加在物理最小刹停间距 `接近速度²/(2·刹车)` 上；挡位越高余量越薄——**由挡位写入**（1~2 挡无安全覆盖，不生效） |
| `aiOvertake` | `0.60` | 超车积极性 0~1（**由挡位写入**，0 = 完全不超）：决定被压多久后发起绕行、绕行持续与速度余量 |
| `aiRankStep` | `0.02` | 位次速度补偿步长：每个名次差 +2% 基准最大速度（名次 1 为 0，第 5 名 +8%）；只放大直道尾速，弯道物理上限不放大（超车加成在弯道最多超速 12%） |

| `aiSharedSense` | `true` | 两位驾驶员是否共享感知——**由挡位写入**；`false` 时各算各的且各有随机理解偏差 |
| `npcMax` | `12` | AI 对手数量上限（滑杆上限随之变化）；配色池 `AI_COLORS` 同样 12 色，满编时每台车颜色不重复 |
| `countdownStep` | `0.9` | 倒计时每一步时长（秒） |
| `finishGracePerLap` | `5` | 首位冲线后每圈宽限的秒数（总宽限 = 圈数 × 该值；全员完赛立即结算） |

## 浏览器要求

Canvas 2D、`requestAnimationFrame`、CSS `backdrop-filter`（仅影响面板模糊，缺失不影响运行）、Web Audio API（音效；不支持时游戏静音运行，其余功能不受影响）。已用现代 Chromium / Firefox / Safari 开发与验证。

音频遵循浏览器的自动播放策略：音频上下文在**第一次点击或按键**后才创建 / 恢复（`main.js` 的 `unlockSound`），所以主菜单上前几秒本来就该是安静的。切到别的标签页会自动暂停。
