# 2026-10-19

## 惯性漂移 + 协作驾驶风格（保守 / 激进）

游戏改名为「双座漂移」，本次是一轮涉及物理、AI、UI、文档的整体改造。

### 1. 车辆物理：从单角度模型改成侧滑模型（`src/entities/car.js`）

原来 `angle` 既是车头朝向又是行驶方向，且 `grip` 随速度上升 —— 高速反而更灵敏，没有惯性。现在拆成两个角：

- `angle` 车头朝向（转向输入直接改）
- `velAngle` 行驶方向（横向轮胎力把它往 `angle` 拉）
- `slip = normAngle(angle − travel)`，`travel` 倒车时为 `velAngle + π`
- 位置积分沿 `velAngle`，车真的往侧滑方向偏
- 横向加速度 = `min(lateralStiff × |slip|, gripMax)`，`gripMax` 随速度衰减 → 高速必然甩
- 新增：`brakeFade`（重刹前轴失抓）、`brakeYaw`（重刹放大转向）、`spinRecover`（打转回正）、`pitch`（刹车点头，表现层）
- **跨零点要翻半个 π**：`_fwd` 记录上一帧行驶方向，否则 slip 会瞬间变 π

实测落点：满速满舵 1s → 57.8°；死打方向稳态 59.9°（不会原地打转）；反打 0.1s 救回；满速纯刹车 0 滑角（物理正确，改做成车身点头）；满速刹车+满舵 43.9°。

## 追加：修 AI「像个笨蛋」（用户实机反馈后）

用户实机反馈：协作驾驶的队友 AI 两档都很笨。搭了无头模拟（vm 沙箱加载全部模块 + Track.create() 同步生成赛道 + 固定步长 1/60）量出根因。**教训：手感问题一定要先建可复现的量化指标，不要靠猜。**

### 诊断方法（以后做这类问题先做这一步）

在 `%TEMP%` 放一次性 node 脚本，`vm` 沙箱里跑 `constants/car-models/math/track/car/collision/race/ai-*`，把 `Sound` / `Camera` / `effects` 换成空实现，`Track.create()` 同步生成赛道。每个档位跨 7~10 个随机种子取中位数（**单种子方差极大，会误判**）。

六个指标：推进(=`lap×赛道长+nearIdx×步距`，最硬)、均速、全速帧占比(≥500)、均滑角、走线 RMS(`√mean(lat²)`)、撞墙/车撞。
**关键：用「推进」而不是「均速」判断卡死** —— 原地打转的档位均速可能不低，但推进卡在几公里。

### 病根 1：转向控制器符号推反（我昨天写错的）

我昨天把 `ai-steer.js` 改成「速度方向控制器」（`headWant = wantVel − clamp(slipLead×vErr)`），符号反了：
`slip>0` 时前馈把车头进一步推向外侧，而横向力又把行驶方向往车头拉 → 正反馈 → 车在中线上横甩。
换成加号同样救不回来（均速 56、滑角 68°）。
**教训：有惯性的车不能用「期望速度方向」做中间量控制律**，那是「转向→侧滑→行驶方向→反馈」的非最小相位环路，符号推错必然自激。

正确解法 = **侧滑前馈补偿**：`steer = (瞄准偏差 − slip × aiSlipLead) × 瞄准增益`（减号）。
把侧滑当成**已知的扰动**从偏差里减掉，而不是拿它当反馈量。
六变体实测：追车头(改造前) 508/82%全速/撞墙1 → 侧滑前馈 **566/96%/撞墙0**。

### 病根 2：三种新增的卡死（漂移模型引入，改造前不存在）

| 形态 | 特征 | 修法 |
|---|---|---|
| 贴墙死锁 | `v≈0`、`slip>90°`、`wallStuck` 恒 0 | `updateStuck` 判定要求 `throttlePlan>0.5`（在给油），倒车期恒 −0.55 → 永不成立。改成看「贴墙+推不动」这个事实本身 |
| 倒车内卷 | 车横在墙里倒车打转十几秒 | 倒车脱困要求车头朝路面方向，横着的车头永远对不上 → 贴墙卡死改为**前进**脱困（新增 `car.wallStuck`） |
| 指令自锁 | 车在中线上横甩、`lat≈0` | 低档位两位驾驶员各按各的世界观操作，指令对不上 → 连续 1.5s 速度<90 强制倒车（新增 `car.idleTimer`） |

**卡死是 bug 不是档位定位** —— 档位可以慢/撞墙，但不能开不出赛道。三层兜底与档案无关，所有挡位共用。

### 病根 3：保守档的参数把弯速算死了

`driftCap` 直接决定弯道限速 `v = √(lateralStiff × driftCap × R)`。原值 0.16 → 弯速被压到 480；再叠加 `brakeWindow=1.45`（感知窗口太长，看到远处弯就收油），**连直道都跑不到全速，全速帧占比只有 18%** —— 这就是「保守」看起来像「笨蛋」的直接原因。
改为 `driftCap 0.24 / gripUse 0.78 / brakeWindow 1.15` → 全速 84~97%。**教训：`driftCap` 和 `brakeWindow` 都是「全局减速器」，调保守风格时它们比 `cornerMargin` 影响大得多。**

### 病根 4：低档位世界观偏差没封顶

`sharedSense:false` 的两位驾驶员各带 ±20px 偏差。加漂移前只影响走线，现在直接乘进侧滑补偿而油门/转向基于两套不同赛道形状 → 实测 60s 只跑 9km。新增 `aiJitterRange`（默认 7px）封顶。
