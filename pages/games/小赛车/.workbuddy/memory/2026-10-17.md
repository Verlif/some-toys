## 赛道改为程序化生长（去掉环线 / ∞ 模板）

- 彻底重写 `src/world/track.js`，不再有 `style` 字段与 loop/infinity 模板。
- 算法：随机椭圆引导（长宽比 1.22~1.72 + 倾角，由目标圈长反推长短轴）→ 朝「椭圆上前视点」做**纯追踪**（LEAD 0.24 参数角）→ 逐段拼接直道 / 缓弯 / S 弯 / 发卡弯 / 360° 回湾 / 大回环 → 走满目标长度后**朝起点收尾** → **Dubins 曲线**（四种「弧-直-弧」组合取最短）闭合。
- 踩过的坑：
  - 用「切向误差 + 径向偏置」当引导时路径持续外扩，走 26000 才绕 0.6 圈；径向偏置符号极易搞反（`err +=` / `-=`），实验结果是外扩时 `-=` 才对。最终改用**纯追踪**才稳住。
  - `theta` 推进若按 `cost / 曲率半径` 算，会跑在车前面导致抄近路；必须用**车辆实际位置的参数角**累加（`theta += normAngle(phi - prevPhi)`）。
  - 收尾阶段不能继续抽普通片段，否则永远到不了起点；改成「对准后小步直行」（`homeGap * 0.55`，钳 90~430）。
  - 纠偏弧要**欠修正**（×0.85、钳 1.05），过修正（×1.2）会来回摆，凭空多出 1/3 长度。
  - `decorStage` 若按「每 120 次尝试 yield」，单片会阻塞 ~107ms；改成沿赛道两侧按采样点铺树（`GAP = 5`、法向偏移 116~366），O(n)，并顺带删掉 `nearestCoarse`。
- 分片异步：`generateAsync({ onProgress })` 用 generator 每片约 8ms 切片，五阶段进度映射；`minDuration = 340ms`，快于它时用 4 步 `setInterval` 把余量平滑补到 1；异常回退 `fallbackTrack()`（正圆环）。
- 进度映射坑：`proximityStage` 里原来 `yield { progress: 0 }` 会把进度打回 0，必须传 `pFrom / pTo`。
- `assignLayers` 改为基于「全局 farDist < (halfW+buffer)×1.35」的连续段配对：环上靠后的一支抬升，坡道按段长 10~22 自适应，取代固定 ±(10+16)。
- `pickStart` 后把数组 rotate，起点落在平地直道中段（检查 -60..+6 全平），发车格不会压在桥上。
- 实测（12 条）：长度 15287~20643（平均 18512，旧环线约 6100）；采样 1000~1450；最小曲率半径 122~170（> 86 安全线）；每局 1~2 个回环、1~6 处立体交叉；生成约 6ms。

## AI 智能化收尾：撞车归零（双驾驶员架构 + 安全覆盖）

上一轮 AI 重写后 6 车混战仍场均 17 次撞车（seed 555 达 100 次/120s）。逐帧回溯（trace_hit.js）定位三类根因：
1. **横向收敛**：并排起步/超车时两车朝同一点修方向，横向 ~50px/s 互切，跟车逻辑只管纵向无感；
2. **高速逼近刹车太晚**：油门计划 0.09~0.15s 反应间隔，全速下一次间隔 = 50~90px 盲开，高速追尾就差这半步；
3. **倒车不看后方** + 恢复死锁（倒车避让 hold 让贴墙卡住的车永远无法脱困，循环刮墙 5 次）。

修复（全部为增量，不改主干）：
- `constants.js` 新增 aiNeighborAhead/Side、aiRearRange/HalfWidth 四个感知参数；
- `ai.js` sense() 一次循环同时算 blocker / neighbor / rear；think() 加两项安全覆盖——紧急制动（按物理刹停距离 + 反应余量现场计算，越过反应间隔立即覆写油门）与倒车避让（后方有车且未贴墙才 hold，贴墙卡住时恢复优先，破解死锁）；
- `ai-steer.js` 加并排横向分离（身旁有车往外让，贴墙侧不让）；躲车权重随速度衰减（×0.42 上限 × (1-0.45·spd/maxSpeed)），治全速 whip-saw 横穿赛道；
- `ai-throttle.js` 跟车模型改比例控制：车距低于安全距时目标 = 前车速度 + err×90（err 越负让得越多），消灭「贴身 +55 蠕行」把车距吃到 2px 的火车病；倒车贴墙（wallGap<60）降速到 -0.55 防尾部横扫。

## 超车与车距判断调优（用户反馈：AI 不怎么超车 + 间距挺大就减速）

用户诉求：① AI 超车太少；② 车身间距挺大时也在减速，不合理；③ 从 L3 起，挡位越高对碰撞距离判断越准、越晚减速。

**根因（插桩实测，5 车 120s，种子 555）**：
- L3 基线：绕行 4 次、名次变化 **0**、急刹触发间距 **141~143px**、跟车限速 p50 **337px**——正是用户看到的现象
- 急刹公式用错了距离：旧 `need = (v²-u²)/(2·brake) + v×0.16 + 40` 用的是"自己一路跑过的距离"，而追上前车时相对距离只缩短 `接近速度²/(2·brake)`（例：600 追 480，前者 75px、后者仅 8.4px）。多出来的 120px 就是"间距挺大也减速"
- 超车半途熄火：`blocker` 只认正前方的车，绕行过半目标退到身侧/略后方时变成 null → 刚好并排就松油门回正 → 最常见超车失败

**实现**：
- `constants.js`：五挡加 `follow:[基数,车头时距]`（100/0.47 → 95/0.45 → 82/0.40 → 66/0.32 → 52/0.26）与 `brake:[反应折算,固定缓冲]`（L3 0.10/72、L4 0.07/66、L5 0.04/62）；CONFIG 新增 `aiFollowBase/aiFollowHead/aiBrakeReact/aiBrakeBuffer`；`game.js` 按挡位写入
- `ai.js`：sense() 新增 `pass`（绕行期间锁定目标车，含身侧与略后方，带速度）；updateOvertake 用 `b||pass` 判定收队（明显超过 = ahead<-150 / 跑出感知范围 / 超时，冷却 1.2/1.0/0.7），发起阈值 0.9-0.5×urge → 0.85-0.5×urge、时长 rnd(1.6,2.4)×(0.7+0.3×urge)；紧急制动改 `closing²/(2·brake) + closing×react + buffer`，横向门控绕行中 72→44（外侧 40+ 已不可能追尾，为它刹车只会掐死超车）
- `ai-throttle.js`：跟车安全距改用挡位参数 + 只对侧偏 64 内的车生效（隔着一条道不为它减速）；绕行加成目标用 `blocker||pass`
- `ai-steer.js`/`ai.js`：并排避让**新增瞄准点层**——把瞄准点拉到"对方横向位置再让开 78px"，权重含**横向接近速度**（按同一台车连续跟踪算，跨车算差值是噪声）；瞄准点限幅 ±0.72 半宽（叠满内切+走线+绕行+避让原可达 ±137px，比墙面还外，是低速绕行撞墙主因）

**踩过的坑（记下来避免重复）**：
1. 限幅写成 `clamp(bias,±0.72)*140`——bias 已是像素值，等于把所有小幅值放大 140 倍、其余饱和到 ±100，全场贴墙撞车（121 墙/26 车）。正确写法 `clamp(bias, ±0.72*trackHalfWidth)`
2. 避让第一版写 `bias += away*offset`（相对中线推）：双方都偏在一侧时会把两车对着挤。必须"拉到目标位" `bias += (want-bias)*w`
3. `neighbor.closing` 若不按车身份跟踪，最近车在几台车间跳换会算出假收拢速度，避让忽强忽弱（某些种子反而更差）
4. 发车格横向拉开（0.42→0.55 半宽）对撞车没确定性帮助，反而增加撞墙，已回退
5. 对照实验陷阱（沿用）：对照参数要在 startRace 之后改；`hit_trace` 用预分离几何，别拿碰撞后再算的 ahead/side 反推

**结果（5 车 120s）**：L3 急刹 141~170→**44~88px**、跟车 p50 337→**150~250px**、绕行 4→**7~59 次**、名次变化 0→**16~98 次**；L4 169→37~81px；L5 147→60~73px。8 种子复核撞车：L3 中位 ~1（0~12）、L4 0~4、L5 0~4（L3 定位就是"偶有失误"）。均速不降（ai_bench 493.5→498.5）；五挡均速 240/401/481/560/606 仍单调。23 JS node--check、ui_check 29、spectate_check 39、race_end、spectate_race、runtime3（0 NaN）、overtake_bench、minimap_check 全过。README 更新五挡表（跟车/急刹两列）、激进风格、安全覆盖、共享感知、实测数据、参数表。

新工具：`Temp/ot3_bench.js`（插桩测急刹触发间距/跟车间距/绕行发起与收队分类，支持 DRC_ROOT 指向别的项目副本）、`Temp/hit_trace.js`（预分离几何 + 避让 want 复算，撞车前 40 帧轨迹）、`Temp/wall_diag.js`（撞墙时的 lat/速度/绕行状态）。
