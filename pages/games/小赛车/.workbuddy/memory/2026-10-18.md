## 音效返修（倒计时"嘟嘟" + 引擎"嗡嗡"）

反馈：倒计时不是"嘟嘟嘟"而是尖细的"哔"；引擎声不对，应该是赛车"嗡嗡嗡"，且速度越快音调变化越大。

改动（只动 `src/audio/sound.js` + README 描述）：
- 倒计时：新增 `horn()` —— 纯五度双振荡器（锯 392Hz + 三角 588Hz）→ 低通（freq×6, Q1.4）→ 20ms 起音、尾音下滑 7%，所以是圆润的「嘟」；3/2/1 各一声、GO 用 523Hz/0.42s。移除了原来的 620Hz 方波哔声。
- 引擎：去掉 LFO 颤音（那种"突突"像拖拉机），改为两条**固定相差 3.2Hz 的锯齿波**产生持续拍频 → "嗡嗡"；玩家车另加 2f 三角波与 0.5f 正弦；低通 Q 提到 2.2。
- 音高：从线性 `46+132·r^1.25` 改为**指数** `56·2^(3.2r)`（56→约 512Hz，近三个八度），截止 = f×(3.2+6.2r)，越到高速同样的加速带来的频率变化越大。
- `reset()` 里同步停止 osc3（原来的 lfo 已删除）。

验证：mock AudioContext 抓频率写入——倒计时 392/588（尾音 364.6/546.8）；引擎 56/59.2/112/28，随速度按指数上升。

## 音效二次返修：换成"声浪" + AI 油门不再怯场

### 引擎声改成排气脉冲循环
反馈"还是没有声浪"。之前是锯齿振荡器合成（永远是管乐音色），改成经典的循环脉冲法：
- `makeEngineBuffer()` 合成**一个周期**：26 次谐波 × 尖起长落的包络（`exp(-5.2p)`）+ 每周期固定的气流噪声（一阶低通防混叠）+ 第 5 次谐波处的排气共鸣峰，归一化到峰值 0.7 后整周期复制填满 0.6s，循环无缝。
- 播放：每台车一个 `BufferSource`（loop）共享同一 buffer，`playbackRate = 2^(2.6r)`（50→303Hz）；低通 320→4520Hz；节点从 9 个/车降到 4 个/车。
- 倍率上限刻意从 8.6× 收到 6×：再高会把频谱整体上移得太多，像玩具车。

### AI 油门"不敢开全速"
两个原因，都已改（`entities/ai-throttle.js`）：
1. `target *= car.skill` 乘在整个目标上 → 低挡位直道只有 72%~88% 全速（正好是用户说的 5/7）。改成 skill 只乘在 `vCorner`，直道目标 = `maxSpeed × boost`。
2. 目标附近是「97% 全油 / 103% 重刹」二值切换，一次决策持 0.14~0.24s，速度在目标上下甩出上百。改成 `err>90 → 1`，否则 `max(0.08, err/90)`，超过用 `err/200`（最多 -1）。

A/B（同种子 6 组，单台车 40s）：普通挡直道均速 482→575，σ 52→3；赛车手 565→576，σ 30→1.6。六车 120s 均速：228/488/583/619/641（新手→赛车手）。

## 修复位次速度补偿写反 + 改成 (名次-1)×2%

问题：用户感觉第一名反而最快。确认是真 bug——`updateRankBoost` 里
`t = (n - rank)/(n-1)`，rank 1（领先）算出 t=1，拿到最大加成，完全反了。

改动：
- `ai.js` 的 `updateRankBoost(car, dt)`：`want = 1 + C.aiRankStep * max(0, rank - 1)`；去掉不再需要的 `cars` 参数。阻尼不对称：`want < cur` 时 rate 6（抢到名次快速收回），否则 rate 2（掉名次慢慢涨）。
- `constants.js`：`aiRankBoost: 0.20` → `aiRankStep: 0.02`。
- `car.js` 的 `phys()`：限速从软阻尼改成**硬截断** `if (speed > vmax) speed = vmax`（倒车同理）。原因：软阻尼下全油门稳态会超出上限 70~90（12%+），把 2% 的名次差异完整吃掉，这也是"看不出补偿"的第二个原因；顺带让 HUD 速度表与实际极速一致（玩家车就是 580，之前能显示 650+）。
- README / car.js / ai-throttle.js 注释：位次加成 → 位次补偿，同步新公式与硬上限说明。

实测（固定名次、单台车 45s）：名次 1~6 极速精确为 580.0 / 591.6 / 603.2 / 614.8 / 626.4 / 638.0，每级差 11.6 = 2%×580。观战 6 车高速段均速 576.9 / 586.4 / 595.3 / 602.2 / 611.1 / 625.5，严格单调。全模式回归无 NaN、无超上限帧。

注意：硬上限让玩家极速从原来的 ~650 落回 580，整体最高速降约 12%——这是修正而非削弱，speed 单位本就按 580 设计。
