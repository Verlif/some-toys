# 键盘实验室 · 键盘反应测试

> 看按键亮起来，然后快点按下去。

一个纯前端的键盘测试玩具：四种配列随心切换，四种玩法从「随手试手感」到「拼反应」，全程不需要后端、不需要账号。

项目使用原生 ES Module 拆分多文件，没有任何框架与构建步骤。

---

## 快速开始

ES Module 必须通过 HTTP 打开，项目自带零依赖静态服务器：

```bash
node tools/serve.mjs          # 默认 5173 端口
node tools/serve.mjs 8080     # 指定端口
# 或
npm start
```

然后访问 `http://localhost:5173/`。

## 四种配列

主页展示当前配列的大键盘，点「切换配列」轮换：

| 配列 | 说明 |
| --- | --- |
| QWERTY 60% | 最常见的紧凑配列，无功能行 |
| QWERTY TKL | 带 F1–F12 功能行的 87 键 |
| AZERTY | 法语区常用配列 |
| Dvorak | 效率优先的英文配列 |

所有配列共用同一套**物理键位定义**（`code` + 显示文本 + 键宽 + 是否修饰键），切换配列只是换标签，键位几何不变。所以 AZERTY 与 Dvorak 看起来不同，按下的物理键完全一致。

## 四种玩法

| 模式 | 玩法 | 结束统计 |
| --- | --- | --- |
| 自由模式 | 只显示键盘，按下即高亮，无计时无限制 | — |
| 录制模式 | 从第一个按键开始记录「按键 + 与上次的间隔」，可回放、导出 / 导入 JSON | 按键序列与节奏 |
| 单按键挑战 | 3 秒倒计时后，每轮随机等待 0.5~2 秒亮一个键，尽快按下；按错计失误但不中断 | 平均 / 最快 / 最慢反应时间 |
| 连续挑战 | 随机生成一整排按键，从右往左依次敲掉，按错计失误 | 总用时 / 平均每键耗时 |

挑战模式可以调难度：单按键挑战选完成次数（5 / 10 / 20 / 30 / 50），连续挑战选序列长度（5 / 10 / 20）。出题只会用到字母与数字键，保证每题都是单个易识别的字符。

### 录制文件

导出的是字段稳定的 JSON，可以自己写脚本生成后再拖回页面复现：

```json
{
  "version": 1,
  "createdAt": "2026-10-16T08:47:34.000Z",
  "layout": "qwerty60",
  "layoutName": "QWERTY 60%",
  "duration": 5321,
  "events": [
    { "code": "KeyA", "label": "A", "t": 0, "gap": 0 },
    { "code": "KeyS", "label": "S", "t": 214, "gap": 214 },
    { "code": "Space", "label": "Space", "t": 690, "gap": 476 }
  ]
}
```

`t` 是相对起点的毫秒数，`gap` 是与上一次按键的间隔（首条为 0）。回放严格按 `t` 的时间轴点亮，起手额外等 0.5 秒，速度可切 0.5× / 1× / 2×。支持点击选择文件，也支持直接把 `.json` 拖到页面里。

## 操作

| 场景 | 操作 |
| --- | --- |
| 主页 | 按任意真实按键，预览键盘同步高亮（不拦截浏览器默认行为） |
| 切换配列 | 主页「切换配列」按钮，选择会记住 |
| 主题 | 右上角主题按钮，亮 / 暗切换并记住 |
| 挑战中 | `Space` `Tab` `Enter` `Backspace` 与方向键会被拦截，避免滚动页面或切走焦点 |
| 返回 | 游戏内的返回按钮回到选择菜单 |

## 目录结构

```
keyboard-lab/
├─ index.html              主页面（键盘预览 + 配列切换）
├─ pages/
│  ├─ test.html             测试页（选择菜单 + 键盘舞台）
│  └─ about.html            关于页（由元数据渲染）
├─ css/                     base / main / test / about
├─ js/
│  ├─ main.js               主页面入口
│  ├─ test.js               测试页入口（阶段与玩法调度）
│  ├─ about.js              关于页入口
│  ├─ core/                 配列定义、键盘渲染、统计、模式元数据
│  ├─ modes/                自由 / 录制 / 单按键挑战 / 连续挑战
│  ├─ ui/                   选择菜单、组件、结算浮层、主题、背景键流、预览自适应
│  └─ utils/                DOM / 时间 / 数值 / JSON / 本地存储
├─ tools/serve.mjs          零依赖静态服务器
└─ assets/                  静态资源
```

模块之间只通过导出函数与 DOM 契约协作：`core/` 不认识界面，`modes/` 只给出「一局怎么进行」，页面级调度在 `test.js` 里串起来。

## 实现要点

- **键宽即数据**：每个键定义 `w`（以 1 单位键帽为基准的宽度），特殊键（`Shift` / `Space` / `Enter`）自然排布，不用为每种配列写死像素。
- **键盘是画出来的 DOM**，不是图片，因此可以任意缩放、随主题换肤、按键高亮零延迟。
- **背景键流**：主页背景有一层缓慢飘落的键帽，与真实按键的高亮互不干扰。
- **预览自适应**：选择菜单右侧的键盘预览按容器宽度等比缩放，窄屏会收起。
- **状态都收在 utils/storage**：配列、主题、录制设置统一走同一层本地存储，读不到就用默认值。
