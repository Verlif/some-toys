# 扫雷小队 · 迷宫竞速

> 迷宫里到处都是雷，但你有队友。

一款实时合作扫雷迷宫竞速游戏。你和 AI 队友从迷宫左侧出发，穿过布满地雷、伸手不见五指的通道，抵达右侧的绿色出口。扫描、排雷、夺旗都会让全队最终用时变短。

**先到的不一定赢，总耗时最短的队伍才赢。**

---

## 快速开始

ES Module 不能用 `file://` 直接打开，起一个静态服务器：

```bash
# 在项目目录下（或仓库根目录加子路径）
npx --yes serve .
python -m http.server 8080
```

从导航页点进来也可以，同源直接玩。

## 玩法

### 一场比赛由什么组成

| 要素 | 说明 |
| --- | --- |
| 队伍 | 2–5 支，每队 1–5 人，同场最多 25 名角色 |
| 地图 | 57 × 27 格迷宫，左侧 4 列是出发区，多个入口任选 |
| 迷雾 | 初始全覆盖，走过 / 扫过才会散；还会随时间缓慢恢复 |
| 地雷 | 80% 即爆雷，20% 延迟雷（给你 1 秒逃命）；爆炸波及中心与上下左右四格 |
| 出口 | 迷宫右侧，第一个到达的队伍会触发 60 秒倒计时 |

### 三个关键动作

| 动作 | 规则 |
| --- | --- |
| 扫描 | 轻按动作键，0.5 秒出结果，半径 2 格，把圈内标成「已知安全 / 已知有雷」 |
| 排雷 | 扫描结束后继续按住 ≥0.5 秒自动开始，耗时 2 秒，**中途松开即取消** |
| 前进 | `WASD` 自由移动，撞墙就走不动；倒地 5 秒后原地复活并带 2.5 秒无敌 |

爆炸不是纯亏：它会清掉波及格上的地雷，并把结果同步给**所有队伍**的认知——用一条命换一片已知安全区。

### 减秒与计分

| 奖励 | 数值 |
| --- | --- |
| 每面旗（地图上旗数 = 队伍数，全图可见） | 该队**每人**最终用时 −5 秒 |
| 每排掉一颗雷 | 该队**每人**最终用时 −1 秒 |
| 队伍成绩 | 队员用时之和，越小越靠前 |

减秒在结算里统一折算（`js/sim/scoring.js`），不会改动实时计时。

### 双人本地对战

两位玩家可以自由选择阵容：

- **各带一队**：P1 带红队、P2 带蓝队，各自记分，总用时更短的一队获胜。
- **并肩同队**：两人同属红队，共用视野与情报，夺旗 / 排雷减秒共享，成绩合并计算。

并肩同队要求每队至少 2 人，否则该选项自动置灰并退回「各带一队」。

## 操作

| 操作 | 单人 | 玩家 1 | 玩家 2 |
| --- | --- | --- | --- |
| 移动 | `W` `A` `S` `D` | `W` `A` `S` `D` | 方向键 |
| 扫描 | 轻按 `空格` | 轻按 `空格` | 轻按 `Ctrl` |
| 排雷 | 按住 `空格` 2 秒 | 按住 `空格` 2 秒 | 按住 `Ctrl` 2 秒 |
| 暂停 | `Esc` | `Esc` | `Esc` |

回放页里：`空格` 播放 / 暂停，`←` `→` 快进快退 2 秒，`Esc` 返回结算。

## AI 队友在干什么

每队都配 AI 队友，三种职责按局势切换（`js/core/config.js` 的 `AI_ROLES`）：

| 职责 | 行为倾向 |
| --- | --- |
| 冲刺手 | 直奔出口，只在必经之路上排雷 |
| 夺旗手 | 绕路抢旗，超过允许绕路格数就放弃 |
| 排雷手 | 在队伍前进路线上清雷，顺手扩大已知安全区 |

AI 会在关键节点「思考」后行动，而不是每帧反应；决策优先级写在 `js/sim/ai.js`，开发文档第 6 章有完整表。

## 录像与回放

每局结束都能回放复盘：

- 对局中以 **30Hz** 采样实体状态、**5Hz** 采样地形快照（已知信息 / 迷雾 / 路径）。
- 独立回放页：0.5×–4× 倍速、±2 秒快进退、进度拖拽、时间显示，播完自动循环。
- 回放只做数据，渲染层不区分实时对局与回放，所以两边表现完全一致。

## 目录结构

```
index.html              页面骨架 + 各屏幕容器
css/                    base / menu / options / game / overlay / result / replay
js/
├─ core/                配置、状态、画布、工具
├─ world/               迷宫生成、地雷、旗帜、队伍容器、碰撞、寻路
├─ sim/                 规则推进：扫描、排雷、爆炸、AI、计分、录像、回放
├─ render/              只读场景渲染：地块、实体、旗帜、特效
├─ ui/                  菜单、设置、HUD、结算、回放、自适应
├─ input/               键盘映射
└─ main.js              装配 + 主循环
扫雷小队_游戏介绍.md     面向玩家的介绍
扫雷小队_开发文档.md     分层约定、规则细节、算法说明
```

分层依赖只允许向下，无循环引用：

```
core → world → sim → render/ui → input → main
```

## 几个实现细节

- **画布不糊**：逻辑分辨率固定，按设备像素比放大画布实际尺寸，缩放时重绘而不是拉伸位图。
- **布局等比铺满**：可视区按比例适配，超宽 / 超窄屏都不会露出画布外的空白。
- **模拟层不依赖界面**：`stepMatch(dt)` 同时服务正式对局与主菜单背景演示局；一局结束由 `ui/flow.js` 接手。
- **配置唯一来源**：网格、配色、按键、时长、采样率全在 `js/core/config.js`，其它模块不重复定义。
