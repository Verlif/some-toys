# 2026-10-04

## 扫雷小队：单文件 → 多目录多文件重构

- 原 `扫雷小队.html`（约 2000 行，HTML+CSS+JS 三合一）已删除，改为与同级项目（`回声躲猫猫`、`田字木头人`）一致的标准结构：
  `index.html` + `css/*.css`（6 个）+ `js/**`（ES Module，`<script type="module" src="js/main.js">`）。
- 分层：`core`（config/utils/state/canvas）→ `world`（maze/mines/teams/entities/collision/pathfind）
  → `sim`（scan/player/ai/hazard/effects/vision/scoring/simulation）→ `render`（tiles/entities/effects/renderer）
  → `ui`（screens/options/hud/result/flow）→ `input/keyboard` → `main.js`。依赖单向，无循环引用。
- 关键设计：`sim/simulation.js` 的 `update(dt)` 返回 `true` 表示本局结束，由 `main.js` 调 `ui/flow.endGame()`，
  使模拟层不依赖界面层；`ui/result.js` 的按钮回调节由 `flow.js` 注入，避免 UI 内部成环。
- 顺手修复：原版暂停面板的「继续 / 重新开始 / 返回主菜单」三个按钮**未绑定事件**（只有 ESC 能用），重构后已全部绑定。
- 玩法逻辑（扫描 0.5s / 按住 0.5s 接排雷 2s / 60s 结算倒计时等）保持原样未改。
- 校验方式：临时 DOM 桩 + node 跑通模块装配、三种队伍配置各 4000 帧模拟与渲染、结算面板，无异常（临时脚本已删除）。

## 扫雷小队：功能扩展（回放 / 5队5人 / 同队路径 / 菜单动态背景）

- 回放：`sim/recorder.js` 以 30Hz 采实体状态、5Hz 采地形快照（known/fog/trail，约 3~7MB/局），
  采样点必须在 `render()` 之后——此时 unionKnown/displayFog/displayTrail 才是本帧值；
  `sim/replay.js` 只做数据（播放头、倍速、seek、二分定位+线性插值，输出与 game 对齐的 scene）；
  `ui/replay.js` 管画布与控制条（⏸/0.5×~4×/进度拖拽/时间），播完循环。
- 渲染层改造：`render(ctx, scene = game)`，所有 render/* 函数改为接收 scene，
  实时与回放共用同一套绘制代码；`drawEntity(ctx, e, elapsed)` 不再直接读 game。
- 规模上限：队伍 2~5（新增青队 #06b6d4）、每队 1~5 人（同场最多 25 人，spawn 加随机抖动防重叠）。
- 路径：`game.teamTrails[]` 按队伍存 Uint8Array，写入后永不消失；`computeDisplayTrail()`
  只合成玩家所属队伍的路径（每格记队伍号 → 按队伍上色）。已移除旧的 TRAIL_DURATION 淡出逻辑。
- 结算面板重做：两栏（左回放 / 右图表+队伍排名）+ 底部完整统计表；
  真人玩家柱子用 45° 斜条纹（P1 金 P2 粉），AI 用队伍色；新增 6 个概览小卡
  （总时长/到达/排雷/扫描/倒地/探索度）与 9 列统计表。
- 菜单背景：`sim/demo.js` 跑一局全 AI 演示局（构建前后临时切回 settings 以免污染玩家选项），
  视野走 vision.js 的 demo 分支（取 0 号队认知 + 迷雾压暗 DEMO_FOG_SCALE），
  CSS `body.at-menu` 控制 `#menuCanvas` 显示（opacity .3 + blur 3px + 径向暗角）。
- 实体新增 `stats{ minesDefused, scans, downs, distance }`，分别在 scan/hazard/simulation 中累加。
- AI 到达时间实测：首达约 77~98s，配合 60s 结算倒计时，一局约 135~160s。

## 扫雷小队：回放独立成页 + 结算自适应

- 回放从结算面板里的一个小画布，改为**独立全屏页面** `#replayScreen`（新增 `css/replay.css`）：
  顶部标题+说明+返回按钮、中间画布撑满剩余高度（flex:1 + canvas `max-width/max-height:100%`，保持 CW×CH 逻辑分辨率）、
  底部控制条（⏪/⏸/⏩ ±2s、0.5×~4×、进度条、时间、再来一局 / 回主菜单）。
  快捷键：空格播放暂停、←/→ 快进退、ESC 返回；点画布也可暂停。
- `ui/replay.js` 改为 `openReplay({caption,onBack,onRestart,onMenu}) / closeReplay / tickReplay / isReplayOpen`；
  退出去向全部由 `ui/flow.js` 注入（返回结算 = 重新 showOverlay，DOM 不重建），回放页不反向依赖结算。
- 结算面板：移除内嵌回放栏，改为卡片网格 `repeat(auto-fit,minmax(min(100%,320px),1fr))`（宽屏两栏、窄屏堆叠），
  底部加 `🎞 观看回放` 按钮（无录像时 disabled），尺寸统一 `clamp()`。
- 自适应要点：遮罩层用 `align-items:flex-start` + 面板 `margin:auto`（flex 居中 + overflow-y 会把超高内容顶部裁掉）；
  柱状图人数 >12 进 `dense` 模式隐藏次要文字；统计表表头 `position:sticky` + 容器 `max-height:min(46vh,420px)`。
