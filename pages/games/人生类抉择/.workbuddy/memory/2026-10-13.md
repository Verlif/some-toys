## 两个重要发现（都不是本轮引入）

1. **`cond` 只写 `max` 的条件恒不成立**。`rules.js#groupPass` 用 `between(v, min, max, defMin)`，`min` 缺省时补默认下限（技能 50 / 属性 40 / 羁绊 30），于是 `{stat:{id:'money',max:22}}` 变成「≥40 且 ≤22」。受影响的原有事件：`gt_b7`(money max 22)、`gt_b8`(health max 24) —— 两条都从未触发过。想写「低于某值才触发」必须显式 `"min": 0`。已把此坑写进 `docs/05` 的「常见坑」表。

## 修复：滑动卡片后窗口出现横向滚动条

- 根因：`card.js` 拖动时写入 `card.style.transform = translateX(dx) rotate(...)`，飞出时 `.card.out-left/right` 用 `translateX(±130%) rotate(±16deg)`。卡片被平移到视口之外，而 `.cardzone`（`position: relative; flex: 1`）和 `#app`（`min-height: 100dvh`）**都没有裁剪**，于是撑开文档横向可滚区域；而且 `.out-left/right` 类会一直挂到下一次 `resetCard()` 才清，所以滚动条不是一闪而过而是持续存在。
- 改法：`base.css` 的根节点加横向裁剪 —— `html, body { height: 100%; overflow-x: hidden; overflow-x: clip; }`。优先 `clip`：它不创建滚动容器（`overflow-y` 不会被强制算成 `auto`），也不会成为 fixed 元素的包含块，所以底部标签栏 / 上浮浮窗 / Toast 的定位不受影响；`hidden` 放前面只作旧浏览器兜底。
- 为什么不在 `.cardzone` 上裁：`.cardzone` 底边基本就是卡片底边，`overflow: hidden` 会把卡片自身的 `--sh-card`（向下 12px + 28px 模糊）切掉；同时 `.peek` 浮窗的阴影也会被切。根节点裁最干净。
- 竖直方向暂未处理：卡片下方还有 `.choices` 一行 + `body.in-game #app` 的 80px 底部内边距，16° 旋转带来的约 67px 溢出被吸收掉了，理论上不会出现纵向滚动条。若后续真出现再单独收。
- 校验：五个 CSS 文件花括号配对（11/11、65/65、77/77、66/66、40/40）；确认 `src/js` 里无人读取 `scrollLeft / scrollX / scrollTo / pageXOffset`，裁掉横向滚动不会影响任何 JS；`responsive.css` 未覆盖 html/body 的 overflow。

## 修复：PC 下右滑文本跑到侧栏右边

- 根因：`.peek` 是 `position: absolute`，参照物是 `.cardzone`（`position: relative`）。而 `responsive.css` 从 720px 起把 `.cardzone` 改成 `flex-direction: row`，卡片 `flex: 1.55`（1024px 起 1.6）、侧栏 `.sideinfo { flex: 1 }`。于是 `.peek.right { right: 10px }` 落到**侧栏的右边**，`.peek.left` 同理偏到整块卡片区左侧；`max-width: 44% / 40%` 也是相对卡片区而非卡片。窄屏（column）下看不出问题，所以只在 PC 暴露。
- 改法：给卡片 + 两个浮窗加一层与卡片同宽的定位容器 `div.cardcol`（**不能塞进 `.card` 里**，因为 `.card` 是 `overflow: hidden`，浮窗和阴影会被切）。
  - `index.html`：`<div class="cardcol">` 包住 `#card` + `#peekL` + `#peekR`，`.sideinfo` 留在外面。
  - `layout.css`：基础规则 `.cardcol { min-width: 0; display: flex; flex-direction: column; }`，**故意不带 `position`** —— 窄屏保持 `static`，浮窗参照物仍是 `.cardzone`，纵向位置（`top: 26%`）与原来完全一致，避免回归；`.card { flex: 1 1 auto; width: 100%; }` 顶替原来靠 `align-items: stretch` 撑高的效果。
  - `responsive.css`：720px 档 `.card { flex: 1.55 }` → `.cardcol { position: relative; flex: 1.55 }`；1024px 档 `.card { flex: 1.6 }` → `.cardcol { flex: 1.6 }`。
- 校验：HTML div 开闭 65/65 配对；用嵌套深度扫描确认 `.cardzone`=2 → `.cardcol`=3 → `card`/`peekL`/`peekR`=4，`.sideinfo`=2（与 `.cardcol` 同级，确实在外面）；五个 CSS 文件括号配对；`src/js` 无人依赖 `.card` 的父级结构（只有 `views.js` 用了无关的 `closest('.aspcard')`）。
