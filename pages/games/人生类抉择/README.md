# 人生模拟 · 左右抉择

> 左右滑动，做一生的决定。每一项都别太满，也别见底。

一个纯前端、零依赖的卡牌式人生模拟小游戏。你从 6 岁开始，每张卡牌都是一个人生岔路口——左滑或右滑作出选择，每个选择消耗一年人生。六项属性中任意一项归零或爆表，人生就此落幕；活到 80 岁，则收获「圆满人生」。

设计参考《王权》(Reigns) 的卡牌抉择手感，叠加《模拟人生》的底层数值模型。

---

## 快速开始

```bash
npm run dev       # 启动本地服务器（零依赖，用 Node 内置模块实现）
# 打开 http://localhost:5173
```

> ⚠️ 本项目使用原生 ES Modules + `fetch` 加载剧本，**不能用 `file://` 直接双击打开**。
> 直接打开时页面会给出明确提示。也可以用 `python -m http.server 5173` 代替。

自检脚本（加载剧本 + 校验数据 + 跑通一局 + 验证可复现）：

```bash
npm run check
```

## 怎么玩

| 操作 | 说明 |
| --- | --- |
| 左右滑动卡牌 | 作出抉择（滑动距离超过 70px 生效） |
| 点击卡面下方两个按钮 | 同上，等价于左右滑 |
| 悬停 / 按住按钮或方向键 | 预览该侧浮窗，看清选项文本 |
| 键盘 `←` / `→` | 同上，桌面端最快 |
| 顶栏四个图标 | 声音开关 / 人生档案 / 抉择履历 / 重新开始 |

滑动时卡片两侧会浮出**选项浮窗**：透明度与大小跟着手指距离走，达到可触发距离时整块高亮反色并提示「松手即选」，不用猜自己滑够了没有。

### 界面构成

- **属性条**：六项属性各占一格，条上加高、带高光，并画出警戒刻度线（黄线=提醒区间，红线=危险区间）
- **常驻旁白条**：固定高度、不会把下方卡片顶上顶下。开局播报「你出生了」，选择后播报「你选择了 X」和各项变化，其余时刻播报里程碑、危险告警或阶段状态
- **卡片区**：手机上贴着屏幕底部，方便单手操作；平板与 PC 上则与右侧「大事记 / 心愿」栏并排

### 六项属性

| 属性 | 含义 | 归零(0)结局 | 爆表(100)结局 |
| --- | --- | --- | --- |
| ❤️ 健康 | 身体本钱 | 病榻尽头 | 养生反噬 |
| 😄 心情 | 精神状态 | 心灰意冷 | 乐极生悲 |
| 💰 金钱 | 物质基础 | 一贫如洗 | 富贵险中求 |
| ⚡ 精力 | 行动力 | 油尽灯枯 | 躺平成仙 |
| 👥 社交 | 人际关系 | 孤岛余生 | 热闹过载 |
| 💼 事业 | 社会成就 | 职场出局 | 高处不胜寒 |

**唯一的通关条件是「平衡」**：任何一项都别让它见底，也别让它顶满。

### 隐藏系统

- **性格特质**：开局随机抽两项（乐天派 / 工作狂 / 社恐 / 节俭 / 健身狂 / 吃货 / 学霸 / 冒险家），会改变属性变化的结算系数
- **五项技能**：学识 / 厨艺 / 运动 / 魅力 / 手巧，随抉择累积，是部分事件的触发门槛
- **三段羁绊**：亲情 / 友情 / 爱情，影响婚姻、生育、养老等事件链
- **人生心愿**：开局四选一（财富自由 / 家庭美满 / 事业有成 / 长命百岁），达成后额外加心情并写入大事记
- **大事记**：结婚、生子、买房、创业、退休…… 会实时记入侧栏与结局时间轴

### 结算

结局页会给出六维终值、一生大事记时间轴，以及一个综合评分：

```
人生得分 = 六项属性之和 + 大事记条数 × 6 + 终年年龄
```

- ≥ 430 传奇的一生
- ≥ 350 美满的一生
- ≥ 280 有滋有味的一生
- 其他 平凡的一生

## 剧本即数据

游戏里**没有任何硬编码的内容数据**。属性、特质、心愿、结局、193 条抉择全部是 `data/` 下的 JSON：

```
data/
├── manifest.json        启动清单（登记要加载哪些文件）
├── init/                初始设置
│   ├── meters.json      六项属性 / 人生阶段 / 五项技能 / 三段羁绊
│   ├── config.json      初始数值 / 调参 / 评分区间 / 状态名 / 人生标记
│   ├── traits.json      8 种性格特质
│   ├── aspirations.json 4 种人生心愿
│   └── endings.json     13 种结局文案
└── choices/             193 条抉择，按阶段与主题分成 12 个文件
    ├── childhood.json   童年 6-11    16 条
    ├── youth.json       少年 12-17   16 条
    ├── adulthood.json   青年 18-29   21 条
    ├── prime.json       中年 30-49   26 条
    ├── senior.json      知命 50-64   18 条
    ├── elder.json       晚年 65-85   20 条
    ├── common.json      全年龄通吃   14 条
    ├── trait.json       特质专属      8 条
    ├── gated.json       技能 / 状态门槛 10 条
    ├── pet.json         宠物链       12 条  ← 组合卡牌
    ├── family.json      家庭链       17 条  ← 组合卡牌
    └── career.json      事业链       15 条  ← 组合卡牌
```

### 组合卡牌链

一部分卡牌只在**你先做出过某个选择**之后才会出现，用人生标记（flag）串联：

| 链 | 入口 | 解锁的后续 |
| --- | --- | --- |
| 🐱 宠物 | 收养流浪猫 / 接手朋友的狗 → `pet`（并分出 `petCat` / `petDog`） | 拆家、遛狗、生病、变老、走丢、绝育、拍照、离世、闯祸 |
| 💍 家庭 | 心动 → `metLove`，求婚 → `married`，生孩子 → `hasChild` | 见家长、同居、家务、夜哭、学区房、空巢、抱孙辈、金婚、离婚 |
| 💼 事业 | 下海 → `biz`，盈利 → `bizSuccess`，失败 → `bizFail` | 找合伙人、天使轮、上线、上市、东山再起、过劳、返聘 |

也就是说，**养了狗之后才会遇到与狗狗相关的抉择**；没创业就永远不会碰到融资。`npm run check` 会校验每条链都「入口能拿到标记、后续卡牌依赖它」，防止写出永远走不到的死链。

启动时 `core/loader.js` 读 `manifest.json`，把清单里的文件全部 `fetch` 进来合并，交给 `core/registry.js` 装进运行时数据库。**加一个新文件只需在 manifest 里登记一行，不用改代码**。

想加事件、改数值、换文案，直接编辑对应的 JSON 刷新即可。详见 [docs/05-剧本文件编写规范.md](./docs/05-剧本文件编写规范.md)。

> 卡面不使用任何外部图片，头部是纯 CSS + 内联 SVG 绘制的人物标识——游戏可以在完全离线的环境下运行。

## 技术选型

- **原生 ES Modules**，无构建步骤、无框架、无第三方依赖
- **剧本数据 JSON 化**，运行时 `fetch` 加载，内容与代码彻底分离
- **CSS 自定义属性**做设计令牌，媒体查询集中在一个文件
- **三档响应式**：手机（卡片贴底单栏）/ 平板（双栏）/ PC（更宽容器与侧栏）
- **WebAudio 现场合成音效**，不加载任何音频文件
- **零外部图片**，卡面人物标识由内联 SVG 绘制
- **localStorage** 存档，自动续玩

整个项目可以直接丢到任意静态托管上（GitHub Pages / Vercel / OSS），不需要构建。

唯一的外链是标题字体（`ZCOOL KuaiLe` / `Noto Sans SC`），加载失败时会自动回退到系统字体，不影响游玩。
