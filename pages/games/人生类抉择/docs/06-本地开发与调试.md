# 06 · 本地开发与调试

## 起服务

```bash
npm run dev
# → http://localhost:5173
```

`tools/serve.mjs` 用 Node 内置模块实现，零依赖。想换端口：

```bash
PORT=8080 npm run dev
# 或直接指定根目录
node tools/serve.mjs ./dist
```

其他等价方式：

```bash
python -m http.server 5173
npx serve -l 5173 .
```

## 为什么不能双击 index.html

两个原因，都会导致白屏：

1. 项目用原生 `<script type="module">`，`file://` 协议下所有 `import` 会被 CORS 拒绝
2. 剧本数据用 `fetch('data/...')` 加载，`file://` 下同样被拒绝

为此 `index.html` 里留了一段**传统脚本**（非 module，在 `file://` 下依然执行）检测协议，命中就显示引导页：

```html
<script>
  if (location.protocol === 'file:') {
    document.getElementById('bootError').classList.add('show');
    document.getElementById('app').style.display = 'none';
  }
</script>
```

剧本加载失败（404、JSON 语法错、manifest 缺字段）也会复用同一层提示，并把具体错误写进 `.detail`——**白屏时先看这一层的文字**。

## 控制台调试

`window.__LIFE` 暴露了控制器内部与剧本数据库：

```js
__LIFE.state            // 当前局完整状态对象 S
__LIFE.state.stats      // 只看六项属性
__LIFE.state.milestones // 大事记
__LIFE.state.log        // 抉择履历
__LIFE.current          // 当前卡牌事件对象
__LIFE.resolve('left')  // 手动执行一次左滑
__LIFE.startNew('rich') // 开一局指定心愿的新人生
__LIFE.db               // 加载后的全部剧本数据
```

启动成功时控制台会打印一行加载摘要：

```
剧本加载完成：19 个文件，618 条抉择，8 种特质，4 种心愿
```

实用技巧：

```js
// 把某项属性直接拉到危险区，测试告警样式与结局
__LIFE.state.stats.health = 3

// 跳到某个年龄，看该年龄段的事件池
__LIFE.state.age = 30; __LIFE.resolve('left')

// 查看某年龄有多少张卡可抽
__LIFE.db.events.filter(e => e.min <= 30 && e.max >= 30).length

// 查看某个心愿的达成条件
__LIFE.db.aspirations.family.check

// 直接给自己打标记，验证组合链后面的卡牌（养狗之后才会遇到的那些）
__LIFE.state.flags.pet = true; __LIFE.state.flags.petDog = true
__LIFE.resolve('left')   // 下一次抽卡就有机会抽到 pt_* 系列
```

## 三档响应式断点

所有 `@media` 集中在 `src/styles/responsive.css`，改布局只动这一个文件：

| 断点 | 设备 | 布局 |
| --- | --- | --- |
| `< 720px` | 手机竖屏 | 单栏；属性条 3 列两行；卡片**贴屏幕底部**，操作提示移到卡片上方 |
| `720px ~ 1023px` | 平板 / 手机横屏 | 属性条 6 列一行；卡片与右侧「大事记 / 心愿」栏并排 |
| `≥ 1024px` | PC 浏览器 | 更宽容器（1080px）、更大字号与卡片、按钮 hover 高亮、浮窗放大 |
| `≥ 1440px` | 超宽屏 | 限制到 1180px，避免卡片被拉成一条 |
| `高度 ≤ 620px` | 手机横屏 | 压缩卡头与留白，隐藏提示行与 chips，同时压扁底部标签栏 |

底部标签栏只在游戏页出现（由 `body.in-game` 控制），游戏页的 `#app` 会自动留出底部安全区，卡片不会被压住。

调试方法：Chrome DevTools 设备工具栏切 iPhone / iPad / 自定义宽度即可；拖动窗口宽度能直接看到断点切换。

## 逻辑自检

```bash
npm run check
```

不需要浏览器，直接在 Node 里跑。它**复用浏览器同一套 loader**，只是把 `fetch` 换成了 `fs.readFile`，加载与校验路径完全一致：

```
[1] 剧本加载
  ✓ 19 个 JSON 文件加载完成
  ✓ 618 条抉择 · 6 项属性 · 8 种特质 · 4 种心愿

[2] 数据校验
  ✓ 六项属性的 high/low 结局 + win 结局齐全
  ✓ 618 条事件合法（id 唯一、选项完整、无任何外部资源引用）
  ✓ cond / check 条件键全部合法

[3] 引擎跑通一局
  ✓ 一路左滑：第 33 回合、38 岁结束 → 「热闹过载」
  ✓ 求生策略：第 74 回合、80 岁结束 → 「圆满人生」，得分 432（传奇的一生）

[4] 相同种子可复现
  ✓ seed=777 两次运行的履历与终局数值完全一致

[5] 组合链可达性
  ✓ 24 个被依赖的人生标记都有来源，组合链不会走进死路
  ✓ 宠物链完整：能拿到「pet」，且有依赖它的后续卡牌
  ✓ 家庭链完整：能拿到「married」，且有依赖它的后续卡牌
  ✓ 事业链完整：能拿到「biz」，且有依赖它的后续卡牌

[6] 心愿判定
  ✓ 心愿「财富自由」在满足条件时判定为达成

[7] 事件规模与单局去重
  ✓ 中年（30-49）310 条可抽事件，覆盖 20 年
  ✓ 40 局随机试玩：单局内零重复事件
  ✓ 40 局共触达 425 / 618 条不同事件
```

第 7 步是数据扩容后加的：它按人生阶段统计事件池深度，再跑 40 局随机试玩，逐局核对**同一局内不出现重复卡牌**。新加事件时如果忘了写 `once: true`，这一步会报错。

**改完 `data/` 或 `core/` 一定要跑一遍。** 尤其是加了新剧本文件之后。

要在 `tools/check.mjs` 里加自己的检查项，直接在对应编号段落里追加即可——它已经 import 了 `db` 与引擎的全部出口。

## 常见坑

| 现象 | 原因 | 排查 |
| --- | --- | --- |
| 页面全白 | `file://` 打开 | 看是否显示了引导页；改用 `npm run dev` |
| 页面显示「剧本加载失败」 | JSON 语法错 / 404 / manifest 缺字段 | 提示层 `.detail` 里有具体错误；JSON 不支持注释和尾逗号 |
| 新剧本文件没生效 | 忘了在 `data/manifest.json` 登记 | 加到 `init` 或 `choices` 数组 |
| 控制台 `Failed to resolve module specifier` | import 路径写错或漏了 `.js` 后缀 | ESM 必须写完整扩展名 |
| 改了 CSS / JSON 没生效 | 浏览器缓存 | `serve.mjs` 已设 `no-cache`；硬刷新 Ctrl+F5 |
| 加了事件却不出现 | 年龄区间 / cond 不满足 | 跑 `npm run check`；用 `__LIFE.state.age` 跳到该年龄段 |
| 组合链后续卡牌死活抽不到 | 入口 flag 没拿到，或 flag 名拼错 | 在控制台直接置 `__LIFE.state.flags.xxx = true`；对照 `config.json` 的 `flags` |
| 滑动浮窗不显示 | 拖动距离太小，或 `busy` 期间 | 需超过 ~10px 才渐显，超过 `swipeThreshold`（70px）才高亮 |
| 旁白条不播报 | 正常：它只在开局 / 选择后 / 里程碑 / 告警时更新内容 | 其余时刻显示阶段状态，不会消失 |
| 音效没声音 | 未发生用户交互 | 浏览器 autoplay 策略：点击一下页面再试 |
| 存档读不出来 | localStorage 被禁用或数据损坏 | 无痕模式会禁用；`loadGame()` 失败会返回 null，属正常降级 |
| 滑动没反应 | 手指移动距离不足 | 需超过 `tuning.swipeThreshold`（70px） |

## 部署

纯静态，直接把整个目录丢到任意静态托管即可：

```bash
# GitHub Pages / Vercel / OSS / Nginx
# 必须上传：index.html + src/ + data/
# 可以不上传：docs/  tools/  package.json
```

不需要构建、不需要环境变量、不需要服务端。

⚠️ 部署后如果 `data/` 没被一起上传，页面会显示「剧本加载失败」——这是最常见的部署事故。
