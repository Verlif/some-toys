## 四条硬约束

1. **内容不进代码。** 属性、特质、心愿、结局、抉择一律写进 `data/` 下的 JSON。代码里只允许出现「写代码必需的常量」。
2. **`core/` 不许碰 DOM。** 规则层必须是纯函数，这样 `npm run check` 才能在 Node 里直接跑通。
3. **`ui/` 不许写业务规则。** 渲染层只负责把状态画出来，任何数值计算都回 `core/`。
4. **UI 只从 `core/engine.js` import。** engine.js 是唯一对外出口，内部模块可以随意重构。

违反这些，工程很快就会退化回「一个 1100 行的单文件」。

## 40 秒上手

```bash
npm run dev      # 起服务 → http://localhost:5173
npm run check    # 剧本 + 逻辑自检
```

改一条事件文案：`data/choices/` 里找到对应文件，改 JSON，刷新浏览器。
加一个新剧本文件：写好 JSON，在 `data/manifest.json` 里登记一行。
