# 🌾 西米的农场

一个温暖的网页农场小游戏。种地、照料、收获，去邻居家串门、偷菜、喂狗，买张藏宝图挖限定种子，每天和 32 位邻居比比排行榜。

**打开就能玩**，不需要注册、不需要下载。存档保存在浏览器本地（IndexedDB），关掉页面下次接着玩。

> 玩法参考 3G 时代腾讯网页家园的经典《阳光牧场》，用原生 HTML/JS/CSS 重制。
>
> **《西米的农场》** · 正式更名，原名「阳光牧场 · 文字版」。

---

## 🎮 怎么开始

1. 用浏览器打开游戏页面（推荐 Chrome / Safari）
2. 选一颗种子，种进地里
3. 浇水、捉虫、等它成熟
4. 收获 → 卖钱 → 买更好的种子 → 扩大地盘

就这么简单。随着等级提升，会解锁更多玩法：

## 🌱 种植系统

| 你关心的 | 说明 |
| --- | --- |
| **作物** | 220 种（165 商店 + 55 限定），6 种原型：速生 / 丰产 / 精品 / 慢生 / 多茬 / 常规 |
| **照料** | 浇水加速 20%；捉虫每只 +10% 产量（上限 50%）；欠水 −15%、欠虫 −40% |
| **土地** | 8 档（普通 → 红 → 黑 → … → 神话），逐级晋升，高阶地产量/速度/经验全提升 |
| **地块** | 开局 6 块，用金币买更多，最多 40 块 |

## 🐕 守护犬

养一条看家护院的好狗！10 个犬种从比熊（20% 拦截率）到龙犬（80%），选一只上岗。

- 狗粮槽全窝共享，上岗时慢慢消耗
- 拦截率 = 犬种基础 ×（0.5 + 0.5 × 饱腹度 / 100）
- 被抓住的偷菜贼：罚款 = 售价 × 5，好感度大幅下降
- 也可以给邻居的狗添粮（好人有好报）

## 🤝 邻居与偷菜

32 位邻居各有性格（热心 / 精打细算 / 爱占便宜…）、等级、财富和好感度（-200 ~ 200）。

- **帮忙**：帮邻居浇水 / 杀虫涨好感
- **送礼**：送仓库里的产出，好感按作物等级涨
- **偷菜**：每块地每轮偷 1 个，成功不掉好感，但被狗抓住就惨了
- **好感 ≥100**：NPC 会优先来你家帮忙、按性格送礼

## 🧭 冒险

买藏宝图去寻宝！5 个等级档位，等级和金币都要达标。

- 走格子收集：金币 / 道具 / **限定种子** / 稀有犬种
- 限定种子商店买不到，只能从藏宝图里挖

## 🏘 村镇联机

同一 WiFi 下填相同村镇名就能和朋友见面！

- 访问真人农场：帮忙 / 偷菜 / 送礼 / 喂狗
- 主人权威防作弊，三段握手送礼防双花
- 需要 `https` 或 `localhost` 环境（浏览器安全限制）

## 🏆 每日排行榜

**一期 = 昨天 14:00 → 今天 14:00**，今天下午 2 点开奖，前三名有奖（并列都发）：

🏅 最友善 · 🐕 狗狗王 · 🌾 打理王 · 🎁 送礼达人 · 🐝 农事劳模 · 🗺️ 冒险王（×5 档）

排行榜页上每一张榜都标着统计区间（如「10/22 14:00 → 10/23 14:00」），
下面是本期的实时排名（今天 14:00 → 明天 14:00），只展示不计奖。

⚠️ 上午干的话算进「昨天」那一期（14:00 切日的必然结果）：10/23 09:00 的收成，
记在 10/22 那一期里，当天 14:00 跟着一起开奖。

## 📖 图鉴与称号

- **收集** = 产出进过仓库；**点亮** = 做过标本（消耗 50 个产出）
- 220 种作物的图鉴卡片，彩色 = 已点亮、灰色 = 已收集、❔ = 没见过
- 38 个称号等你拿（收获量 / 偷菜数 / 好感度 / 图鉴…）

## 🏭 种子制造间

Lv.5 解锁。把仓库里的产出换回种子（消耗产出 + 工本费），限定作物不能造。

## 🔧 技术说明（开发者向）

纯前端零构建：原生 ESM + IndexedDB + WebRTC P2P。开发文档在 [docs/](./docs/README.md)。

```bash
node server.mjs        # 本地开发，http://localhost:5173
npm run start:https    # 局域网联机（自签证书）
npm run check          # 静态校验（零依赖）
```

支持 PWA：可「添加到主屏幕」离线游玩，iOS 建议添加以避免 Safari 7 天清理存档。
