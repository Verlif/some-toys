# 阳光牧场 · 文字版

一个零构建的原生 ESM 网页小游戏，玩法参考 3G 时代腾讯网页家园的《阳光牧场》：
种地、照料、收获、逛邻居家偷菜、喂守护犬，还能买藏宝图去挖限定种子。
存档落在浏览器 IndexedDB，不需要服务器。

> 原始版本是 1368 行的单文件 HTML，现已重构为规范的多目录多文件工程。
> 历史文件保留在 `archive/legacy-single-file.html` 供对照。

📖 **开发文档在 [docs/](./docs/README.md)，按模块分成 12 份**，改动前建议先看对应那篇。

## 快速开始

```bash
node server.mjs        # 或 npm start，默认 http://localhost:5173
node server.mjs 8080   # 指定端口
npm run check          # 静态校验（9 项，零依赖）

静态校验管不到运行时。真实 Chrome 跑的端到端校验覆盖 **26 步表层交互 + 15 步完整游戏循环 + 18 步功能回归**
（播种 → 浇水 → 施肥 → 收获 → 铲除 → 卖出 → 买种 → 升级土地 → 偷菜 → 喂狗 → 刷新持久化 → 触摸下拉关闭）。

它抓出过好几个静态校验漏掉的 bug，包括「拖拽手势把弹窗甩飞」这种桌面端必现的问题。
脚本不进仓库（项目坚持零依赖），跑法见 [docs/11-端到端校验.md](./docs/11-端到端校验.md)。

# 静态校验（零依赖，不启动任何服务）
```

项目是原生 ESM，**必须经由 http(s) 打开**，`file://` 下会被浏览器的模块 CORS 策略拦住。

## 分层约定

依赖方向是单向的，不能逆向引用：

```
ui  →  store  →  core  →  （浏览器 API）
 └──→  data（纯配置与规则，谁都可以读）
```

- **core** 只跟浏览器打交道，不认识任何游戏概念；
- **store** 是唯一允许改状态的地方，改完必须落盘；
- **ui** 不保存任何业务状态，只做「读 state → 渲染 → 把点击转给 store」；
- **data** 只有常量与纯函数，调数值时唯一需要动的目录。

领域层需要给玩家提示时，走 `store/notify.js` → 事件总线 → `ui/toast.js`，
这样 store 全程不引用任何 DOM 符号。

# 数值平衡

作物、土地、地块、经验这四张表由 `tools/gen-data.mjs` 统一产出：

```bash
node tools/gen-data.mjs
```

生成器里带自校验，任何一处数值失衡（等级倒退、售价倒挂、重复命名、
阶段未配齐）都会直接报错并拒绝写文件。

## 核心思路：经验曲线是累加的

升级所需经验只跟等级有关，与作物、土地、地块数的平衡改动互不影响：

```
升到下一级所需 = 200 × 当前等级 + 上一级所需的经验
```

即 `100 × 等级 × (等级 + 1)`：Lv1→2 要 200，Lv10→11 要 11,000，
Lv199→200 要 398 万。每一级都比上一级贵 200，越往后每升一级要种的轮数稳步上升。
满级（Lv200）累计 **2.67 亿**经验。

## 规模

| 项 | 数值 |
| --- | --- |
| 作物 | 200 种（165 常规 + 35 限定），覆盖 Lv1-200 |
| 地块 | 40 块（开局送 6 块，其余铺到 Lv200） |
| 土地 | 8 档（普通 / 红 / 黑 / 白银 / 黄金 / 水晶 / 彩虹 / 神话） |
| 守护犬品种 | 10 个（基础拦截率 20% ~ 80%） |
| 称号 | 26 级阶梯 |
| 等级上限 | 200 级 |
| 满级累计经验 | 约 2.67 亿 |

## 作物解锁节奏

| 等级段 | 每级解锁 | 该段作物数 | 成熟时间 |
| --- | --- | --- | --- |
| Lv1-20 | 2~3 个 | 50 | 40s → 6.4min |
| Lv21-60 | 1~2 个 | 60 | 6.4min → 12.6min |
| Lv64-200 | 每 4 级 1 个 | 35 | 12.6min → 22min |

前期一级只要一两轮收获，后期一级要连续种十几轮 ——
越往后越需要土地升级与多茬作物来提速。

## 生长阶段与多次收获

每个作物按形态（根茎 / 叶菜 / 谷物 / 果实 / 花卉 / 菌菇…）决定一条阶段序列，
序列里每个阶段占整轮时间的比例由 `data/stages.js` 的 `weight` 决定：

```
播种 → 发芽 → 生长 → 开花 → 结果 → 成熟
```

根茎类没有花果阶段，会自动省略。`成熟` 只是「已可收获」的终点标记，
不参与时间分配 —— 否则会出现阶段显示成熟、地块却还不能收的错位。

**多次收获作物**（`harvests > 1`）收获后不消失，而是进入再生轮次：

- 首次成熟 `grow` 秒，之后每次 `grow × regrow` 秒；
- 再生轮次回到「开花 / 结果」阶段，跳过播种发芽，所以时间能显著压缩；
- 第 n 次收获的经验按 `0.8^(n-1)` 递减，与生成器里的收益系数是同一套公式。

| 等级段 | 可收获次数 | 再生系数 |
| --- | --- | --- |
| Lv1-20 | 1（一次性） | 0.50 |
| Lv21-40 | 2 | 0.42 |
| Lv41-70 | 3 | 0.42 |
| Lv71-110 | 5 | 0.35 |
| Lv111-150 | 6 | 0.35 |
| Lv151-200 | 8 | 0.28 |

# 邻居系统

32 位固定邻居，各自有一座会自己生长的农场，性格、职业、作息、手脚干不干净都不一样。

人数不是越多越刺激：偷菜是「先挑农场、再挑地块」，**按地块平摊的话邻居越多，
你自己被偷的概率反而被稀释**。所以玩家农场在挑目标时有 2 倍权重
（`PLAYER_FARM_WEIGHT`）—— 地多招贼，32 位邻居带来的偷窃量大约是 20 位时的 2.4 倍。

## 上线模型

每个 NPC 有自己的上线节奏，分两种：

- **固定钟点**：每天 6 点、18 点各来一次（带 ±30 分钟浮动），像上班一样规律；
- **随机间隔**：每次上线后掷 2~16 小时，晚出晚归。

上线一次先按性格权重做 2~4 件经营上的事（收获 / 播种 / 打理），
有空地就顺手补种，再按自己的偷菜倾向顺一手，热心肠的还会帮玩家照料一块地。

**性格**决定经营行为的权重：勤勉的多种多收，爱钻研的勤打理。
**职业**让每个人有身份：果贩、教师、主播、种粮大户、退休支书……
**偷菜倾向**单独一档：从不偷 / 偶尔顺 / 常去顺 / 见菜就偷。

## 结算时机

邻居的世界**在玩家在线期间也持续推进** —— 每 60 秒结算一次，
所以他们上线时游戏里会弹一条提示（「👋 李大婶、小雨 等 5 位上线了」）。
标签页隐藏时不跑，切回来立刻补一次。

上线之后**动作不是瞬间做完的**：一趟上线被拆成一串动作，每做一件隔 3~7 秒，
你能看着「谁上线了 → 他打理了 4 块地 → 他从你农场顺走了胡萝卜」一件件发生。
每一步都会立刻落盘，这时候关掉页面也不会丢掉已经发生的事。

具体的补算仍然是「按时间差」而不是「按帧推进」，所以没有任何后台定时器：
玩家什么时候打开游戏都不影响邻居的成长节奏。

为了做到「离线多久回来都不卡」，结算分两段：

- **远期**（超过 7 天）：用聚合公式一次性推进等级与财富，不记日志；
- **近期**（7 天内）：逐条执行上线会话，行为写进动态日志给玩家看。

在线轮询与首次进入都用同一个 `settleWorld()`，它**分帧执行**（每帧 12ms）
并用单例 Promise 去重。实测：32 位邻居、离线 1 天到 **10 年**，结算耗时稳定在 1~12 毫秒。

## 邻居会动你的农场

邻居串门时会：

- **顺菜**：从成熟且本轮没被顺过的地里偷走 1 个（你收获时就真的少 1 个）；
- **帮忙照料**：顺手替你浇一块地或捉一次虫（只在成熟前动手）。

这些事会写进**农场日志**（农场页底部「📔 农场日志」按钮，最近 7 天），
结算后也会给一条汇总提示：「🏡 你不在时：被顺走 3 个作物，邻居帮你照料了 2 块地」。

玩家在别人农场上的操作**不写进自己的日志** —— 那份日志记的是「我的农场发生了什么」。

## 守护犬

狗分**三层**，「☰ 其他 → 🐕 狗窝」从上到下就是按这个顺序排的：

1. **品种** —— 十个品种（比熊 20% → 龙犬 80%），决定「这只狗能有多灵」；
2. **上岗** —— 同一时刻只有一只看家，也可以一只都不上岗（那就完全不设防）；
3. **狗粮槽** —— 整个狗窝**共用**一份存货（0~100，每份狗粮 +45，每小时 −6.25），
   **只有有狗上岗时才消耗**，喂满约守 16 小时。

实际拦截率 = 品种基础率 × 饱腹度修正（饿了打对折，空槽直接 0%）。
喂满 100 需要约 2.2 份狗粮（共 100 金币出头）。

**十个品种只能从冒险获得**：低概率、按藏宝图档位分品阶上限、不会重复。
一级图不给狗，二级 15% / 三级 18% / 四级 22% / 五级 30%。
初始赠送最低档的比熊；田园犬在第 7 档（58%），是老玩家才养得起的主力。

点已上岗的那只 = 让它**休息**，农场暂时不设防。

农场页底部常驻一行「🐕 比熊 · 拦截 32%」加一条饱腹条，
不用进狗窝页也知道自家狗什么状态。

**每位邻居也有一条自己的守护犬**，同样有品种（品阶下限钉在 3，
否则「被抓住就封锁全场」这个惩罚就形同虚设）。饱腹度按时间衰减，
上线时按性格决定要不要添食（勤勉的热心，悠闲的懒散）。
偷菜被对方的狗抓住，**那座农场当前所有的作物这一轮都偷不了**（地块右上角标记 🐕）。

被逮住的那一刻，屏幕会整片暗下来**闪一只狗**：那只狗的品种 emoji 从中间弹出来，
写明是谁家的、什么品种（拦截率）、罚了多少金币，1.7 秒后自己淡出（点一下可提前收起）。
偷菜时人正盯着地块连点，顶部那条提示很快就过去了，容易误以为偷成功。

## 偷菜规则

每块地的每轮作物最多被顺走 1 个，作物重新种下后刷新。
被顺走几个就少收几个，不做「产量减半」这种翻倍惩罚。

## 化肥与一键道具

普通化肥有五档：缩短 30 分钟 / 1 小时 / 2 小时 / 6 小时 / 18 小时，
价格 60 / 110 / 200 / 520 / 1300；有机化肥（1800）一键成熟。
点地块上的 🧪 选一档，剩余时间不足一档时会直接成熟，不浪费。
每块地每轮限用一次普通化肥，有机化肥另有一次额度。

**洒水器 / 杀虫剂**（各 200 金币）是一次性道具：背包里有对应道具时，
自己农场底部或邻居弹窗底部会出现「🚿 一键浇水 / 🧴 一键杀虫」，
点一次消耗 1 个道具，把这座农场**所有**需要浇水 / 捉虫的地一次处理完。

**增产剂**分三档（+10% / +20% / +30%，1000 / 3000 / 8000 金币）：
不改成熟时间，只加这一轮的产量。普通化肥、增产剂、有机化肥
**共用同一个额度** —— 一株作物一轮只能施一次肥，三选一。

## 邻居卡上能看到什么

等级、职业、财富（自动转「万 / 亿」缩写）、可偷地块数、待照料地块数，
以及最近 3 条动态；点开详情能看到最近 10 条，包括你自己去帮忙的记录。

```
3小时前  🌾 收获了一批作物，+2.4万 💰
5小时前  🥷 从 李大婶 那儿顺走了 🥕胡萝卜
7小时前  🧹 打理了 3 块地，浇了水也除了虫
```

上线时间不在界面上显示 —— 那是后台节奏，摆出来只会变成一张要一直盯的时间表。

## 邻居互偷

NPC 之间会互相偷菜，被偷的地同样标记 `stolenAt`。
这意味着玩家看到「可偷」的地，随时可能在下一次结算时被邻居抢先。

# 种子制造间

「☰ 其他 → 🌱 种子制造间」。把仓库里的农产品投进去，换回**同种作物的种子** ——
收成卖钱还是留着当种，玩家第一次有了选择。

- **解锁**：农场 Lv.5 + 2000 金币（一次性）；
- **制造**：挑一种够份数的产出，扣掉、摇数量，1 个 80% / 2 个 18% / 3 个 2%；
- **升级**：累计制造次数 + 金币，最高 10 级，满级期望 2.00 个 / 次。

**每次制造要付两笔**：

```js
产出份数 = max(5, ceil(种子价 × 0.2 ÷ 农产品单价))   // 按市价折算
工本费   = 一颗同种作物种子的售价                      // 金币
```

份数按市价折算，是因为农产品单价远低于种子价；固定「5 份」在 Lv1 就是 2.4 倍利润、
到 Lv200 是 12 倍，商店的种子直接没人买。工本费则把「造种子」从印钞机拉回一门生意 ——
玩家得在「花 10 金币买一颗」和「花 5 份产出 + 10 金币造 1~3 颗」之间权衡。

代价是**低等级基本不赚**：一份香菇值 0.18 个种子，5 份 + 1 个种子价的工本费必然倒贴。
Lv1 约 −19%、Lv15 约 −35%，Lv6 以后转正，满级约 +64% —— 制造间的等级因此有了意义。

限定作物（藏宝图那 55 种）**不能制造**。

完整的等级表与数值推导见 [docs/04-数值平衡.md](./docs/04-数值平衡.md#种子制造间)。

# 时报

底部导航第 3 个 tab「📰 时报」是镇上的大新闻板，按时间倒序记录：

- 🎉 谁家的农场升级了（玩家与邻居都记）；
- 🥷 谁偷菜被守护犬当场抓住；
- 💰 谁在藏宝图里挖到大奖（带回价值超过图价两倍才算「大奖」）。

数据存在 `news` 表里（一条一行，`farmId` 标明来源），只保留最近 7 天、最多 80 条，
刷新后照样在。邻居的故事由离线结算补写过去的时间点。

# 图鉴与称号

「☰ 其他 → 📖 图鉴」里是全部 200 种作物。

**点亮图鉴靠做标本**：一份标本要花掉仓库里 **50 个**同样的产出。
库存不够或已经做过时，卡片上根本不显示「制作标本」按钮 ——
做不了的东西不该给人点。收获数与种植数仍会统计，只是不再作为点亮条件。

**称号分三类，条件不同但都要手动领取**：

| 类型 | 数量 | 条件 |
| --- | --- | --- |
| 等级称号 | 26 | 农场等级（新手农夫 → 阳光牧场主） |
| 图鉴称号 | 7 | 点亮的图鉴数量（10 / 30 / 60 / 100 / 140 / 170 / 200 种） |
| 金币称号 | 5 | 当前持有的金币（1 千 → 100 万） |

称号页用 **tab 分成这三组**（tab 上写「已领 / 总数」，有能领的挂红点）——
38 个称号一次摊开，光找「现在能领什么」就得滚半天。

达成条件后去「☰ 其他 → 🏅 称号」领取，奖励**只有道具**（化肥 / 增产剂 /
洒水器 / 杀虫剂 / 特殊种子 / 藏宝图），按称号难度逐级加重。
领到的第一个称号会自动戴上，之后可以随时换着戴，**同时只能戴一个**，
佩戴的称号显示在顶栏。入口上有红点提示有新的可以领。

# 每日签到

「☰ 其他 → 📅 签到」每天固定发三样：

- **普通化肥（缩短 30 分钟）×1**
- **一颗随机商店种子**（等级不高于当前农场等级）
- **少量金币**（连续签到的 7 天循环递增，断签只从第 1 天重新累计，不清零）

**每周六是大奖日**：除了日常奖励，还能开一个盲盒，
从「你当前等级对应的那一档藏宝图」的奖励池里随机抽一份
（等级不够 10 级时，兜底给金币与化肥）。

# 冒险系统

商店里卖 5 档藏宝图（2,500 ~ 40,000 金币，要求 Lv10 ~ Lv50），
在「☰ 其他 → 🧭 冒险」里用掉：

- 一趟有 **档位 × 5 + 10** 次选择机会，每张牌两条路，只有一边藏着奖励；
- 左右滑动（或方向键）选择，退出前会二次确认，已挖到的东西即时落盘；
- 每张图**必出 3 种限定种子**，其余奖励的总价值约为图价的 3 倍；
- 限定种子上限是「需求等级 + 10」，商店种子上限是「需求等级 × 2」；
- 35 种限定作物商店买不到，只能挖；
- **低概率附带一只守护犬**（一级图不给，二级起 15%~30%），
  品阶受图的档位限制，不重复获得，不折算金币。

邻居也会按同样的价格与等级门槛去买图，用算法直接结算收益（但不会抽到狗）。
细节见 [docs/12-冒险.md](./docs/12-冒险.md)。

# 常用扩展

**加一种作物** → 往 `tools/gen-data.mjs` 的 `CATALOG` 里加一行，
重跑生成器。商店、包裹、种子选择弹窗、背包、图鉴位会自动出现，
连等级解锁节奏和经验曲线都会自动重新分配。

**加一档土地** → 改生成器的 `SOILS` 数组。经验曲线会跟着重新反推。

**加一块地** → 改生成器的 `TOTAL_PLOTS`（注意同步调整 `PLOT_UNLOCK_LV` 的分布公式）。

**加一个邻居** → 往 `data/friends.js` 的 `NPCS` 里加一条，或在
`PERSONALITIES` 里定义一种新性格。

**加一个生长阶段** → 改 `data/stages.js` 的 `STAGES`，
并在生成器的 `STAGE_PATHS` 里给对应形态配上新的序列。

**加一个子页面** → 在 `ui/subpages/` 建模块导出 `{ render(body), actions }`，
再到 `ui/subpages/index.js` 注册；最后把 `data/navigation.js` 里对应入口的 `ready` 改成 `true`。

**加一次数据库变更** → 改 `core/db.js` 的 `DB_VERSION` 与 `SCHEMA`，
在 `onupgradeneeded` 里补迁移逻辑。

# 存档说明

数据库名 `sun_farm_v2`，与旧版 `sun_farm_v1` / `homeland_farm_v2` 完全隔离，
旧存档不会被破坏，可以随时回退到 `archive/` 里的单文件版本。

| 表 | keyPath | 内容 |
| --- | --- | --- |
| `farm` | `id` | 每座农场一行：玩家一行 + 32 位邻居。经济、看家狗、成长档案都在这里 |
| `plot` | `[farmId, id]` | 所有农场的地块，按 `farmId` 归属 |
| `log` | `[farmId, seq]` | 所有农场的日志，`seq = 0` 是最新一条 |
| `news` | `seq` | 全镇时报，`farmId` 只标明来源 |
| `inventory` | `itemId` | 种子 / 农产品 / 道具，数量为 `count` |

**没有「只有一条记录」的表**：玩家是 `farm` 里 `kind: 'player'` 的那一行，
地块与日志各自成表、用 `farmId` 关联 —— 农场规模怎么长，
也不会把某一条记录撑成巨无霸。详见 [docs/05-存储层.md](./docs/05-存储层.md)。

背包 key 规则见 `data/keys.js`：`seed_<作物>` 是种子，`crop_<作物>` 是农产品，其余为道具 id。

一次收获会同时改地块、背包、金币、经验，这些改动通过 `storage.commit()` 放在**同一个事务**里提交，
不会出现「钱扣了但没收成」的中间态。

读档时会自动补齐缺失字段（地块的时间戳、邻居的 `dog`、玩家的 `progress` 等），
并把补齐结果原样写回一次。

两处**破坏性的规则变更**（第 15 轮）：

- 施肥额度从「普通化肥一次 + 有机化肥一次」合并成**一株一轮只能施一次**，
  老存档里的 `plot.organic` 在读档时并进 `plot.fert`；
- 图鉴的「点亮」判定从「收获过」改成**做好标本**，所以老玩家的图鉴进度会归零
  （收获与种植统计仍保留），等级称号也需要重新领一次。

# 端到端校验

静态校验管不到运行时。真实 Chrome 跑的端到端校验覆盖 **26 步表层交互 + 15 步完整游戏循环 + 18 步功能回归**
（播种 → 浇水 → 施肥 → 收获 → 铲除 → 卖出 → 买种 → 升级土地 → 偷菜 → 喂狗 → 刷新持久化 → 触摸下拉关闭）。

它抓出过好几个静态校验漏掉的 bug，包括「拖拽手势把弹窗甩飞」这种桌面端必现的问题。
脚本不进仓库（项目坚持零依赖），跑法见 [docs/11-端到端校验.md](./docs/11-端到端校验.md)。

# 静态校验

`npm run check` 会跑 9 项检查，全部零依赖：

1. 每个 JS 文件通过 `node --check`
2. 相对 import 路径能解析到真实文件
3. 具名导入的名字在被导入模块里确实存在
4. `index.html` 引用的脚本与样式都存在
5. `byId()` 用到的 id 在 `index.html` 里存在
6. CSS 与 JS 里用到的 `var(--x)` 都定义过
7. 所有 `data-action` 都有对应的处理器
8. 数据表交叉校验：作物的阶段在阶段表里定义过、作物数 ≥140、地块表与称号阶梯都对齐等级上限、经验曲线严格递增

第 7 条是专门为重构前的 bug 加的：旧版播种弹窗里的按钮没有绑定任何事件，
整个播种流程点不动，现在这种漏绑会在提交前被静态校验直接拦下。

## 后续可以补的玩法（对照《阳光牧场》）

按预期收益排序：

1. **玩家离线收益弹窗** —— 作物本来就在离线生长，但回来时没有任何提示；
2. **天气系统** —— 下雨自动浇水、倒春寒减产、冰雹砸坏地块；
3. **季节与土地状态** —— 荒地需开垦、冬季停产；
4. **狗的养成深度** —— 品种与粮槽已经做完了，缺的是「狗的等级 / 亲密度 / 技能」；
5. **加工坊** —— 农产品加工成高价商品（第 18 轮删了占位入口，还没有实现）；
6. **偷菜反制与好感度** —— 偷多了被邻居反向偷回，或被拉黑。
