# 06 · 领域层

`src/store/` 是唯一的「可以改状态」的地方，纯业务逻辑，**不出现任何 DOM 符号**。

## mutator 与落盘分离

`player.js` 里函数分两类：

```js
// 内存操作，不落盘
export function addCoins(amount) { ... }
export function spendCoins(amount) { ... }
export function addExpRaw(amount) { ... }

// 落盘 + 广播
export async function flushPlayer() {
  await commit({ player: state.player });
  emit(EVENTS.PLAYER);
}
```

分成两半是为了**合并事务**：一次收获里金币、经验、地块、背包的变化
应该进同一个 IndexedDB 事务，而不是各写一次。

`inventory.js` 整体是内存操作（`add` / `take` / `count` / `has`），
落盘交给调用方的 `commit`。

## 等级与上限

```js
export function addExpRaw(amount) {
  player.exp += amount;
  while (player.level < MAX_LEVEL && player.exp >= expForLevel(player.level)) {
    player.exp -= expForLevel(player.level);
    player.level += 1;
  }
  if (player.level >= MAX_LEVEL) player.exp = 0;   // 满级后不累积
  // ...
}
```

两个细节：

1. `while` 而不是 `if`，因为一次收获可能连升好几级。
2. 满级后把经验**清零**而不是留着 —— 否则 `expForLevel(200)` 返回 `Infinity`，
   HUD 会显示 `0 / Infinity`。清零 + HUD 特判「已满级」最干净。

升级时会顺带 `notify` 提示，并统计新解锁的地块数量。

## 地块

### 状态

```js
{
  id, cropId, harvested,
  plantedAt, readyAt, total,
  soil, watered, fert, organic, weed, pest,
}
```

- `plantedAt` / `readyAt` / `total` 是绝对时间戳与当前轮时长，
  所以**关掉页面作物照样在长**，回来时直接看 `readyAt` 判断成熟即可。
- `harvested` 是本轮已收获次数，多次收获作物靠它决定是否还有下一茬。

### 状态机

```js
plotStatus(plot) → 'locked' | 'empty' | 'growing' | 'ripe'
```

`locked` 优先级最高，其次看有没有作物，最后比较时间。

### 再生收获

```js
function beginRegrow(plot, crop, soil) {
  const done = (plot.harvested || 0) + 1;
  if (done >= crop.harvests) return false;         // 次数耗尽

  const regrowMs = Math.max(30_000, Math.floor(crop.grow * 1000 * soil.timeMul * crop.regrow));
  plot.harvested = done;
  plot.plantedAt = Date.now();
  plot.total = regrowMs;
  plot.readyAt = plot.plantedAt + regrowMs;
  plot.watered = plot.fert = plot.organic = false;
  return true;
}
```

返回 `false` 时调用方 `clearPlot(plot)` 把地清空。

### 减产

杂草与害虫各 40% 概率让产量打七折，两个可以叠加：

```js
if (plot.weed && Math.random() < 0.4) { amount = Math.floor(amount * 0.7); penalty += '杂草减产30% '; }
if (plot.pest && Math.random() < 0.4) { amount = Math.floor(amount * 0.7); penalty += '害虫减产30% '; }
amount = Math.max(1, amount);
```

> **已知问题**：目前只有清除逻辑，没有任何地方把玩家地块的 `weed` / `pest`
> 置为 `true`，所以减产对玩家来说是不会触发的死代码。
> 邻居地块因为有「打理」行为，是真的会滋长的。

## 签到

字段：`lastSign`（时间戳）、`signStreak`（连续天数）、`signTotal`（生涯总天数）。

```js
export async function signIn(now = Date.now()) {
  if (signedToday(now)) return false;
  state.player.signStreak = streakBroken(now) ? 1 : state.player.signStreak + 1;
  state.player.lastSign = now;
  state.player.signTotal += 1;
  // 发奖励：rewardFor(signStreak)
}
```

**中断不清零**，只是从第 1 天重新累计 —— 连着签和断着签都有收益，
不会因为断一天就前功尽弃。

日历（`calendarOf`）生成当月网格：周一排第一列，
已签 / 今天 / 过去 / 未来四种状态，每天的奖励对应循环里的第几天。

## 图鉴与新手引导

`codex.js` 同时管这两件事，因为它们都是「记录进度」的领域。

### 统计

统计存在 `player.cropStats`：

```js
player.cropStats = { '小麦': { planted: 3, harvested: 12 } };
```

埋点分布在：

| 位置 | 事件 |
| --- | --- |
| `farm.applyPlant` 之后 | `recordPlanted(cropId)` |
| `farm.harvest` 之中 | `recordHarvested(cropId, amount)` |

**点亮规则**：`harvested > 0` 即点亮。
**解锁规则**：`level >= crop.lv`。

图鉴未点亮的作物以剪影呈现（emoji 打码、名字显示「未收集」），
保留等级作为「下一个目标」的提示。

老存档没有 `cropStats`，统计从接入那一刻开始累积，不追溯历史。

### 新手引导

取代了原来的每日任务。6 个一次性目标，**达成即自动发奖**：

| key | 目标 | 金币 | 经验 |
| --- | --- | --- | --- |
| plant | 第一次播种 | 50 | 20 |
| harvest | 第一次收获 | 60 | 25 |
| sell | 第一次交易 | 50 | 20 |
| steal | 第一次串门 | 40 | 30 |
| upgrade | 第一块好地 | 500 | 80 |
| feed | 第一顿饭 | 30 | 20 |

```js
await completeGuide('harvest');
```

自动发奖的理由：奖励直接绑在业务动作上，玩家不需要记得回来领，
也不会因为漏点而损失。新手引导的目的是带玩家走一遍，不是制造待办。

## 离线结算调度

`social.createSettler()` 返回一个分帧执行器，**落盘与调度分离**：

```js
const settler = social.createSettler();   // 纯计算，store 层
while (!settler.run(12)) { /* 让出一帧 */ }
await social.persistFriends();            // 一次性落盘
```

驱动它的是 UI 层（`views/friends.js`），所以 store 里没有 `requestAnimationFrame`。
模拟引擎本身见 [07-邻居模拟](./07-邻居模拟.md)。

## 新增领域的步骤

1. 在 `store/` 建模块，`import { state } from './state.js'`
2. mutator 只改内存
3. 动作末尾 `commit()` 并 `emit(EVENTS.XXX)`
4. 要提示玩家就 `notify()`，**不要碰 `document`**
5. 新事件名加到 `core/bus.js` 的 `EVENTS`
6. 在 `main.js` 里把新事件接到 `renderCurrent`（子页面需要跟着刷新时）
