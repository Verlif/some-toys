# 01 · 快速开始

## 环境要求

只需要 Node.js ≥ 18（用于开发服务器与静态校验）。**游戏本身没有任何运行时依赖**，
`package.json` 里只有 scripts，没有 dependencies。

## 启动

```bash
node server.mjs          # 或 npm start → http://localhost:5173
node server.mjs 8080     # 指定端口
```

## 静态校验

```bash
npm run check
```

会跑 9 项零依赖检查，详见 [10-静态校验](./10-静态校验.md)。

## 重新生成数值表

```bash
node tools/gen-data.mjs
```

产出 `src/data/{crops,soils,progression}.js`。这三份文件头部都写着「请勿手改」，
要调平衡请改生成器。生成器内置自校验，任何失衡都会拒绝写文件。

## 为什么必须用 http 打开

项目是原生 ESM，`file://` 协议下浏览器会以 CORS 为由拒绝加载 `<script type="module">`。
必须经由任意 http(s) 服务访问。

## 常见问题

**改了代码但页面没变？**
浏览器缓存。`server.mjs` 已设置 `Cache-Control: no-cache`，
若仍有问题请硬刷新（Ctrl/Cmd + Shift + R）。

**旧存档显示异常？**
库名 `sun_farm_v1` 与旧版 `homeland_farm_v2` 完全隔离，互不影响。
`state.js` 里的 `normalizePlot` / `normalizeNpc` 负责给老存档补新字段，
新增字段时记得在那里补一行。

**数据文件能不能手改？**
`crops.js` / `soils.js` / `progression.js` 不行，会被生成器覆盖。
其它 data 文件可以随意改。
