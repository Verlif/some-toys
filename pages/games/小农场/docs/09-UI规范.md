# 09 · UI 规范

## 设计令牌

全部定义在 `styles/base.css` 的 `:root`：

```css
:root {
  --green:    #4caf50;
  --green-d:  #35833a;
  --green-l:  #7cc576;
  --bg:       #eef3e9;
  --card:     #fff;
  --text:     #22301f;
  --muted:    #8a978a;
  --gold:     #f0a92e;
  --line:     #e3e9dd;
  --radius:   16px;
  --danger:   #e05a4e;
  --hud-h:    64px;   /* 兜底值，运行时由 ui/hud.js 量出来覆盖 */
}
```

用 CSS 变量而不是散落的硬编码色值，改主题只需要改这一个 `:root`。

`--hud-h` 特殊：它是运行时测量的，但必须有兜底值，
否则 JS 未执行时依赖它的吸附定位会失效。

## 样式文件分工

| 文件 | 内容 |
| --- | --- |
| `base.css` | 重置、设计令牌、排版基线、`.app` 外壳 |
| `components.css` | 可复用组件：按钮、地块、卡片、弹窗内容、图鉴、日历 |
| `layout.css` | 骨架与浮层：HUD、tabbar、三个浮层、结算画面 |
| `animations.css` | 全部 `@keyframes` |

拆分原则：**按职责而不是按页面**。改一个按钮样式只需要打开 `components.css`，
不会波及别处。

`@keyframes` 集中在一个文件里，引用它们的规则分散在各组件中 ——
这样能一眼看完项目里所有动画。

## 三个浮层

底部浮窗、子页面、模态弹窗共用一套交互规范：

| 特性 | 值 |
| --- | --- |
| 出现方式 | 从底部上滑，`cubic-bezier(.2, .9, .3, 1)`，0.3s |
| 关闭方式 | 点遮罩 / 关闭按钮 / **下拉超过 72px** |
| 圆角 | `24px`（四角，面板不再顶满屏幕） |
| 顶部留白 | `--sheet-top: max(4vh, 28px)` |
| 最大宽度 | 640px（桌面上居中，不会拉成横贯全屏） |
| 阴影 | `0 -10px 40px rgba(0,0,0,.16~.2)` |
| 顶部 | 都有一根 `.sheet-handle` 拖拽指示条 |

三者的 `max-height` 都要减掉 `--sheet-top`（弹窗和浮窗还要减 `env(safe-area-inset-bottom)`），
否则内容一多就会重新顶到屏幕顶端。

最大宽度限制是刻意的：桌面上全屏宽的底部面板会非常难看。

### 弹窗的内部结构

模态弹窗拆成两层：

```
.modal-card          卡片本体：flex 纵向、圆角、overflow:hidden、不滚动
  .sheet-handle      拖拽把手（留在卡片上，不能跟着内容滚走）
  .modal-body        真正的滚动容器，padding 也在这里
```

这样做的原因有两个：把手在滚动时始终可见；「边缘渐隐」的遮罩可以只作用在
`.modal-body` 上，而不会把卡片自己的白色背景一起淡掉。

对应地，`dragToClose()` 的 `scrollArea` 支持传**取值函数**：
每次 `openModal()` 都会重建 `.modal-body`，传元素会拿到上一个已被丢弃的节点，
导致「内容明明滚动过，下拉却仍然直接关闭」。

## 滚动条与边缘渐隐

滚动条在 `base.css` 里全局隐藏：

```css
* { scrollbar-width: none; }
*::-webkit-scrollbar { width: 0; height: 0; }
```

「还有内容」的提示交给遮罩渐隐，只加在真正滚动的容器上：

| 容器 | 渐隐方向 |
| --- | --- |
| `.subpage-body` | 上下各 12 / 18px |
| `.modal-body` | 底部 18px（正好落在 padding 区，不削内容） |
| `.shop-panels` | 左右各 16px |
| 主页面（`.app::after`） | 底部导航上方一条 26px 的定宽渐隐带 —— 农场 / 邻居是**文档滚动**，没法给容器加遮罩 |

> 不要把渐隐加在**有背景色**的容器上（比如 `.modal-card` 本身）：
> `mask-image` 会把背景一起淡掉，边缘看起来像被啃掉一块。

## 安全区

刘海屏 / 底部指示条区域用 `env(safe-area-inset-*)` 避让：

```css
.tabbar      { padding-bottom: calc(8px + env(safe-area-inset-bottom)); }
.hud-bar     { padding-top: calc(11px + env(safe-area-inset-top)); }
#toasts      { top: calc(84px + env(safe-area-inset-top)); }
.sheet-panel { bottom: calc(8px + env(safe-area-inset-bottom)); }
```

`.app` 也要给 tabbar 留出空间：

```css
.app { padding-bottom: calc(78px + env(safe-area-inset-bottom)); }
```

### 卡片网格

| 类 | 用途 |
| --- | --- |
| `.seed-row` | 播种弹窗里的种子条状卡（宽，能摆下各项参数） |

| `.codex-card` | 图鉴卡 |

### 数量步进器（`.qty`）

商店的种子详情弹窗里用：`−` / 数字 / `+`，右侧是购买按钮。

- 数量范围 1~99，按住 `−` / `+` 超过 380ms 进入连发（每 90ms 一次）；
- 连发结束后松手会补一次 `click`，用捕获阶段 `stopPropagation()` 吞掉，
  否则「按住减到 1」会多减一次；
- 按钮要写 `touch-action: none`，不然移动端纵向手势会把按住打断；
- 数量变化只改数字与按钮状态，**不重建弹窗**，否则连发会被自己打断。

### 播种 / 购买的分工

| 位置 | 内容 |
| --- | --- |
| 播种弹窗（点地块） | **只列背包里有存货的种子**，右上角一个「🏪 商店」按钮 |
| 商店种子列表 | 点整行开「种子详情」弹窗，数量在弹窗底部调整 |

商店按钮通过 `emit(EVENTS.NAVIGATE, 'shop')` 请求切页，
`tabs.js` 订阅这个事件 —— 视图之间不互相 import，避免循环依赖。

**统一高度的关键**：卡片是 `display: flex; flex-direction: column`，
按钮用 `margin-top: auto` 顶到底部。这样「偷完之后少了按钮」也不会让
同一行的卡片看起来参差不齐 —— 这是实际踩过的坑。

### 空状态

```html
<div class="empty-tip">🧺<br>仓库里还没有农产品<br>去农场收获一些吧～</div>
```

emoji + 两行文案，第一行说事实，第二行给下一步建议。

## 文本转义

任何来自用户或外部的文本都要转义：

```js
import { escapeHtml } from '../core/dom.js';
els.name.innerHTML = escapeHtml(name);
```

邻居动态里混着 NPC 名字，`views/friends.js` 里有个局部 `escapeText()`
处理 `& < >` 三种字符。

## 响应式

- `.app` 最大宽度 900px 居中；
- 卡片网格一律用 `repeat(auto-fill, minmax(Npx, 1fr))` 自适应列数；
- 农场页地块超过 15 块时切 `.dense` 紧凑模式；
- 三个浮层最大宽度 640px。

## 无障碍

- 顶栏展开按钮有 `aria-expanded`；
- 邻居卡片有 `role="button"` + `tabindex="0"`，并绑定 Enter / 空格；
- 浮层有 `aria-label`。

目前只做到基础级别，详见「后续可补」。
