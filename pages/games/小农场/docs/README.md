# 阳光牧场 · 文字版

一个零构建的原生 ESM 网页小游戏，玩法参考 3G 时代腾讯网页家园的《阳光牧场》。
存档落在浏览器 IndexedDB，不需要服务器。

## 技术栈

- 原生 ESM，零构建，零运行时依赖
- 浏览器 IndexedDB 做持久化
- 无框架、无打包器，`node server.mjs` 起个静态服务器就能跑

## 核心设计主张

1. **数值表由脚本产出** —— 作物、土地、地块、经验、称号全部来自 `tools/gen-data.mjs`，
   手改数据文件会在文件头留下警告。
2. **经验曲线是累加的** —— 升级所需 = `200 × 当前等级 + 上一级所需`，
   只跟等级有关，作物 / 土地 / 地块怎么调都不影响它。
3. **业务逻辑不碰 DOM** —— 领域层要提示玩家时走事件总线，交给 UI 层渲染。
4. **世界状态不用后台定时器** —— 邻居成长按时间差补算，
   「时间到了自然恢复」这类效果用时间戳判定而不是轮询。
   （世界**推进**由一个每分钟的轮询驱动，但**状态变化**全靠时间戳算，不存盘也算不出）
5. **不写测试，只做验证** —— `npm run check` 的 9 项静态检查挡低级错误，
   另有真实 Chrome 跑的端到端校验兜住运行时问题（见 [11-端到端校验](./11-端到端校验.md)）。
   静态校验**抓不到模块内私有函数的丢失** —— 这类问题只有 e2e 能兜住。
