# 局域网联机可行性（基于 webConnect.js）

> 已按本文的 A 案落地了 P0+P1（村镇房间 + 在线名单 + 只读访问），
> 实现细节与踩坑见 [14-村镇联机](./14-村镇联机.md)。本文保留当时的技术判断与备选方案。
>
> 结论先放前面：**能做，但不是「零配置」** ——
> webConnect.js 强制依赖 `crypto.subtle` 与公网信令，所以页面必须是 **https（或 localhost）**，
> 两端也都要**能上外网**。真正断网的封闭局域网跑不起来。

## 一、这个库是什么

| 项 | 值 |
| --- | --- |
| 包名 | `webconnect`（npm），当前 0.0.12 |
| 体积 | 单文件 ESM，未压缩 **437 KB** |
| 传输 | WebRTC **DataChannel**（DTLS 自带加密），Mesh 全网状 |
| 房间 | `appName + channelName + connectPassword` 三件套 |
| 信令 | BitTorrent tracker（WSS）/ MQTT broker / Nostr relay —— **都是公网服务** |
| 加密 | AES-GCM，密钥由 `SHA-256(password:app:room)` 派生，房间名本身还要 SHA-1 |
| API | `webconnect(opts)` → `onConnect / onDisconnect / onReceive / Send / getMyId` |

它替你省掉的只有一件事：**不用自己搭信令服务器**。代价是把「能不能连上」交给了公共 tracker。

### 三个硬前提

| # | 前提 | 为什么 | 现状 / 处置 |
| --- | --- | --- | --- |
| 1 | **页面必须 https 或 localhost** | 连房间时会无条件调 `sha1()` / `genKey()`，`crypto.subtle` 在非安全上下文里是 `undefined`，直接抛错 | `server.mjs` 现在只跑 http。给局域网 IP 访问就必须加 `--https`（自签证书，浏览器点一次「继续前往」）；否则只能双开 localhost |
| 2 | **两端都要能上外网** | 信令走公共 torrent tracker / MQTT / Nostr，没有局域网发现（mDNS）能力 | 家里有宽带就行；纯离线内网不行 |
| 3 | 路由器别开 AP 隔离 | WebRTC 走 host candidate 直连，AP 隔离会让同 WiFi 的两台机器互相不可达 | 普通家用路由默认是关的，一般不用管 |

> 前提 1 是最容易被忽略的坑：`RTCPeerConnection` 本身在 http 下能用，但**这个库的加解密不行**。

## 二、现有代码接得上吗

**好消息**：世界是「时间戳驱动」的，不需要高频同步。地块成熟、缺水、再生全靠
`readyAt / waterNext / waterTimes` 算，两边只要**开一次快照 + 每次操作回一个补丁**，
流量大概是几 KB 级别。

**坏消息**：`state.friends` 这套模型是「本地可写 + 本地模拟」的 ——
几十位 NPC 会被 `settleWorld()` 推进，邻居弹窗里的每个操作都直接改本地存档。
真人邻居**绝对不能**走这条路，否则会被本地模拟算成假数据。

所以最省事的切法：**真人玩家放 `state.peers`（只存内存、不落库、不参与模拟）**，
`getFriend()` 先查 NPC 再回落到 peers。这样 `npc-sim.js` 一行都不用改。

## 三、三个功能具体怎么做

### 1. 上线提醒

`onConnect` 只给一个 `connectId`，拿不到名字 —— 所以要自报家门：

```
A 连上 → A 发 hello{playerId, name, avatar, level, dataVersion}
       → B 收到：列表里插入 A，toast「🌾 小芳 上线了」
A 关页面 → onDisconnect → B toast「🌾 小芳 下线了」，农场转只读缓存
```

坑：

- **刷新页面会先断后连**，别立刻报「下线」，加 8 秒防抖；
- 手机切后台浏览器会冻结 DataChannel，靠 30 秒心跳 + 90 秒判死；
- `dataVersion`（220 种作物那套数据）不一致直接拒绝连接，否则对方作物在我这边渲染成空气。

### 2. 修改用户名

`state.farm.name` 是唯一来源，弹窗、列表、`hello` 都读它，改完广播一次即可，
`inline-tags` 有 `clearTagCache()`，标签立刻跟着变。

**但日志是「渲染时文案」** —— 每条记录存的是 `「王大爷 送来 🌾小麦 ×2」` 这样的字符串，
人名靠 `inline-tags` 扫文本匹配。所以改名只影响以后：
旧日志里的旧名字会失去可点标签（但仍可读）。

想追溯就得改名时把这 60 条历史文案里的人名替换一遍（自己农场 + 邻居提到自己的记录），
能实现，但属于「一次性数据迁移」，不建议放进第一期。

### 3. 访问真人农场（和 NPC 弹窗同一套交互）

| 动作 | 消息 | 权威方做什么 | 发起方做什么 |
| --- | --- | --- | --- |
| 打开 | `req:snapshot` | 回 `farm` 快照 + `serverAt` | 存进 peers 缓存，照常 `openFriendModal` |
| 偷菜 | `req:steal{plotIndex, reqId}` | 判守护犬 → 标记 `stolen` → 算好感 → 回 `{ok, yield, caught}` | 加背包 / 记日志（被赶出来则这趟白跑，不罚款） |
| 浇水·杀虫 | `req:care{plotIndex, kind}` | `serveCare()` 应用 → 回补丁 | 加经验、好感 ±1 |
| 一键照料 | `req:careAll{kind}` | 循环处理 → 回补丁 | 同上 |
| 送礼 | `req:gift{cropId, n}` | 先 `receiveGift` 成功再回 ack | **收到 ack 才扣背包**（否则能刷礼物） |
| 好感 | 动作消息里带 `relDelta` | 各存一份，双方同步 ± | 允许少量漂移，不做强一致 |

几个必须定死的规则：

- **所有请求带 `reqId`**，收到重复的直接返回上次结果（防重发导致偷两次）；
- **送礼先给后扣**，偷菜先扣后给，顺序反了都能刷；
- **离线只读**：对方不在线时用最后一次快照，操作按钮置灰，横幅写「离线 · 3 分钟前的样子」；
- **超时 5 秒**，超时提示「对方没有响应」，不要静默失败。

## 四、风险清单

| 风险 | 影响 | 处置 |
| --- | --- | --- |
| https 门槛（中） | 换 IP 就再点一次证书警告，体验割裂 | 或接受「localhost 双窗口演示」 |
| 公网信令（中） | 公共 tracker 抽风时握手慢甚至失败 | 配多个 relay 兜底；重连退避 |
| 库的维护（中） | 0.0.12、单人作者、437 KB、无类型定义 | vendor 进 `vendor/` 固化版本，不走 CDN |
| 客户端权威（高） | 双方都能改内存，本质是「朋友间玩」不是竞技 | `reqId` 幂等 + 先扣后给 + 不做排行榜 |
| 时钟差（低） | 两端钟差大 → 成熟时间显示不一致 | 快照带 `serverAt`，按差值校正 |
| 掉线（中） | 对方合上笔记本，你正在他农场里点操作 | 5 秒超时 + 明确 toast |
| 版本不一致（低） | 一方旧版本，作物 id 对不上 | `hello` 校验 `dataVersion`，不一致拒绝 |

## 五、备选：本地中继（SSE）

`server.mjs` 已经在跑了，加一条 **SSE（服务端推送）+ POST（上报）** 的房间通道即可：
零依赖、**不需要 https、不需要外网**、天然内网广播，房间号就是 `?room=xxx`。

上层代码与 webConnect 方案**完全一样**（快照、`reqId`、ack、心跳都不变），
差别只在 `net/link.js` 一个文件：约 80 行换成 SSE 版本。

| | A：webConnect.js | B：SSE 中继 |
| --- | --- | --- |
| 需要外网 | 是（信令） | 否 |
| 需要 https | 是（`crypto.subtle`） | 否 |
| 额外依赖 | 437 KB 库 | 0 |
| 延迟 | 同网段直连，最低 | 多一跳服务器，同网段仍是毫秒级 |
| 跨网络（不同 WiFi） | 能（走 NAT 穿透） | 不能，仅同一局域网 |
| 服务器职责 | 无 | 只转发 + 记在线名单，不存农场 |

**折中方案**：先抽好 `link` 接口，A 跑通；将来要「不用 https、不要外网」时只换 `link.js`。

## 六、建议的落地顺序

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| P0 | 传输层 + 房间面板 + `hello`/心跳 | 两台机器能互相看见，控制台能收发消息 |
| P1 | 快照只读访问 + 上线提醒 + 联机横幅 | 能打开真人的农场，看得到在线状态，但还不能动手 |
| P2 | 远程操作（偷菜/浇水/杀虫/送礼/一键）+ 幂等 + 超时 | 交互与 NPC 弹窗一致 |
| P3 | 改名、离线缓存、时钟校正、断线重连、版本校验 | 体验收口 |

P0+P1 约 1 天，能验证「这套连接在你家网络里到底通不通」——**建议先做这一段再决定后面**，
因为 https 与公网信令这两件事，只有真机跑一次才知道顺不顺。
