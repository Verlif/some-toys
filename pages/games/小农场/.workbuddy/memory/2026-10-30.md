## 收尾复查（第二轮：调整 + 找遗漏）

审查了全仓所有 `commit({...})` 调用点（store 层 14 个模块），结论与改动：

1. **抽 `state.js` 的 `farmRows(...)`**：批量落盘统一走它（自动追加 commons、去重、滤空值），
   以后再加第四类数据只改一处。三个批量出口：`social.persistFriends` /
   `daily.persistNow(true)` / `social.runLiveStep`。
2. ⚠️ **第三处真遗漏**：`runLiveStep`（在线演出单步提交）原来 `farms: [state.farm, npc, ...extra]`，
   演出队列里排着 `commons` 动作时会漏 —— 账本留在内存，重开能再拿一遍。
3. ⚠️ **`commonsSnapshot()` 不再播种**：它是 `renderCenter` 每 tick 调的渲染函数，
   在里面写 `plantedAt` 又不落盘 = 「刚才明明是西瓜，回来变成萝卜」。
   播种移到 `advanceCommons` 与 `openCommonsModal`，后者种过就 `flushCommons()`。
4. `sowCommons()` 内部先 `ensurePlots()`：村庄刚升级时新地块也要一起种上。
5. 删掉死常量 `COMMONS_LOG_DAYS`（裁剪实际走 `data/friends.js` 的 `trimLog`/`LOG_KEEP_DAYS`）。
6. `center.js` 的 `commonsHint` 兜住「一片空地」（新档第一屏真的是六块全空）。
7. `commons-modal` 的加成档位改成与 `friend-modal` 同口径的写法（`pct / 30` 再 ceil）。
8. `manual.js` 新增「🏞 公共用地」一节（9 条），放在「村庄建设」之后。
9. **提示口径确认**：村民在公共地抢收，在线演出那条路**会**弹 toast（一趟才几次，
   正好提醒玩家「有人去抢了」）；在线空闲那条路不弹（每 1~3 分钟一次会刷屏）。
   文档原先写「不弹」，已按实现改正。

审查结论（**不需要改**的）：
- 玩家主动操作邻居的 10 处单点提交不带 commons —— 那些操作不碰公共地，带上只是白写；
- `village.js` 的 invest/pray 不带 commons —— 升级后块数由下次 `advanceCommons` 补，`normalizeCommons` 兜底；
- `bulkAdvance` 降级段不推进公共地 —— 公共地不循环，最多长到成熟停住，不需要补算历史；
- 公共地照料不记排行榜 —— care 是「帮人」、work 是「自家」，记哪张都会让口径变形；
- `records.js` 不看 `by`，所以公共地日志复用 `recordItemsHTML` 不会重复显示来源；
- 弹窗打开期间村民抢收不会重绘（与邻居弹窗同一约定，数字滞后但操作时重算，不会出错）。

## 第 59 轮：公共用地收尾（按钮瘦身 / 1 天换种 / 标记排查）

### 1. 入口按钮压薄（玩家反馈「太大」）
- `.center-act.commons`：`padding 10px 11px` → `6px 10px`，圆角 15 → 12，图标 34 → 24（字号 19 → 14），
  高度 56px → **38px**。
- **主因是竖排两行**：`.ca-body` 从 `flex-direction: column` 改成 `row` + `align-items: baseline`，
  一行放得下「🏞 公共用地　2 块能收了」。
- 徽标从右上角改成**右侧竖直居中**（`top:50%` + `translateY(-50%)`），`line-height` 收到 15px；
  因为绝对定位不占位，`.ca-body` 自己补 `padding-right: 20px`。
- **0 时 `display:none`**：订单的 0 是「你还没发单」这条信息，公共地的 0 只是「现在没熟」，
  说明行已经写了，细条子上再挂一颗灰的纯噪音。
- 整宽（`grid-column: 1 / -1`）**保留**：一行挤三颗会把副标题全变省略号。

### 2. 「会不会显示待浇水 / 待捉虫」—— 排查结论：不会
- 徽标 `data-role="commons-n"` 只接 `commonsSnapshot().ripe`（我能拿的块数），
  `refreshMarks` 里也只写这一个数。
- `commonsHint` 只分 ripe / 全空 / ready / 都在长 四种，没有水虫分支。
- `commonsSnapshot` 本身根本不统计 `needsWater` / `needsPest`。
- **不是 bug，也不必加**：公共地没有「欠水 −15%、欠虫 −40%」的减产惩罚
  （`rollCommonsYield` 只乘 `boost` 与 `villageYield`），不照料只是长得慢、产量低，
  没有时限压力；而按钮刚被要求瘦身，再挂两个红点正好相反。
  → 已把这条判断留给玩家决定，没动。

### 3. 熟了摆 1 天就换种
- `data/commons.js` 新增 `COMMONS_RIPE_HOURS = 24` 与 `commonsRipeDeadline(plot)`。
- **不新增存档字段**：锚点直接用 `plot.readyAt` —— 它就是熟的时刻，浇水只会把它往前挪
  且只有成熟前能浇，熟了之后不再变。省掉一次旧档迁移。
- `advanceCommons` 改成「补地块 → **摇产量** → 清空该换种的 → 补种」：
  ⚠️ 摇产量必须在前，`commonsRemain = pendingYield − taken`，没摇过的两者都是 0，
  先判会把一块刚熟、一份没被拿的地当「已经被拿光了」直接铲掉。
- 该换种 = `commonsRemain <= 0` **或** `now >= commonsRipeDeadline`。
- 系统补种**不写日志**：补算跨 7 天会一次跑几十次补种，写进去就是流水账。
- `openCommonsModal` 从 `sowCommons()` 改成 `advanceCommons()`（顺带把熟透的地清掉重种），
  动过才 `flushCommons()`。
- 成熟地卡加第三行 `np-time`：「23 小时后换种」/「马上换种」。
  新加 `fmtLeft()` 折成「N 小时」/「N 分钟」两档 —— 不复用 `fmtDuration`，
  它给的「23小时45分」在 141px 的地卡上放不下。

### 4. 顺带修的文案 bug
`commonsHint` 原来只有「能收 N 块 / 全空 / 都在长」三种，`ripe=0 && ready>0`
（都熟了但这一轮你拿过了）会落到「都在长」—— 1 天窗口里这个状态可能持续好几小时。
`commonsSnapshot` 补返回 `ready`（熟了的总块数），文案改成「N 块熟了 · 这一轮你拿过了」。

  而这时候地里还剩几份恰恰最该知道（值不值得叫人来拿）。
- 改成 `还剩 N 份 · 你拿过了 / 先到先得`，`N` 用 `.np-remain` 放大加粗；
  拿光了才写「已经被拿光了」。

  村民在公共地抢收走世界时钟，弹窗开着时他也可能顺手拿走一份 ——
  指纹不含数量的话，玩家会盯着一块「还剩 3 份」的地看半天，实际早被拿光。

### 5. 村中心布局（用户选「方案 A」）
- 第一行不变：村民总览(1fr) + 🏆排行榜(2fr)，`.center-duo`。
- 第二块换成 `.center-main`：`grid-template-columns: 1fr 2fr` + `rows: 1fr 1fr`，
  左列上=📢公告栏 / 下=📋订单，右侧 🏞 公共用地 `grid-column:2` + `grid-row:1 / span 2` 跨两行。
- ⚠️ commons 有显式 grid 位置，**先于自动放置占位** —— 前两个按钮天然落到第 1 列的两行，
  不需要给它们写 `grid-area`。
- ⚠️ 公共用地**不能被内容撑开**：内部全绝对定位 + `min-height:122px` + `overflow:hidden`。
  它一长高，左列两格（`1fr 1fr`）跟着长，整页被推下去。
- ⚠️ `.ca-body` 绝对定位时 `width:auto` 是 shrink-to-fit，**必须同时钉 `left` 与 `right`**，
  否则 nowrap 的长句会顶出卡片、被 `overflow:hidden` 裁掉半个字。
- ⚠️ `.ca-body b` / `.ca-body i` 都要 `display:block` + 省略号（行内元素不吃 `overflow`）；
  压到 1/3 宽后窄屏只有 90 来像素，不截断就顶出圆角。
- ⚠️ `.center-act.orders .ca-body` 补 `padding-right: 24px`：徽标绝对定位不占布局，
  会直接盖在「有活干了」的尾字上。
- 公共用地补一行 `ca-hint`「先到先得 · 熟了摆 1 天换种」；`.center-acts` 整块删除。
