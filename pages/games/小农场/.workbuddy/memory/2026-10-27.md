## 第 56 轮：产出堆叠 + 限定金边 + 圆角修复 + 长按连发

### 可收获产出堆叠（`data/yield-pile.js`，新建）
- `pileCount` 用 **`floor(n/2)+1`**（封顶 10），不是直觉的 `ceil(n/2)`。
  原因：堆叠还要表达「被偷走一个」，产量绝大多数是偶数 ——
  `ceil` 下 6→3 张、偷后剩 5 还是 3 张（看不出）；`floor+1` 下 6→4 张、偷后 3 张（少一张）。
  代价：奇数产量看不出变化、产量 2 摞 2 张；产量 ≥19 封顶后也看不出（交给文字提示）
- `pileLayout`：**黄金角螺旋**（2.39996）+ 半径 `0.42+0.58√t` + 三重抖动。
  试过网格（像货架）和纯随机（聚团留空洞），都不像「地里长出来的一堆」
- **位置必须稳定**：地块 500ms 心跳重绘，`Math.random()` 会让图标乱跳。
  种子 = 地块 id 经 djb2 → LCG，同 key 永远同一堆
- **坐标用 em 不用 px**：紧凑模式地块只有 71~90px 宽，CSS 只换 `font-size`
  （24 / 19 / 19），整摞等比缩放
- `pileHTML` 自家农场与邻居共用；邻居种子带 `${friend.id}-${plot.id}` 防两家形状撞车
- `.yield-pile` 固定 `3.4em × 2.3em`，`pointer-events: none` 让点击穿透到 `.plot-art`
- ⚠️ **`.plot-art` / `.np-art` 要 `padding: 0 .4em`**：图标散开后比盒子宽（左 5.9 / 右 3.3px），
  不补内边距时点到最外侧图的边缘命中的是 `.plot-main`，作物详情打不开（看着能点、实际没反应）
- 邻居卡「已被顺走」分支也继续摞（每块每轮只能偷 1 个，产量还在）；
  退回单张小图会像「整块被搬空」，和实际剩的量对不上
- 实测：紧凑 430px 最紧横余 13.5 / 纵余 9px；桌面 1280px 横余 60 / 纵余 17.9px；
  邻居卡四分支（可偷/已偷/狗守/生长期）高统一 138px

### 限定地块金边 4px（常规 1px 的两倍）
- 靠 `padding` 给厚度，**不加粗 border**（border-box 下加粗会挤压内容区）
- 整圈收在 border 内侧 = 「向内扩」，内容区一寸没让

### 圆角修正：三个坑连在一起
1. `inset: 0` 贴的是 padding box，比外沿小 2px → 改 `inset: -1px` 对齐 border box
2. 尺寸小了但半径 `inherit` 同一 `--radius`，曲率对不上 → 对齐外沿后半径**不该加**
3. 顶到外沿后环压在抗锯齿临界线上，圆角透出页面底色
   → **最终解**：aura `inset:-1px`，金边环 `inset:1px / r-2px / padding 4px`，
   扩散环 `inset:2px / r-4px / padding 2px`。**每收进 N px，半径减 N px**
- 品红底像素采样验证：p3 / p5 / p6 圆角内侧 322 个采样点，命中品红 **0 处**

### 长按连发（`ui/hold.js`，新建）
- `mountHoldRepeat(root, fire)` 委托层，只在 `modal.js` / `subpage.js` 各挂一次，业务零改动
- 380ms 后进入连发、70ms 一格；捕获阶段 `stopPropagation()` 吞掉松手补发的 click
- 定时器存 `WeakMap`；`el.disabled` 时自己停
- 实测：单击 +1、按住 1.4s 连发 15 格、静置不多跳、按「−」停在下限 1、短按 120ms 只涨一格
