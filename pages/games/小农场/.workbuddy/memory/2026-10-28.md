- `.plot` / `.npc-plot` 都改成**单列**：删掉 `.plot-side`（34px 竖排操作列）与 `.np-acts`（底部横排按钮行）

# 追加 · 「点掉按钮整行变矮」的修复

## 症状（用户报的）
有操作按钮的地块会把整行撑高，点掉之后整行又缩回去。

## 病根：不是按钮，是内容行数
先证明按钮无罪：把所有 `.plot-hang` 从 DOM 摘掉再量，
每块地的高度变化**全部是 0.0px**。真正的差异是内容行数 3~6 行：

| 状态 | 行数 | 多出来的那一行 |
| --- | --- | --- |
| 生长中 + 缺水 + 生虫 | 6 | **💧 缺水 / 🐛 生虫 警示行** |
| 生长中 正常 | 5 | — |
| 空地 | 4 | 含升级按钮 |
| 成熟 | 4 | 堆叠图更高（+30px） |
| 荒地 | 3 | — |

点 💧 的**同一瞬间**警示行消失 → 这块地矮 15px → grid 拉齐 → 整行一起缩。
所以 `min-height` 写在 `.plot` 上没用：它只是地板，内容一多照样顶穿。

## 改法
1. `min-height` 锁到**内容层**：`.plot-main { min-height: 141px }`（6 行实测 137 + 4 余量）、
   `.grid.dense .plot-main { min-height: 113px }`（紧凑 6 行 110 + 3）
   —— 留余量是必须的，卡在 137 上不同系统差 1px 就重新顶穿
2. `.plot` 的 `min-height` 删掉（只留 padding-bottom）
3. **`ripeHTML` 的「照料不周」不能单独占一行** —— 成熟是 4.4em 堆叠图，
   5 行 = 156px，比生长中 6 行 137px 还高。改为与「还可收获」**挤同一行**：
   尾行 `照料 −40% · 最后一茬`，行数恒为 4
4. `.npc-plot` 自己锁 `min-height: 142px`（它直接装内容、没有中间层，锁它身上）。
   不取 138：可偷那格是 65px 堆叠图 + 名字 + 提示 = 141.6，比其它行高 3.6px；
   统一到最挤那档，同一行才真的齐平
5. 守卫犬提示从「🐕 被守护犬盯着，这轮偷不了」缩成「🐕 有狗盯着」——
   360px 两列时 `.npc-plot` 只有约 153px 宽，原句折成两行把那格撑到 152（其他 142）

## 验证
- 五档宽度 320 / 430 / 900 / 1200 / 1600：**同一 top 上高度集合唯一**，
  无一行参差（`mixed: []`）
- 真实点击链六个步骤（浇水 → 再浇水 → 捉虫 → 收获 → 再收获）：高度**恒定不变**
  - 紧凑：145（原 142）｜ 非紧凑：177（原 173）
- 极限内容（最长作物名「切花郁金香」+ 产量 96 + 被偷 8 + 照料不周 + 加成 120%）：
  无溢出（`scrollHeight == clientHeight`）
- NPC 弹窗逐格点掉 warn 按钮：六档宽度 320 / 360 / 430 / 720 / 900 / 1200
  点前点后都是**唯一值 142**、`mixed: []`；只有 `.plot-hang` 少按钮
- 文字底边 → 悬挂按钮顶边 最小 3.5px（窄屏 5px），探出 6~7.5px
- `node tools/check.mjs` 全绿
