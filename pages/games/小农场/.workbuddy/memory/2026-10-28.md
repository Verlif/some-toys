# 2026-10-28 · 农场土地布局重做（单列 + 悬挂按钮 + 堆叠更散）

## 背景
玩家要重新调整农场土地布局，**玩家的与 NPC 的用同一套**。

## 结构改造
- `.plot` / `.npc-plot` 都改成**单列**：删掉 `.plot-side`（34px 竖排操作列）与 `.np-acts`（底部横排按钮行）
- 主内容 `.plot-main`（`.npc-plot` 直接子元素）横向铺满整格：手机 83px → 117px
- 操作按钮改挂底边：`.plot-hang` = `position: absolute; left:50%; bottom:0;
  transform: translate(-50%, calc(25% + 1px))`
  - **3/4 在格内、1/4 探出**；绝对定位不参与 flex/grid 行高 → 邻格位置一像素不动
  - `left:50% + translateX(-50%)` 居中（按钮数量会变，不能靠 flex 撑）
  - `pointer-events: none` + `> * { auto }`：空白处不吃点击
- 底部统一预留 padding（普通 23px / 紧凑 22px / 邻居 22px）—— 有无按钮都同高

### 铲除 / 施肥移进作物详情弹窗
- `plotActionsHTML(plot, ripe)` → `openCropModal(..., { extra })`
- `grid-template-columns: minmax(0,1fr) auto`：施肥吃剩余宽度、铲除固定 36×34 方框
- 外层 `.pa-row { max-width: 300px; margin: auto }` 做最长限制 + 居中
- 成熟后只剩铲除：改正常胶囊（一颗方框孤零零很怪）
- `PLOT_ACTIONS` 删掉 `fert` / `remove`，改由 `openPlotCrop` 的 `onAction` 转
- 铲除仍走二次确认（`confirmRemove`），叠层取消回详情

## 堆叠更分散（`data/yield-pile.js`）
- `RADIUS_X 1.45 → 1.62`、`RADIUS_Y 0.62 → 0.66`、`MAX_ROT ±24°`
- `.yield-pile` 容器 `3.4em → 4.4em`（横向整格宽），每张图 `-webkit-text-stroke` 白描边 + 双层 drop-shadow
- 图标字号：普通 25 / ≥720 27 / ≥960 29 / 紧凑 18；`.np-art` 与玩家**同档**（不再单独降一档）
- `.plot-art` / `.np-art` 加 `width: 100%` + `padding: 0 .5em`（撑可点范围）

## ⚠️ 踩到的坑
- **`bottom: 0` 落在 border 内侧**：绝对定位包含块是 padding box，探出量少 1px
  （24px 按钮只露 5px、比例 0.79）→ `translateY(calc(25% + 1px))` 才对
- 缺水地块 `.plot-main` 更高，22px 预留不够（文字离按钮仅 1.5px）→ 23/22px
- 最窄格子 131px：`RADIUS_X` 约 1.7 以上最外侧图会被卡片裁角，1.62 是实测上界
