# 第 16 轮：商店滚动保持 / NPC 在线提示 / 守护犬品种化

四项用户需求全部落地，`npm run check` 9/9，第 16 轮 e2e 26/26、第 15 轮 15/15、
第 14 轮 18/18 全过。

## 实现要点

- **商店滚动**：根因是 `syncTabFromScroll()` 跑在 `scrollLeft` 恢复**之前**，
  此时 scrollLeft 还是 0 → `activeTab` 被误判成第一个 tab → 纵向滚动恢复到了
  错误的面板上。改成先恢复 `scrollLeft` 再同步 tab，并用局部变量 `tabAtRender`
  固定面板key（重建过程会改写 `activeTab`）。新增 `keepPanelScroll` 标志：
  改筛选与 `setShopTab()` 外部跳转时置 false 回顶部，买东西重绘时保持
- **在线推进**：新增 `npc-sim.simulateNpcUntil(npc, npcs, now, farm, onVisit)`
  逐条跑会话并回调 `(at, entries, delta)`；`social.settleWorld()` 分帧（12ms/帧
  + rAF）推进，单例 Promise 去重，`visits.length > 0` 才落盘。
  `pollOnline()` 按 `v.at >= sessionStart` 把结果分进 `pendingOffline` /
  `pendingArrivals` 两个**暂存桶**，UI 用 `takeOfflineSummary()` /
  `takeArrivals()` **取走式消费**（避免「谁先轮询谁先拿到」的竞态）。
  `main.js` 每60s 轮询 + `visibilitychange` 切回时立刻查一次
- **守护犬三层模型**（新建 `data/dogs.js` + `store/dogs.js`）：
  品种（基础拦截率 20%~80%，10 档）× 上岗（`pet.active`，唯一，可全下岗）
  × 狗粮槽（`pet.satiety`，**全窝共享一份**，只在有狗上岗时按 6.25%/h 消耗）。
  实际拦截率 `catchChance(rate, sat) = rate × (0.5 + 0.5 × sat/100)`
- **品种来源**：初始送最低档田园犬，其余只能从冒险获得。
  `DOG_TIER_BY_MAP = [0,2,3,5,7,10]`（图档位 → 品阶上限）、
  `DOG_REWARD_CHANCE = [0,.15,.18,.22,.26,.3]`（一级图不给狗），
  狗奖励是**预算之外**的额外奖励且 `value: 0`，已收集的不再给
- **NPC 狗也品种化**：`npc.dogBreed`，品阶上限 `min(8, max(3, 3+lv/12))`
  ——**下限钉在 3**，否则「被抓住就封锁全场」这个惩罚形同虚设
- **迁移**：`data/friends.js` 的狗常量/函数 → `data/dogs.js`
  （`dogCatchChance`→`catchChance`、`rollNpcDogSatiety`→`rollNpcDogBreed`）；
  `store/social.js` 的 `dogSatiety/isDogGuarding/guardRemainMs/feedDog`
  → `store/dogs.js`。老存档由 `state.normalizePet()` 补田园犬并上岗

## 本轮修掉的真 bug（静态校验 9 项都抓不到）

1. **`logFriend()` 函数被整个删掉了**，但 `social.js` 里有 6 处调用（偷菜、
   被狗抓、浇水、捉虫、一键浇水、一键杀虫）。`node --check` 只查语法，
   只有 e2e 真的调 `social.steal()` 才炸 `ReferenceError`。已按 git 恢复。
   ⚠️ 这类「本文件私有函数丢失」是当前静态校验的盲区，值得加一项检查
2. **商店筛选条会消失**：模板写成 `${activeTab === 'seed' ? filterHTML() : ''}`，
   但 `filterHTML()` 内部已用 `hidden` 控制显隐、`switchTab()` 也靠
   `filter.hidden`切换。两者矛盾 → **在道具 tab 买东西触发重绘后筛选条被从
   DOM 删除，点回种子 tab 也回不来**。改成无条件 `${filterHTML()}`
3. **农场页守护犬信息被道具绑架**：`if (!water && !pest) { if (toolsKey) {...} return; }`
   —— 首次进入 `toolsKey === ''`，`el.hidden` 永远 true，
   新玩家永远看不到自己养了条狗。改成统一 key 比较，没道具时只渲染狗行、
   且**不**加 `has-farm-tools`（只有工具按钮在时才需要顶开日志按钮）
4. **`feedDog()` 迁移时漏了 `await completeGuide('feed')`** —— 引导项
   「第一顿饭」的奖励再也发不出去

## 本轮新踩的 e2e 坑

- **商店切 tab 是 smooth 滚动（约 1s）**，动画没停就点下一个元素会点空。
  解法：轮询 `.shop-panels` 的 `scrollLeft` 直到连续两次相同再继续
- **`el?.click() || fallback.click()` 会两个都点** —— `?.click()` 返回 `undefined`，
  `||` 短路失效。必须 `const t = a || b; t?.click()`
- **验证滚动位置不能只看 `scrollTop` 是不是 0**：要先确认面板真的有可滚长度
  （`scrollHeight - clientHeight > 100`），并手动 `scrollTop = row.offsetTop - 200`
  滚到中间，否则恒为 0，测不出「有没有被重置」
- **商店筛选默认「现在能种」只有 3 行**，且未锁定行只在列表开头 ——
  测种子面板要先切「全部」并把 `player.level` 拉高
- **断言别写死基础率**：实际拦截率还要乘饱腹系数，槽不满时不等于基础率
- **store 迁移函数后，老脚本里的旧路径导入会静默变成 `undefined`**
  （不报错、只是值为空），必须逐个 grep
