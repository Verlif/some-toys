# 2026-10-20 第 14 轮：邻居弹窗重做 / NPC 守护犬 / 时报 / 一键道具 / 经验累加

## 用户需求（9 项）

1. NPC 农场弹窗中，农场与最近操作交换位置
2. 土地操作按钮被文本挤走 → 产量变化百分比放左上角色标，按档位着色；
   已被偷过的土地右上角标记
3. 守护犬饱腹度不保存（bug）
4. 被守护犬抓住 → 该农场当前所有作物不能再偷（等同标记已偷）
5. 商店藏宝图等级限制标记写反（应为「农场等级≥多少」）
6. 升级经验 = 当前等级×200 + 上一级所需（累加）
7. 仓库确认卖出后自动关窗（bug）
8. 跳转按钮（买种子/买藏宝图）弹出商店后自动切到对应 tab
9. NPC 农场也应有守护犬，上线按性格可能喂食
10. 底部新增「时报」tab：偷菜被抓住、冒险大奖、升级等大新闻（要持久化）
11. 商店增加洒水器与杀虫剂（一次性），有道具时农场底部出一键浇水/杀虫

## 实现要点

- **经验曲线改为累加**：`expForLevel(n) = 200×n + expForLevel(n-1)`（= 100·n·(n+1)），
  生成器删掉 `expPerHourAt/plotsAt/soilExpMulAt/targetHoursAt` 整条反推链。
  满级累计 2.67 亿（旧 1630 万）。`expForProgress()` 供签到等按等级折算用（满级不返回 Infinity）
- **NPC 守护犬**：`npc.dogSatiety + npc.dogAt`，与玩家同一套 6.25%/h 衰减；
  上线按 `min(0.55, tend×0.13)` 概率喂食；初始 `20 + tend×12`
- **被抓封锁**：`social.steal` 里被狗拦下时给该 NPC 所有 `cropId` 地块置 `guarded`，
  `isStealable` 一并检查；重种/进再生轮时清除（npc-sim 两处）
- **时报**：`store/news.js`（`player.news`，7 天/80 条，不升数据库版本）；
  玩家升级（player.js）、被狗抓（social.js）、寻宝大奖（adventure.js，>2×图价）、
  NPC 偷玩家/互偷/寻宝/升级（npc-sim 经 `farm.news` 回调）
- **一键道具**：`sprinkler/pesticide` 各 200 金币，`ITEMS[].all = 'water'|'pest'`；
  `farm.waterAll/catchPestAll`、`social.waterAllNeighborPlots/catchPestAllNeighborPlots`；
  玩家农场出 `#farmTools`（与日志按钮同行，`body.has-farm-tools` 顶开日志按钮），
  NPC 弹窗出 `.npc-quick`
- **角标**：`.plot-corner` / `.np-corner` 绝对定位不占流；
  ⚠️ 坑：HTML 类名 `np-corner`，CSS 一度写成 `npc-corner` 导致角标全部失效
- **弹窗换位**：农场网格移到「最近操作」之上；狗状态进数据卡
- **跳转**：`EVENTS.NAVIGATE` payload 支持 `{page, tab}`；`setShopTab()` 外部入口
- **两个 bug**：`feedDog` 把 pet 放进 `commit` 第二个参数（collections）被忽略 →
  改 singles；bag 确认卖出缺 `closeModal()`

## 验证

- `npm run check` 9/9；生成器自校验通过
- 端到端 18/18 全过、零控制台错误（脚本在托管 node 工作区 `e2e-round14.mjs`，不进仓库）
- Node 侧：NPC 狗饱腹衰减/喂食、时报补写过去时间点、guarded 重置

## 端到端脚本的三个坑（已写进 docs/11）

1. 切页必须等 `body[data-page]` 落地——各页启动时就渲染过，等「元素存在」会瞬间通过
2. 邻居页进入有 ≥650ms 结算浮层，会吞点击
3. 所有浮层有 0.25~0.3s 位移动画，点太早点在动画中途
   （通用解法：等元素及祖先 `getAnimations()` 全部 finished 再点）

# 第 15 轮：增产肥料 / 图鉴标本 / 称号系统 / 冒险产出 / 签到重做

## 用户需求（7 项）

1. 商店增加增产肥料（10%/20%/30%，1000/3000/8000），
   **同一株作物只能施肥一次（无论何种肥料）**
2. 图鉴加「制作标本」按钮（已有标本或仓库产出不足则不显示），
   用 50 个对应产出制作，**制作完才算点亮图鉴**
3. 图鉴点亮数量 → 称号（手动领取），参考《阳光牧场》
4. 称号系统：展示全部称号、手动领取并给奖励、可佩戴一个（在农场信息显示）、
   每个称号有不同图标与背景
5. 冒险增加更多卡牌，奖励池增加成熟作物产出（2~10 个，等级同种子范围）
6. 签到去掉经验；每天发普通化肥(30分) + 随机商店种子 + 少量金币；
   周六大奖日开盲盒（按农场等级取最高可用藏宝图的奖励池抽一份）

## 用户拍板的关键决定

- 26 个等级称号**全部改成手动领取**（不再按等级自动显示）
- 老存档图鉴进度**不补，从 0 开始**（标本是新规则）
- 签到**保留少量金币**（按等级缩放）
- 图鉴称号奖励 = **金币 + 道具组合**（道具按难度逐级加重）

## 实现要点

- **称号**：生成器产出 33 个称号（26 等级 + 7 图鉴），带 `emoji/skin/need/coins/items`；
  `progression.js` 的 `titleOf(level)` 改成 `titleById(id)` + `titleAt(type, value)`；
  新增 `store/titles.js`（领取 / 佩戴 / 奖励发放）与 `ui/subpages/titles.js`；
  玩家存档 `player.titles = { claimed:{}, equipped }`；顶栏显示佩戴的称号
- **标本**：`player.specimens = { cropId: true }`；`codex.js` 加 `makeSpecimen`、
  `SPECIMEN_COST = 50`；`lit` 判定从「收获过」改成「有标本」
- **施肥额度统一**：`plot.fert` 一个标记（普通/增产/有机共用），
  增产加成记在 `plot.yieldBonus`，收获时与捉虫加成**相乘**；
  老存档 `plot.organic` 在 `normalizePlot` 并进 `plot.fert`
- **冒险**：`SCENES` 18→30；`REWARD_MIX` 加 `produce`（金币 2 : 种子 3 : 产出 2 : 道具 1）；
  产出数量按预算反推再夹到 2~10，按单价记账
- **签到**：`data/signin.js` 重写（每日固定三样 + 周六 `isBigDay`）；
  `store/signin.js` 的 `rollBigBox(level)` 取该等级可用最高档藏宝图的奖励池抽一份；
  盲盒奖励也可能抽到 `produce`，`applyReward` 要多认一种 kind

## 验证

- `npm run check` 9/9（静态校验的称号检查改成按 `need.type` 分组校验）
- 端到端 15/15 全过（第 15 轮新脚本）+ 第 14 轮 18/18 回归全过
- 实测：增产剂让平均产量 19.8 → 28.3（+30%）；称号 33 个 / 10 套配色；
  标本扣 50 个后点亮；周六盲盒抽到限定种子

## 本轮踩到的坑

- 称号页最初把「可领取」单独开一区 → 同一个称号在页面上出现两次。
  改成一条横幅 + 「全部领取」按钮
- 端到端脚本测产量对比时忘了清背包残留产出，基准被污染（基准 25 vs 实际 19.8）
- 端到端脚本切页前要先关子页面：子页面盖住底部导航，tab 点点不到
