# 第 18 轮：种子制造间 / 弹窗标题可拖 / 狗窝改名单 / 土地底纹

## 需求（6 项）

1. 新增**种子制造间**：Lv≥5 + 2000 解锁；选 ≥5 份产出消耗换同种种子（1/2/3 个）；
   可升级（累计使用次数 + 金币），最高 10 级；先给升级需求表评估
2. 弹窗顶部标题可**直接下拉关闭**，右上角加关闭图标
3. 删除「其他」里的加工坊、交易行
4. 狗窝：基础犬种换比熊，田园犬挪到 58%，「下岗」文案改「休息」
5. 玩家/NPC 升级土地后格子背景渐变（左土地色 → 右普通色），农场信息显示土地构成

## 实现

- **种子制造间**：`data/workshop.js`（等级表 / 概率 / `produceCost` / `rollSeeds`）+
  `store/workshop.js`（unlock / craft / upgrade / craftables）+ `ui/subpages/workshop.js`。
  状态 `farm.workshop = { level, uses }`；入口「其他 → 🌱 种子制造间」（`seedshop`）。
- **关键数值决策**：固定「5 份产出」在 Lv200 是 12 倍利润（5 份值 0.10 个种子），
  会毁掉金币来源 → 改成按市价折算 `max(5, ceil(seed × 0.6 ÷ sell))`，
  任何等级稳定约 2 倍（满级 3.3 倍）。用户原方案 5 份作为下限保留。
- **限定作物不能制造**（否则藏宝图失去意义）。
- **弹窗**：`openModal()` 把 `.modal-head` 移到 `.modal-body` 之前（滚动区外），
  没有 `[data-close]` 就自动补 ✕，没有 head 的补 `.modal-head.bare`；
  `dragToClose.canStart(target)` 从 `.modal-head`/`.sheet-handle` 起手时忽略 scrollTop。
  邻居弹窗头部改成 `modal-head npc-head`，白拿固定头 + 关闭图标。
- **狗窝**：`DOG_BREEDS` 第 1 档换比熊 🧸 20%，田园犬移到第 7 档 58%，狐狸犬删除；
  `LEGACY_BREED_MAP = { tuyuan:'bixiong', huli:'tuyuan' }` + `dog.migrated='r18'` **只迁一次**
  （逐条改会被二次改写；每次读档都改会把正经收集的田园犬降级）。
  3 处「下岗」文案改「休息」。
- **土地底纹**：`soilbg-<id>` 类 + `::before` 横向渐变（左土地色 0% → 46% 透明），
  不改 `background` 以免覆盖 `.ripe/.warn/.growing`；颜色走 `--soil-tint`，彩虹地单独多色规则。
  邻居地块新增 `soil` 字段（`rollNpcSoil(level)` 按等级随机），收成吃 `SOILS[].yieldMul`。
  顶栏加 `.hud-cell.wide`「当前土地」，`title` 放完整明细与平均产量。

## 验证

- 真机冒烟（430×900）：菜单项、未解锁文案、解锁、制造 20→14 份得 1 种子 uses=1、
  弹窗结构 `sheet-handle / modal-head / modal-body`、拖标题 120px 关闭、邻居弹窗头带 ✕、
  地块 `plot soilbg-red`、顶栏「银土 ×1 · 黑土 ×1 · 红土 ×1」、邻居土地分布 38/251 块非普通
- 迁移脚本验过：旧档 `{tuyuan,huli}` → `{bixiong,tuyuan}`，两次读档不重复迁移，
  已迁移档里的田园犬不被降级
