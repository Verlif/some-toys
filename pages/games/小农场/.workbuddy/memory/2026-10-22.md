采收机同时提供永久版（10 万），洒水器 / 杀虫剂也各加一个永久版（各 5 万）。

- **`data/care.js`**：`nextCareAt` 区间改成 `[次数×1h, (次数×2+1)h]`，再夹到「成熟前 15 分钟」；
  `下限 > 上限` 时返回 0（本轮不再需要、不算欠账）。之前下限固定 1 分钟，会出现
  「刚浇完一分钟又缺水」。0 次时下限是 0，种下就可能立刻要浇（用户明确要求严格取 0）。
- **`data/relation.js`**：`stealRelLoss(售价)` → `stealRelLoss(等级)` = `max(1, round(等级/3))`。
  三处调用点（玩家偷成功 / 被狗逮住 / 邻居互相偷）全部改成传 `crop.lv`。
  按售价折算时高阶作物一份上千，偷一次掉几十上百，跟「偷一把菜」完全不匹配。
- **新道具**（`data/items.js`）：`harvester`（200，一次性）+ 三个永久版
  `sprinklerPro` / `pesticidePro`（各 5 万）/ `harvesterPro`（10 万），`permanent: true`；
  新增 `TOOL_KINDS` 映射 `kind → {consumable, permanent}`。
- **新模块 `store/tools.js`**：`hasTool / toolUses / useTool / toolCountText`，
  **先查永久版再查消耗版**（顺序反了有永久版也会白吃消耗品）；`toolUses` 返回 `Infinity`，
  UI 显示 ∞。自家（`farm.js`）与邻居家（`social.js`）的一键照料共用这一套。

  产量 / 照料减产 / 被顺走 / 再生轮 / 经验都只在一处算。一键收获一次落盘、一条汇总日志

  文案压短（括号里只放块数，完整说明进 `title`），`flex-wrap` 兜住 360px 小屏；
  按钮出现条件是「拿得出工具」，存量 `×3` / `∞`。邻居弹窗的一键按钮同样支持永久版。
- **商店 / 包裹 / 冒险三处连带**：
  商店买过硬拦重复购买、按钮变「已拥有」并置灰（价格用 `formatCoins` 显示成 5.0万 / 10.0万）；

- **新模块 `store/collected.js`**：`isCollected(cropId)` / `noteProduce(itemId)`。
  记录挂在 `player.progress.collected`（`{ 作物id: true }`），**只增不减** ——
  卖掉、送人、做成标本之后依然算收集过。
- **唯一埋点在 `inventory.add()`**：所有产出入包都走它（收获 / 偷菜 / 收礼 / 签到 /
  冒险产出），不用逐个业务加代码，将来新增来源也不会漏。种子（`seed_*`）与认不出的
  key 不计。⚠️ 不要改成在 `harvest()` 里单独埋点，会漏掉偷菜与送礼。
- **`store/codex.js`**：`ensureStats` 补 `collected`；`codexEntries` 新增 `collected`，
  老档兜底 `isCollected || harvested>0 || owned>0`；`codexSummary` 新增 `collected`，
  `percent` 改成按收集算（顶栏与图鉴进度条都吃这个）。
- **UI**：卡片剪影判定 `!entry.collected`（不再是 `!lit`）；标题「已收集 X / 220」，
  副标题「已点亮 Y 种 · 已解锁 Z 种 · 收集进度 P%」；筛选键 `lit` → `collected`；
  详情弹窗多一行「📖 图鉴　已收集 · 未点亮　做一份标本就点亮」。

### 追加：去掉邻居页筛选条的滑动切档

用户：「邻居列表上的排序与分类，把滑动切换标签逻辑去掉，移动端上有问题」。
`views/friends.js` 里删掉 `shiftSort()` 与 `mountFriends()` 的四个监听器
（touchstart / touchmove / touchend / mousedown+move/up 双通道）——
横向位移 40px 就切档，在手机上滑芯片行时经常误切，还跟 `.filter-bar` 的

### 追加：排序标签条不再跳回最前面

用户：「点击了排序之后，这些标签不应该刷新，也就是不应该滚到前面的」。
根因是 `renderFriends()` 把整个 `#friendsBody`（含 `.filter-bar`）innerHTML 换掉，
新元素的 `scrollLeft` 归零 —— 手机上点最右边的「好感」，条子立刻滚回「全部」那端。
重绘前读旧条子的 `scrollLeft`、重绘后同步赋给新条子（`if (keepLeft)`），
和商店页 `renderShop()` 恢复面板位置同一套路；同步赋值不会闪。
