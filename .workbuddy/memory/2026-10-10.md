**卡片悬浮阴影被裁剪（关键修复）**
- 根因：折叠动画用 CSS `max-height + overflow: hidden` 常驻，祖先容器裁掉了卡片外扩阴影。
- 方案：`.group-body` 默认 `overflow: visible`；折叠/展开由 JS（模板内联脚本的 `collapse()` / `expand()`）临时写内联 `max-height`、`overflow`，动画结束（380ms）清空内联回到 CSS；卡片 hover/focus-within 加 `z-index: 2`；`.cards-grid` 用 padding + 负 margin 留呼吸位。

**中英双语**
- 新增 `assets/i18n.js`（141 个 key × zh/en，无依赖），导航页与 pages/介绍.html 共用。
- 属性协议：`data-i18n / -html / -title / -content / -placeholder / -aria-label`，插值用 `data-i18n-vars='{"n":3}'`。
- 语言优先级：`?lang=xx` > localStorage `lang` > navigator.language > zh。
- 注意：`I18N.nextLabel` 应返回 `t('nav.langLabel')`（即目标语言标签），别写成取对方字典。
