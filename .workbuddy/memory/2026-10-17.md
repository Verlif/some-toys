### 校验方式（静态）

- 自研编码器与 Python `qrcode` 库逐模块比对：v2 / v4 / v8 / v9 / v10 全部一致（v2 仅掩码选择不同，8 种掩码里 mask=2 完全一致）。
- 踩过的两个坑：
  1. 生成多项式要转成「首项在前」再做综合除法，否则纠错码字全错（数据段对、纠错段错 → 表现为第 dataCount 位开始不一致）。
  2. 对齐图形必须先于定时图形绘制：`ALIGN` 里位于第 6 行/列的定位点在 v7+ 会落在定时图形上，先画定时图形会被 `!== null` 判断跳过，导致 v7–v10 矩阵错误。
- 校验脚本放在 `.ta3NewCoder/qrcheck/`（check.py / words_compare.py / gen.js / png.js）与 `.ta3NewCoder/verify.js`（内联脚本语法 + 字典中英键比对 + data-i18n key 存在性 + 资源引用），均被 gitignore。

## 修正：弹窗整体不该有滚动条，只有 README 区滚

- 根因：`.modal-panel` 一直是 `overflow-y: auto`，README 区高度按 `42vh` 固定估算，叠加标题/简介/底部按钮后在 768~900 高的窗口上会溢出几像素到几十像素，于是面板自己出现滚动条。
- 改法：`openModal()` 里有 README 时给面板加 `has-readme`，面板切成 `display:flex; flex-direction:column; overflow:hidden`，头部/简介/底部 `flex:none`，`.modal-readme` 与 `.md-body` 用 `flex:1 1 auto; min-height:0` 吃掉剩余空间——只有 `.md-body` 有滚动条。没有 README 的页面卡片保持原块级布局与面板滚动。
- 极矮视口（`max-height: 560px`，如横屏手机）退回面板整体滚动并给 `.md-body` 保底 140px，避免正文被压成 0。
- 顺带修掉一个隐藏问题：面板是 `.modal` 的 flex 子项，默认 `min-width: auto` 会被 README 里的长代码行顶宽（窄屏会超出视口、关不掉弹窗）。补 `min-width: 0` 给面板 / `.modal-readme` / `.md-body`，并给 `.md-pre`、`.md-table` 加 `max-width: 100%`。
- 验证方式：装了 `puppeteer-core`（在 `C:/Users/16508/.workbuddy/binaries/node/workspace`）用真实视口量测 390×844 / 768×1024 / 1440×900 / 800×420，检查「面板是否滚动、README 是否滚动、有无横向溢出、footer/关闭按钮是否在面板内」，并截图目视确认。脚本在 `.ta3NewCoder/viewport-check.js`。
