## 总体架构

整站没有框架、没有构建步骤，只有三个东西：

```text
扫描(pages/, templates/)  →  字符串替换生成 index.html  →  浏览器端 JS 负责交互
```

| 阶段 | 执行者 | 产物 |
| :--- | :--- | :--- |
| 扫描 + 渲染 | `generate-index.js`（Node，零依赖） | `index.html` |
| 布局 + 视觉 | `assets/nav.css` | — |
| 交互（搜索 / 折叠 / 抽屉 / 主题 / 国际化） | `templates/nav-template.html` 内联脚本 | 随 `index.html` 一起下发 |
| 文案字典 + 运行时 | `assets/i18n.js` | — |
| 持续构建 | `.github/workflows/generate-nav.yml` | 推送回仓库的 `index.html` |

数据流：

```text
pages/**            generate-index.js         index.html
  │  <title>            │  scan()                 │  静态 HTML + 数据属性
  │  <meta desc/date>   │  renderTree()           │
  │  index.html?  ───►  │  replace {{placeholders}}
templates/             │
nav-template.html   ───►
```

> `index.html` 是生成物，**不要手改**，改模板或脚本后重跑生成器。

## 生成脚本 generate-index.js

零第三方依赖，用 Node 内置 `fs / path / child_process`。

### 扫描规则

递归扫描 `pages/`，同层先文件后文件夹，均按 `localeCompare('zh-Hans-CN')` 排序：

```
scan(dir)
  ├─ 每个 *.html 文件  → buildPage()   （单文件页面）
  └─ 每个子目录
       ├─ 含 index.html → buildProject()（整目录算一个项目）
       └─ 否则          → scan() 递归  （分组）
```

- 完全没有任何 HTML 的目录会被跳过，并打印 `跳过空文件夹`。
- `pages/index.html` 被视为模板文件，不参与扫描。
- 分组按遍历顺序分配稳定锚点 `nav-1 / nav-2 / …`，同时生成侧栏索引。

### 元数据读取

| 函数 | 作用 |
| :--- | :--- |
| `readTitle(content, fallback)` | 读 `<title>`，读不到用文件名 / 文件夹名 |
| `readMeta(content, names)` | 按 `name` 或 `property` 取 `content`，兼容属性顺序颠倒的写法 |
| `extractDescription(content)` | 兜底：剥掉 `script / style / head / header / nav / footer / svg / canvas` 等标签后取正文首段，优先截到第一个句末标点，最长 58 字 |
| `lastCommitDate(path)` | `git log -1 --format=%ad --date=format:%Y-%m-%d -- <path>`，失败退回文件 mtime，再退回今天 |
| `totalSize(dir)` / `countPages(dir)` | 递归统计目录体积与 HTML 数量 |

### 渲染产物

每个卡片带这些属性，供浏览器端脚本使用：

```html
<div class="card has-more" data-name="小写拼接头（参与搜索）" data-kind="page|project">
  <a class="card-link" href="…">…</a>
  <span class="card-tag" data-i18n="nav.projectTag">项目</span>
  <button class="card-more" data-i18n-title="nav.viewMore">…</button>
</div>
```

- `data-name` = `标题 + 描述 + 原始名 + tags` 拼接后转小写 —— 搜索就是在这个字符串上做 `indexOf`。
- `data-kind` 区分「单文件页面」与「项目文件夹」，决定是否渲染角标。
- 「共 N 页」等带数字的文案用 `data-i18n-vars='{"n":1}'` 传参，交给前端字典插值。

### 模板占位符

| 占位符 | 含义 |
| :--- | :--- |
| `{{siteTitle}}` `{{owner}}` `{{ownerText}}` `{{bio}}` | 来自脚本顶部的 `site` 配置 |
| `{{sideNav}}` `{{railNav}}` | 侧栏 / 横向分组索引 |
| `{{content}}` | 渲染好的卡片与分组树 |
| `{{statProjects}}` `{{statPages}}` `{{statGroups}}` | 项目 / 页面 / 分组数量 |
| `{{generatedAt}}` | 生成时间（UTC） |
| `{{introUrl}}` | `pages/介绍.html` 的编码后地址（扫描得到，找不到按约定路径兜底） |
| `{{docDevUrl}}` `{{docUserUrl}}` | `docs/` 下两份文档的 GitHub 阅读地址 |

替换完成后，脚本会检查残留占位符并打印警告。

## 导航页模板 templates/nav-template.html

### DOM 结构

```text
.app-shell
├─ aside.sidenav#sidenav        侧栏（宽屏常驻 / ≤1199px 抽屉）
│  ├─ .brand                   头像 + 作者 + 简介
│  ├─ nav.side-links           分组索引（含深度缩进）
│  └─ .sidenav-foot            统计、文档链接、GitHub、生成时间
├─ .scrim#scrim                抽屉遮罩
└─ .content
   ├─ header.topbar#topbar     菜单键 + 搜索 + 折叠/置顶/语言/主题
   ├─ nav.rail#rail            窄屏横向分组条
   ├─ main#content
   │  ├─ .page-head            标题 + 副标题 + 三个统计块
   │  └─ {{content}}           分组 / 卡片树
   ├─ .no-result#noResult
   └─ footer.site-foot
```

### 前端脚本模块（IIFE，无框架）

| 模块 | 要点 |
| :--- | :--- |
| 主题 | 读 localStorage `theme`，否则跟随 `prefers-color-scheme`；首屏内联脚本提前落 `data-theme` 防闪烁 |
| 分组折叠 | **不用纯 CSS 的 `max-height + overflow:hidden`**，改用 JS 测量高度做过渡，动画结束后清空内联样式回到 `overflow: visible` —— 这样卡片悬浮阴影不会被祖先容器裁剪 |
| 搜索 | 80ms 防抖；命中处用 TreeWalker 遍历文本节点包 `<mark>`，不清空 DOM 结构；`data-name` 做匹配 |
| 相对时间 | `relTime()` 把 `YYYY-MM-DD` 转成「今天 / 昨天 / N 天前 / N 个月前 / N 年前」 |
| 抽屉 | ≤1199px 时侧栏变 `position: fixed` 抽屉，遮罩点击 / Esc / 窗口变宽自动关闭 |
| 滚动联动 | IntersectionObserver 选最靠上的可见分组，高亮对应索引项；点击索引会先清空搜索并逐层展开祖先分组 |
| 详情弹窗 | 从卡片 DOM 里取标题/描述/图标/统计，支持复制链接（回落 `window.prompt`） |
| 国际化 | 启动时 `I18N.apply(document)`，语言变化时重算相对时间、按钮 title、计数文案，并重绘打开的弹窗 |

快捷键：`/` 或 `Ctrl/Cmd+K` 聚焦搜索，`Esc` 逐层退出，`D` 切主题，`L` 切语言。

## 样式 assets/nav.css

### 主题变量

所有颜色走 CSS 变量，`:root` 为暗色，`[data-theme="light"]` 为亮色。常用项：

| 变量 | 用途 |
| :--- | :--- |
| `--bg` / `--bg-gradient` | 页面底色与背景光斑 |
| `--panel` / `--panel-solid` | 顶栏、侧栏、弹窗面板 |
| `--card-bg` / `--card-bg-hover` / `--card-border` | 卡片三态 |
| `--accent` / `--accent-glow` / `--accent-faint` / `--accent-line` | 强调色及三档透明度 |
| `--shadow-color` / `--shadow-close` / `--shadow` | 阴影（悬浮时三层叠加） |
| `--card-min` / `--grid-gap` | 卡片最小列宽与栅格间距（由断点改写） |
| `--side-width` | 侧栏宽度 |

### 响应式断点

| 断点 | 布局 |
| :--- | :--- |
| ≥1600px | 列宽提到 288px、间距 22px（超宽屏多列） |
| ≥1200px | 侧栏常驻 + 内容区，卡片 `auto-fill minmax(272px, 1fr)` |
| ≤1199px | 侧栏改为抽屉，出现 ☰ 按钮与横向分组条 |
| ≤1023px | 卡片列宽 240px（平板竖屏约两列），页头纵向堆叠 |
| ≤767px | 单列卡片、搜索框换行占满、弹窗变底部抽屉式、操作按钮常驻 |
| ≤420px | 统计块等分、隐藏语言按钮文字只留图标 |
| `hover: none` | 触屏设备取消位移效果、常驻显示 `…` 按钮 |

另外适配了 `env(safe-area-inset-*)`、`prefers-reduced-motion` 与 `@media (prefers-color-scheme)` 的 `theme-color`。

### 阴影不被裁剪的实现

悬浮卡片需要外扩阴影，因此：

1. `.group-body` 默认 `overflow: visible`、`max-height: none`；
2. 折叠动画由 JS 临时写入 `overflow: hidden` + `max-height`，动画结束立刻清空内联样式；
3. 卡片 `:hover` / `:focus-within` 时 `z-index: 2`，保证阴影盖在相邻卡片之上；
4. `.cards-grid` 用 `padding + 负 margin` 预留 4~8px 呼吸位，避免边缘卡片的阴影贴边。

## 国际化 assets/i18n.js

导航页与介绍页共用这一个文件，没有额外依赖。

### 用法

给节点加任一 supported 属性，脚本会自动替换：

```html
<span data-i18n="nav.home">首页</span>
<span data-i18n="nav.pages" data-i18n-vars='{"n":3}'>共 3 页</span>
<button data-i18n-title="nav.search" data-i18n-aria-label="nav.search" title="搜索项目">
<meta name="description" data-i18n-content="nav.metaDesc" content="…">
```

| 属性 | 写入位置 |
| :--- | :--- |
| `data-i18n` | `textContent` |
| `data-i18n-html` | `innerHTML` |
| `data-i18n-title` | `title` |
| `data-i18n-content` | `content`（给 `<meta>` 用） |
| `data-i18n-placeholder` | `placeholder` |
| `data-i18n-aria-label` | `aria-label` |

字典里用 `{n}` 占位，通过 `data-i18n-vars` 传值。

### 运行时 API

```js
I18N.lang            // 'zh' | 'en'
I18N.t(key, vars)    // 取文案并插值
I18N.apply(root)     // 翻译某个子树
I18N.set(lang)       // 指定语言（会写 localStorage 并广播）
I18N.toggle()        // 中英互换
I18N.onChange(fn)    // 注册语言变化回调
I18N.nextLabel       // 按钮上显示的「另一种语言」标签
```

语言优先级：`?lang=xx` > localStorage `lang` > `navigator.language` > `zh`。

### 加一条新文案

1. 在 `assets/i18n.js` 的 `DICT.zh` 与 `DICT.en` 里各加同一个 key；
2. 在 HTML 上写 `data-i18n="key"`，默认文本内容写中文（便于抓取与兜底）；
3. 如果该文案是 JS 动态生成的，用 `I18N.t('key')`，并在 `I18N.onChange` 回调里重算。

> key 尽量用 `模块.语义` 命名：`nav.*` 导航页、`intro.*` 介绍页、`common.*` 通用、`time.*` 相对时间。

## CI 工作流

`.github/workflows/generate-nav.yml`：

```yaml
on:
  push:
    branches: [ main ]
    paths: [ 'pages/**', 'templates/**', 'assets/**', 'generate-index.js' ]
  workflow_dispatch:          # 支持手动触发
permissions:
  contents: write             # 关键：允许推回 index.html
```

步骤：checkout → setup-node 20 → `node generate-index.js` → 有变更则 commit & push（`github-actions[bot]` 身份）。

触发条件包含 `assets/**`：虽然 CSS/JS 是运行时引用、不必重建，但模板结构调整时一并触发更省心。

## 二次开发清单

| 想改什么 | 改哪里 | 要不要重新生成 |
| :--- | :--- | :--- |
| 配色、间距、断点 | `assets/nav.css` | 不需要 |
| 文案、新增语言 | `assets/i18n.js`（+ 各页面 `data-i18n`） | 不需要 |
| 导航页结构、交互脚本 | `templates/nav-template.html` | 需要 |
| 扫描规则、排序、卡片字段 | `generate-index.js` | 需要 |
| 站点标题 / 作者 / 仓库名 | `generate-index.js` 顶部 `site` | 需要 |
| 图标映射 | `generate-index.js` 里的 `iconMap` | 需要 |
| 触发时机 | `.github/workflows/generate-nav.yml` | — |

`site` 配置：

```js
const site = {
  owner: 'Verlif',      // GitHub 用户名：头像、链接、文档地址
  repo: 'someToys',     // 仓库名：拼接 docs 链接
  siteTitle: 'someToys',
  bio: 'AI 单页面作品集',
};
```

新增占位符的流程：在模板里写 `{{xxx}}` → 在 `generate-index.js` 的替换链里加一行 `.replace(/\{\{xxx\}\}/g, value)`。生成器在收尾时会扫描残留占位符并警告，忘记加也能被发现。

## 约束与已知问题

1. **`index.html` 永远由脚本生成**，手改会在下次 CI 时被覆盖。
2. **Git 不跟踪空目录**，新分组里必须至少放一个 HTML（或用 `.gitkeep` 占位）。
3. **CI 是全新 checkout**，`git log` 取不到提交时间时会退回当天日期；需要固定日期就写 `<meta name="date">`。
4. **搜索只做小写包含匹配**，不分词、不支持正则；中文连写时命中依赖子串匹配。
5. **分组锚点 `nav-N` 由遍历顺序决定**：新增分组会让后面的编号整体位移，旧分享链接可能跳转偏移。
6. **卡片标题 / 描述不会翻译**：它们来自作品的 `<title>` 与 `description`，切换语言只影响界面文案。
7. **relTime 依赖客户端时间**：时区差异可能让「今天 / 昨天」差一天，`title` 属性里始终保留原始 ISO 日期。
8. 打开的卡片页均为新标签页（`target="_blank"`），嵌套第三方页面无法被导航页控制。
